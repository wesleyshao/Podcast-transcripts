# Why the Biggest Robotics Opportunity Isn’t Humanoid

## Transcript

**主持人 David Hoffman：** 今天的嘉宾是 Shahin Farshchi，他是 Lux Capital 的 General Partner。Lux 是一家投资 hard tech 的风险投资机构，关注 frontier technology，包括 AI、automation、biotech 和 robotics，但并不投资 crypto。Shahin 在 robotics 和 automation 领域投资了十多年，经历过几轮行业热潮。我想借这次机会了解，机器人产业真正的机会在哪里，也想分清楚哪些是长期趋势，哪些只是围绕 humanoid robots 的兴奋叙事。

**David：** 最近机器人领域的热度非常高，很多人第一次认真了解这个行业。Tesla Optimus、Figure 等 humanoid 项目让更多人开始关注机器人。但热度既能带来学习机会，也可能让人把演示当成商业进展。你认为当前围绕 robotics 的 hype 是否合理？

**Shahin Farshchi：** 我认为 hype 是合理的。但我并不是因为 humanoid 这个形态本身而兴奋。真正吸引我的是最近一轮 AI 创新、制造成本下降，以及把非常复杂的系统以更低价格做出来的能力。把 intelligence 和 cheap manufacturing 结合起来，就能产生过去因为成本或工程难度而无法实现的产品。

Robotics 和 automation 都不是新事物。assembly line 已经存在了很久，Ford 时代就开始把自动化引入制造业。过去十五年左右，随着 2010 年代初 convolutional neural networks 的发展，以及 robotic arms 成本持续下降，我们看到了新一轮 robotics applications。Humanoid robots 是这轮变化的一种表现，但我个人的兴趣并不建立在 humanoid 上，而是建立在驱动机器人运行的软件变强，以及硬件逐渐 commoditization 这两个更大的 tailwind 上。

如果回到 1970 年代，也能看到相似机会。当时 microprocessor 可以被看作那个时代的 AI，它把一定程度的 intelligence 放进机器人，让 robotic arms 能按非常细的规格执行 welding、riveting、gluing、painting 和 inspection 等具体任务。机器人因此进入 automotive manufacturing，并在之后不断扩展。今天走进大型汽车工厂，早期的许多制造步骤几乎完全自动化，直到安装内饰、wiring harness 和玻璃等较后面的步骤，才会看到更多人工参与。

现在的变化是，向大型企业供应零部件的中小企业也可能获得 automation。走进 Ford 工厂，会看到很多自动化设备；但走进给 Ford 供应部件的工厂，自动化可能少得多，因为它们没有 Ford 那样的预算，无法用传统方式投入大量工程和资本。AI 正在降低这种门槛。就像现在任何人都可以通过自然语言生成代码，未来也可能通过更容易使用的工具编程机器人。过去没有机会接触机器人的行业，正在获得新的入口。

**David：** 所以你的兴奋点是 intelligence 进入 automation，同时让自动化成本下降，并使更多产业能够使用它，而不只是制造一个外观像人的机器人？

**Shahin：** 对。对投资人而言，robotics 的意义不只是进入一个已经存在的大市场，也可能是创造过去不存在的市场。AI、软件和 hardware commoditization 让原本买不起机器人、也没有能力设计自动化方案的公司，开始成为潜在客户。新的市场一旦形成，其中一些公司就可能建立优势。

**David：** 我们经常把 robotics 和 automation 放在一起说，它们是否是同一个概念？

**Shahin：** Automation 是为了解决一个问题而设计的整体 solution。它包括 financing、engineering、factory floor 和 workflow 的设计，也包括 physical robot 本身、运行机器人的 software，以及维护系统，确保设备能够以极高 uptime 工作。所有这些资源共同完成一个任务的自动化。

Robot 是 automation 的一个 component，但两者不相同。一个工厂可以通过重新设计流程、软件、传感器或设备来提高自动化程度，不一定需要一个外形复杂的通用机器人。反过来，一个机器人如果没有融入工作流、没有维护能力、没有清晰的经济回报，也不等于一个有效的 automation solution。

**David：** 机器人似乎有一条从高度专用到高度通用的 spectrum。比如 Ford 工厂里的固定 robotic arm 只做一个精确动作，Amazon 仓库里搬运包裹的小车则相对灵活。你看好哪一段？

**Shahin：** Automation solution 的形态取决于要解决的问题。Amazon warehouse 的 order fulfillment 和汽车 assembly 是完全不同的任务，需要不同的系统。一个创始人或投资人可能有经济动机把自己的产品描述成能够解决所有 automation 问题的通用平台，humanoid form factor 也很适合这个故事，因为人类可以完成很多不同任务。但这更像一种经济叙事，而不是在所有场景都实用。

我的判断是，不同应用会对应不同的 robotics 和 automation solution。未来肯定有 humanoid robots 适合完成一部分现在由人完成的任务，但它们只是许多形态中的一种。Ford 工厂里负责 welding 的机械臂，和 Amazon 仓库里搬运箱子的机器人几乎没有共同的外形；它们可能都由金属、塑料、芯片和摄像头组成，但给最终用户创造的价值完全不同。没有理由认为一个单一形态会在所有问题上都胜过针对特定任务优化的设备。

**David：** 也就是说，humanoid 之所以容易被讨论，是因为它有一个统一、直观、像人的形态。但其余 automation 会是高度异质的、针对具体任务设计的系统？

**Shahin：** 基本如此。不同机器人之间仍会共享一些 building blocks，例如 cameras、force sensors、reduction gear sets、encoders、power management systems、motors 和 arms。它们就像 smartphone、laptop 和 tablet，使用场景不同，外形和规格不同，但共享 ARM-based processor、memory、Wi-Fi、display 和一部分 software architecture。

一个做 welding 的 robotic arm 可能和一个做 riveting 的 robot 使用相同的 motors、encoders、force sensors 和 cameras，但 end effector、运动范围和软件逻辑不同，因为它们分别针对不同任务优化。机器人产业真正的难点，不一定是生产每个零件，而是把这些零件按照具体任务组合成一个可靠、经济的系统。

**David：** 这是否意味着原材料和执行器已经足够，约束在于如何把它们组装成正确形状？

**Shahin：** 这正是为什么 robotics 长期只在大型工业环境中普及。Ford 可以投入数千万美元，请 Honeywell、Dematic、Symbotic 等擅长特定场景的公司设计 automation。汽车生产线上有一连串任务：机器人把铝板送进冲压机，再把冲压后的部件转移出去；带摄像头的设备检查缺陷；另一个机器人把金属片放在一起进行 welding，后面还有 riveting、gluing、acid bath 和 painting。每一个步骤都可能需要单独的 engineering。

传统技术下，这类工程非常昂贵，只有少数公司负担得起。我的兴奋点在于，机器人硬件越来越便宜，设计和编程机器人也可能越来越容易。未来，用户可以对 AI-powered interface 说出自己想自动化的任务，由系统帮助编程，而不必每次都雇佣专门工程师。这会像一个 developer platform：基本组件已经存在，关键是让更多人能够组合、测试和调整这些组件，满足更小、更具体、更分散的市场需求。

**David：** 现在有没有公司已经在做这种更开放、更容易使用的系统？

**Shahin：** 一个例子是 Physical Intelligence。对结构化的 welding 任务，机器人可以在非常精确的固定路径上工作；但对没有固定结构的任务，自动化难度高得多。Physical Intelligence 正在训练适合不同 unstructured tasks 的 models，并把很多模型放到 open source repositories，供 roboticists 下载、fine-tune 和用于各自的场景。

过去，这类工作可能需要很多 PhD、数百万美元资金和多年时间。现在，一个本科生甚至高中生，也可能下载模型并让机器人完成某个具体任务。当然，机器人还没有因此马上遍布各地。它们需要变得更 reliable、更 fast，也要在成本上和 labor 竞争。技术能够运行，不等于客户愿意购买；真正的商业化还取决于稳定性和回报。

**David：** 你说机器人产业的拐点可能已经发生，只是普通消费者还没有感觉到？

**Shahin：** 是的。消费者可能走在纽约街头，还看不到 robotics 明显改变生活，但工厂内部的 frontier 已经在推进。可以用 compute 的历史来类比。1970 和 1980 年代，人们把 computer 看作 hardware，关心 processor speed、RAM 和 graphics interface。互联网出现后，compute 不再主要被理解为一台设备，而是一个 capability。人们使用互联网、消费内容和保存文件，底层 hardware 被抽象掉了。

机器人现在有点像 compute 的早期阶段。我们仍然在谈论 plastic、metal、bearings、cameras 和 software，仍然在看机器本身和酷炫 demo，还没有完全转向讨论机器最终输出了什么。未来如果产业成熟，用户不会重点关心机器人采用什么材料，而会关心它能否完成某个任务、产出多少、成本是多少。这种从“机器”到“能力”的抽象，是大规模普及的重要信号。

**David：** 机器人会不会把人类从工作中替代掉？

**Shahin：** 这是合理的担忧。直觉上，automation 增加，labor opportunity 似乎会减少。但历史趋势并不完全支持“automation 等于更多失业”。采用更多 automation 的经济体，往往也能获得更低的失业率；拒绝自动化的经济体，反而可能面临更高失业。真正同时阻碍 labor 和 automation 的共同因素，很多时候是 cheap labor。

当另一个地区拥有更便宜的人工时，本地工作会被转移，同时 automation 也更难达到经济门槛。automation 当然会在短期内挤出一些岗位，但它也可能创造更多质量更高、流动率更低、员工满意度更好的工作。关键不只是机器人替代了什么，还要看机器人能否让企业在本地继续生产、提高生产率，并创造新的工作类别。

Lux 投资的 Formic 提供 robots as a service。它卖的不是一台孤立的机器，而是机器能够完成的 output。Formic 把设备和复杂部署过程抽象掉，让工厂或仓库的 owner/operator 使用机器人像雇佣 labor 一样简单。很多客户并不是为了裁员或单纯节省工资才使用 automation，而是因为根本找不到足够的工人。这些岗位过去 churn 很高，部署自动化后，反而可能形成更多质量更高、满意度更好的工作。

**David：** 如果 automation 在未来十年大规模成功，会如何影响普通消费者、商品价格和经济？

**Shahin：** 大方向会是更多选择、更多竞争，以及最终对消费者有利。工厂的 productivity 提高，员工可以获得更高工资，单位经济性改善，企业能够以更好的价格出售更好的产品，收益最终传给客户。前提是 automation 足够容易采用，也足够 reliable。

社会还必须教育 workforce，让人们有机会提升 skill set。不能只看到岗位被替代，然后被动问如何处理失业，而应该提前准备新一代工作。若员工能够掌握维护、部署、流程设计、监督和其它更高价值技能，automation 更可能带来更高薪、更高质量的岗位，而不是把转型成本全部压给个体。

农业是一个很好的历史例子。农业很早就开始自动化，结果是社会从 food shortages 走向食物更充足。Automotive 和 consumer electronics 也高度自动化，所以我们能够获得更安全、更高效、更可靠的汽车和设备。新一轮 automation 可能把类似收益带到过去因为成本高、需求分散或流程复杂而没有自动化的行业。

我对 factory 和 warehouse 的 near-term opportunity 比 companion robots、butler robots 和 household robots 更兴奋。自动驾驶汽车是一个重要例子，autonomous vehicles 已经开始出现，但 autonomous trucks 和 big rigs 还没有完全实现。家庭场景还要解决安全、可靠性和复杂环境问题。清理孩子留下的东西、帮助老人、把餐具放进洗碗机，听起来简单，实际需要机器人在高度不结构化环境中安全行动。

家庭机器人还有 last-mile 问题。工业客户的 task 更受约束，价值主张和 ROI 也更容易定义；家庭消费者对家具和设备的使用差异很大，同一台机器人给不同家庭带来的效用未必相同。因此，工业和商业场景可能会更早规模化。不是家庭机器人不可能出现，而是它可能比许多 hype 叙事预期的时间更晚。

**David：** 新一代 automation 公司现在最大的共同约束是什么？

**Shahin：** 主要是应用范围、reliability 和 unit economics。买 conveyor belt、package sorting machine 或餐厅的 coffee grinder 时，客户通常知道投资回报怎样计算。一个有十个客户试用过的新技术则不同，客户很难据此判断长期回报。很多新 automation 公司面对的难题不只是技术能否运行，而是如何证明价值，如何让客户能够 properly underwrite 这项投资。

客户需要知道机器能运行多少小时，故障时谁负责维护，部署要花多久，需要多少人工配合，产能提高多少，以及节省的成本能否覆盖设备费用。若这些问题没有清晰答案，再先进的 demo 也很难转化为大规模销售。机器人公司必须把技术、部署、融资和服务放在一起，才能真正成为 automation provider。

**David：** 我还想理解 AI 怎样进入机器人。很多人会想，既然有 LLM，把它装进机器人就会得到通用智能机器人，但现实显然更复杂。VLM 和 VLA 分别是什么？

**Shahin：** AI 在机器人里有很多层。今天现场运行的机器人，通常会从 cameras、radar、LIDAR 或其他传感器获取信息，再经过 processing chain 理解环境。这包括把天空、地面和物体分开，判断什么可以移动、什么不能移动、哪个是目标对象。这个阶段可以叫 perception。

接下来是 planning：如果是机械臂，如何伸手抓住目标；如果是汽车，如何在有施工的路口选择路线。最后是 actuation，系统根据计划启动不同 motor，实际执行动作。这种 sensing、perception、planning、action 的流程，是当前机器人常见的 AI workflow。

VLM 是 vision language model，VLA 是 vision language action model。它们试图用 language 解释场景，再通过 language 形成 action plan，把观察和意图转换成机器人的动作。例如，传感器拍到冰箱内部，系统识别物体，理解“我想要一瓶啤酒”，再规划打开冰箱、定位啤酒、伸手抓取和拿回来的动作。

这是一种很有吸引力的 generalizable 方法，但不能简单地认为只要把模型做大就能解决一切。人和动物并不会在脑中逐句说出看到什么、接下来怎么行动。我们还依赖感觉、预先训练的 reflex、heuristics 和大量未必显式表达的判断。因此，纯粹依赖 language 的大模型，和传统 sensing、perception、planning、action 体系怎样结合，仍然没有定论。我预期未来会出现 hybrid approach。

VLM 和 VLA 已经显示出更强的可泛化潜力。理论上，可以像教孩子一样教机器人完成任务，而不必为每个环境从头编程。但今天它们还相对新，速度和 reliability 可能不如传统系统。一个 autonomous vehicle 可能需要数百名工程师训练和验证从 A 到 B 的安全路径；未来 VLA 是否能以更少的人力实现同样的可靠性，还需要时间证明。

**David：** 语言模型能够从互联网获得海量数据，但机器人没有同样规模的数据。机器人如何解决 training data bottleneck？

**Shahin：** 这是一个非常重要的优势来源。我们投资了 XO，它专注于生成 robotics training data。Physical Intelligence 也在内部积累大量数据。能否访问、生成和组织特定应用的 training set，会成为机器人公司的重要差异化能力。

机器人需要学习的不是一个网页上的知识，而是如何以正确的力抓住一个物体、如何在不同材质上移动手臂、如何在障碍物旁边保持安全、如何在误差发生时恢复。这样的 physical interaction data 不容易从互联网直接获得。能够建立数据采集、仿真、训练、fine-tuning 和反馈闭环的公司，会拥有明显优势。

但数据多也不是全部。数据要与具体任务相关，模型要转化为可执行动作，系统还要经过现实世界的安全验证。机器人在实验室里偶尔成功，和在工厂中连续运行、保持 uptime、承担责任，是完全不同的标准。未来竞争会同时发生在 model、data、hardware、workflow 和 deployment service 上。

**David：** 你个人最希望尽快拥有哪种 automation？

**Shahin：** 我希望有一辆始终可用的 autonomous car，不需要每次叫 ride share，也不需要自己处理停车。现在通过 Waymo 和 Tesla FSD，某种程度上已经能体验到这一点，但我希望车辆能够自己找地方停车、离开并在需要时回来。作为一个 car enthusiast，这会很有吸引力。

家庭里，我也会出于好奇想拥有一台能力不算很强的机器人，比如可以关掉炉子、倒一杯水并送过来。但我有妻子和两个年幼的孩子，在机器人被证明绝对安全、不会绊倒孩子之前，家里未必会允许它进入。对我个人来说，它会是有趣的 novelty；对一个普通家庭来说，安全和可靠性必须先于新奇感。

**David：** 听众如果想继续学习，有哪些公司值得了解？

**Shahin：** 可以了解 Physical Intelligence，看看它公开的 models 和研究。也可以关注 Formic，它正在真实的 manufacturing 和 logistics 场景中部署 robots as a service，已经有数百个 deployment。许多客户在使用 Formic 之前几乎没有 automation，这说明市场不只是把旧设备换成新设备，也是在让过去接触不到机器人的客户第一次使用 automation。

**David：** 你的核心判断是，机器人产业的真正机会不在于一个能解决所有问题的 humanoid，而在于 AI 让各种具体、专用、可负担的 automation solution 更容易被部署？

**Shahin：** 是的。Humanoid 会有自己的位置，但它只是整个 spectrum 的一部分。更大的机会可能来自 software、training data、integration、maintenance、robots as a service，以及让中小企业也能使用机器人的 developer platform。真正的产业进步会表现为更多任务被可靠、可量化地完成，而不是每次都出现一个更像人的 demo。

如果 automation 足够便宜、足够可靠、足够容易部署，它会从大型汽车工厂扩展到仓库、农业、商业服务和更多细分行业。工业和商业场景的约束更清楚，客户的 ROI 更容易计算，也更容易形成规模。家庭机器人最终可能到来，但其安全、数据、环境变化和 last-mile 复杂度意味着它需要更长时间。

**David：** Shahin，谢谢你参加 Bankless。

**Shahin：** 谢谢邀请，David。这次讨论很愉快。

## 核心观点

1. 嘉宾认为 robotics 的长期热度有基本面支撑，但个人兴奋点不在 humanoid，而在 AI、低成本制造和机器人软件共同降低 automation 门槛。
2. Automation 是一个解决问题的完整系统，包含流程工程、机器人硬件、software、维护和 financing；robot 只是其中一个 component。
3. 不同任务需要不同形态的专用设备。Humanoid 可能占据一部分市场，但不太可能成为所有自动化问题的单一解决方案。
4. 机器人产业的关键机会包括更便宜的硬件、降低编程门槛、开放模型、training data、系统集成、维护和 robots as a service。
5. 工业和商业场景的任务约束更强、ROI 更容易计算，因此可能早于家庭场景规模化。家庭机器人还要解决安全、可靠性和 last-mile 复杂度。
6. 自动化可能在短期挤出部分岗位，但也可能因本地化生产率提高而创造更高质量岗位。劳动力再培训是能否共享收益的重要条件。
7. VLM 和 VLA 提供了更强的泛化路径，但速度、可靠性、训练规模和 physical interaction data 仍是开放问题，未来更可能采用 hybrid architecture。
8. 节目提到 Tesla、Ford、Honeywell、Dematic、Symbotic、Waymo 等案例或行业参照，没有对这些上市公司给出估值、目标价或明确买卖建议；Physical Intelligence、Formic、XO 属于节目讨论的私有公司或项目，不能直接转成交易结论。

## 继续转写：应用、商业化与模型

**主持人：** 农业是不是一个特别值得关注的自动化领域？如果 automation 在未来十年达到行业希望的程度，普通人会怎样感受到它？

**Shahin：** 农业其实是最早被自动化的行业之一。自动化推动社会从过去的 food shortages 走向更充足的食物供应。Automotive 和 consumer electronics 也是高度自动化的领域，所以今天我们拥有更安全、更高效、更可靠的汽车和电子产品。很多人会使用一辆车十年，也可以选择购买更先进的新车，而汽车随着技术进步往往变得更便宜、更有能力、更安全、更节能。这些都是 automation 传导给消费者的收益。

如果看今天的 zeitgeist，很多人最兴奋的是家庭里的 companion robot、butler robot 和 household robot。我对这些场景比较谨慎，不是因为它们不可能，而是因为 factory 和 warehouse 里仍有大量更现实的工作没有完成。我们已经在看到 autonomous cars，但 big rigs 和 trucks 还没有完全自动化。未来家庭机器人可能会清理孩子留下的东西、帮助老人、把餐具放进洗碗机，但这些任务需要处理高度变化的环境，安全标准也远高于一个封闭的工业工作站。

把机器人送进每一个家庭，存在巨大的 last-mile 问题。工业和商业场景的任务通常更 constrained，客户的价值主张和 economics 更容易定义。家庭里不同人的生活方式差异很大。一件家具对一个人很有用，对另一个人可能几乎没有用；一个家庭愿意为机器人支付的价格，也取决于安全、噪声、空间和使用频率。因此，工业和商业 automation 可能更早形成可规模化的市场。不能因为家庭机器人更性感，就忽略工厂、物流和商业服务里的真实机会。

**主持人：** 新产品进入工厂时，客户应该怎样判断 ROI？

**Shahin：** 传统设备的回报相对容易计算。客户购买 conveyor belt、package sorting machine 或餐厅的 coffee grinder，通常知道它需要多少资金、提高多少产出、节省多少人工和维护费用。新的 automation 产品只有少量早期客户时，客户很难从十个样本判断长期表现。

所以，新一代 robotics company 的挑战很多时候不是“能不能做出来”，而是能否证明价值。客户需要看到 uptime、故障率、部署周期、维护成本、产量变化和替代方案，才能 properly underwrite。一个机器人在演示中成功一次，不代表它能在工厂里连续工作。只有当公司能把硬件、software、部署、维护和融资组合成清晰的服务，客户才会把它当作生产工具，而不是一次实验。

**David：** 如果这些 system 变得容易部署，automation 对经济的长期影响会怎样？

**Shahin：** 总体上会带来更多选择和更多竞争，最终让消费者受益。采用 automation 的工厂提高生产率，员工有机会获得更高工资，单位经济性改善，企业就能以更好的价格提供更好的产品。短期可能存在岗位从一个行业转到另一个行业的痛苦，但长期需要关注创造了什么新工作，以及员工是否得到学习新技能的机会。

社会不能只看到岗位减少后再被动处理 workforce，而应当主动教育员工。新的工作可能与设备维护、流程设计、机器人监督、数据和安全有关，也可能出现在 automation 之前不存在的服务中。如果员工有机会提高 skill set，生产率提升就更可能转化为更高质量、更高收入的岗位。

**David：** 现在机器人使用的 AI，是否就是把 LLM 放进一个机器身体？

**Shahin：** 不是这么简单。现场运行的机器人通常从 camera、radar、LIDAR 或其他传感器获取环境信息，再进行 perception。系统需要判断哪里是 sky、哪里是 ground，哪些 object 可以移动，哪些不能移动，哪个 object 是目标。之后进入 planning，决定机械臂怎样触碰目标、汽车怎样通过路口或仓库机器人怎样到达另一个位置。最后才是 actuation，按照计划启动 motor 和其他执行器。

VLM 是 vision language model，VLA 是 vision language action model。它们尝试把视觉场景转换成语言或更高层的语义，再根据目标产生行动计划，并把计划转成 motor actuation。例如，系统看到 refrigerator，理解用户想要 beer，找到啤酒的位置，打开门、伸手抓取，再把啤酒拿回来。这种 language-mediated approach 可以帮助机器人处理更多变化，但它还比较新，在速度和 reliability 上可能不如传统的 perception、planning、action pipeline。

人类也不是先用语言完整描述场景，再一步步执行。我们依赖触觉、习惯、预先训练的 reflex 和 heuristics。机器人模型是否可以只靠更大规模的 language model 解决这些问题，还是必须和传统控制方法结合，目前还没有答案。我更预期两者会形成 hybrid。VLM 和 VLA 有机会提升 generalizability，让机器人像教孩子一样学习一个任务，但要达到工业安全标准，仍需要大量训练、测试和验证。

例如，要教一个四岁孩子写数字，有些数字示范两次就会，有些数字因为弯曲和停顿的动作很难学会。机器人也会面对类似问题：大方向看似理解了，细微的 force、timing 和 stopping point 却可能决定是否成功。模型变大可能有帮助，但不代表所有 physical skill 都会自动出现。

**David：** Chatbot 可以从整个互联网学习，但机器人没有同样规模的数据。物理交互数据是不是一个更大的瓶颈？

**Shahin：** 是的。机器人要学的是如何用正确的力抓取东西，如何在不同材质上移动，如何处理一个 object 滑动或突然改变位置。这类 data 很难从公开互联网获得。能够访问和生成 robotics training data 的公司会更有优势。我们投资了 XO，它专门生成 robotics training data；Physical Intelligence 也在内部积累大量数据。

训练集必须和具体 application 相关。一个在实验室中抓取杯子的模型，不一定能在工厂抓取金属零件；一个适合 warehouse 的导航系统，也不一定能处理农业、建筑或家庭。除了收集 data，还要把数据转成可训练的模型，再把模型部署到 hardware，并在现实环境中验证安全和稳定性。模型、数据、硬件、集成与服务之间的闭环，可能是长期竞争的核心。

**David：** 你个人希望机器人尽快怎样改变生活？

**Shahin：** 我希望有一辆一直可用的 autonomous car，不用叫 ride share，也不用自己处理停车。Waymo 和 Tesla 的 FSD 已经让部分体验出现，但我希望车辆能自己找地方停车，之后在我需要时回来。作为 car enthusiast，这对我很有吸引力。

在家里，如果只考虑个人兴趣，我会想要一台能力普通的机器人，可以帮忙关掉炉子、倒一杯水或者把东西送过来。但我有妻子和两个小孩，家人不会接受一台还可能绊倒孩子的机器。家庭机器人必须首先被证明安全、可靠，能够处理意外情况，而不是只在精心准备的 demo 中完成任务。

**David：** 还有哪些公司能帮助听众理解这个行业？

**Shahin：** Physical Intelligence 值得关注，大家可以研究它公开的 models，了解 unstructured task 的方向。Formic 也值得了解，它在真实 manufacturing 和 logistics 场景部署 robots as a service，已经有数百个 deployment。许多客户在采用 Formic 之前几乎没有 automation，这正说明可访问性本身就是市场机会。它希望让客户购买机器的 output，而不是自己承担硬件和工程的全部复杂性。

未来机器人产业不会只属于生产最酷的 humanoid 的公司。更重要的问题是，哪种系统可以在明确任务中持续运行，客户是否愿意付费，系统是否可以被更多企业采用，以及训练数据和软件是否随着部署增加而变强。只要机器人从一个需要专家维护的机器，变成一个任何企业都能调用的 capability，产业才会真正进入大规模增长阶段。
