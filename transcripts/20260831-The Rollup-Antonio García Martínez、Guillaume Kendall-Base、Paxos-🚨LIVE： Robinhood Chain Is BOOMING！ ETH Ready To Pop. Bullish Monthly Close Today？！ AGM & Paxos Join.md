Antonio：B20 中的 20 来自 ERC-20。它是在基本 token standard 上加入更多可调用功能。它有 compliance features，也有 OFAC checks，不能把 token 发送给被正常金融体系禁止的 wallet。它还通过 multiplier 处理 dividends。B20 不是简单地把一个 token 放在链上，而是把 security 作为真实资产放在链上交易。B20 由 Base chain team 开发，chain 像 engine room 一样运转，真正与资产、证券和合规有关的功能则在更高层实现。

### Antonio 的链上营销解释

Andy：我们再谈谈 onchain marketing。你有地址、tracking 和 links 方面的经验。我们熟悉 Facebook pixel，它把用户点击广告与最终购买串起来。onchain marketing 现在是什么状态？

Antonio：我曾经是 Facebook 的 PM，参与过 pixel 发展。用户点击 Facebook 或 Instagram 的广告并购买商品之后，一个 signal 会返回 Facebook，告诉它用户完成了 funnel，广告价值需要怎样计费。Pixel 把 top of funnel，也就是用户看到的广告，与 bottom of funnel，也就是用户购买商品，串起来。

Antonio：Spindle 的核心思想是，链上不需要 pixel firing，因为用户最终是否完成了行为直接写进 blockchain。我们使用 builder codes。当用户在某个 frontend 上交易，例如在 Hyperliquid 或 Base 的 partner 上交易时，frontend 会把匿名的 code 附加到 transaction data，说明用户是从 FOMO、KyberSwap、LiFi 或其他渠道来的。

Antonio：随后我们可以观察这个用户在链上的 monetization 表现，并把相应价值返还给真正带来用户的 partner。这不像依赖 cookies、PII、GDPR 的传统 pixel，而是链上数据。我们正在 tokenized equities 上做 trading contest，也在探索如何把价值分给用户与 distribution partner。这其实是在闭合 growth loop，但它仍是没有完全解决的问题，crypto 里的增长仍然很难。

Andy：对于 DeFi protocol、blockchain 或 CMO 来说，onchain attribution tracking 是不是不可谈判的基础设施？

Antonio：这取决于你在过去四年什么时候问我。Spindle 刚成立时，我和一些市值十亿美元的 protocol 交流，问他们 CAC、LTV 和 acquisition cost，他们甚至不知道 CAC 是什么。这是 2022 到 2023 年左右 crypto 的状态。现在，最好的 protocol，例如 Morpho 和其他成熟项目，已经知道自己的 CAC、LTV 和收入。对于有真实收入的大型 protocol，growth team 需要 onchain attribution。

Antonio：当然，这仍然很难。用户可以直接通过 RPC node 进入 protocol，项目可能不知道用户从哪里来。但传统互联网也有同样问题。Google Analytics 里的 organic 列，很多时候并不代表真正的自然增长，只是 attribution system 失败了，不知道用户来源。链上也有 unattributed organic activity。但总体上，这个领域比过去成熟很多，大多数项目都会在某种程度上跟踪这些指标。

Andy：Base 当前最重视的指标是什么，用户、TVL 还是交易量？

Antonio：如果你让我在一个房间里用十五分钟写出描述 Base economy 健康度的指标，我会列出几乎相同的一组指标。revenue 是核心，因为它决定我们如何 monetization。除此之外，还有 volume、lend and borrow TVL、payment volume 等。这些是任何 Dune dashboard 都会关注的基本指标。

主持人：谢谢 Antonio。Base 与 Robinhood 的竞争只是整个市场的一小部分，未来的 pie 还要扩大很多。链上交易、投资、earn 和 save 都在变成成熟的替代路径。稳定币、机构 tokenization 和企业资产上链正在同时发生。

### USDG、USDG0 与全天候 settlement

Andy：聊天室有人问 USDG 和 USDG0 的区别。USDG0 是 LayerZero 版本，设计目标是在 Paxos 没有原生支持的链上实现 cross-chain。USDG 则在 Solana、Ethereum、Robinhood Chain 和其他网络提供 native support。USDG0 的核心优势是更广泛的跨链可用性。

Andy：Robinhood Chain 上不少 stock pairs 使用 USDG，Uniswap V4 hooks 也允许设计新的 liquidity pool。周末股票的 tokenized price 经常相对周五收盘价出现脱节，周一开盘又回到另一个水平。24/7 交易下，USDG 如何处理非 24/7 市场的周末 settlement？

Guillaume：任何时候都可以直接把 USDG 拿到 Paxos，一比一兑换成 USD，这是监管要求。无论链上的市场价格怎样变化，Paxos 都提供无费用的一比一兑换。至于某些 tokenized equity 资产的 24 小时流动性，交易者需要意识到市场深度可能很薄，执行订单时可能出现 slippage。但 USDG 这一侧始终对应一个美元。

Guillaume：PAXG 也有类似现象。Gold 是对全球事件非常敏感的资产。当伦敦 gold hours 或其他传统黄金市场没有交易时，PAXG 会成为参考价格。最近的研究显示，周一开盘价和周日链上价格之间的差异正在缩小，因为 PAXG 的交易量在过去六个月增长了大约四倍甚至更多。

Guillaume：部分原因是 gold price 相对 crypto price 的变化。Gold 一度接近每盎司 55,000 美元，表现很强，而 crypto assets 的表现较弱，所以一部分 stablecoin 或 crypto asset 资金流向 PAXG。世界上任何国家发生军事行动，都可能推高 gold。随着更多资产、现金和交易活动转向 24/7，这些价格差异会逐渐收窄，但这需要很长时间。传统金融基础设施也在往 24-hour market 发展。

### Stablecoin、美国国债与宏观机制

Andy：美国长端债券收益率很高。Scott Bessent 正在购买 long-dated bonds，试图抑制收益率曲线长端陡峭化。30 年期收益率超过 5.2%，10 年期超过 4.7%。根据 Genius Act，stablecoin issuer 必须持有到期日不超过 93 天的短期 Treasury bills。如果 Bessent 能在一到两年内让 stablecoin issuance 爆发，稳定币发行方就会产生大量短期 T-bill 需求，财政部可以借此支持短端，同时继续操作长端。

Andy：所以 stablecoin 已经从 crypto 产品变成美国国家经济安全项目。牛市会带来更多交易、借贷、settlement 和 issuance，推动 stablecoin demand 增长。美国政府有动力通过 stablecoin 延伸美元在全球的 hegemonic role。其他国家也可能借 stablecoin 延伸自己的货币和短期债务需求。

Guillaume：美国确实领先，stablecoin issuer 本来就是美国债务的重要持有者。Paxos 在 Genius Act 之前也一直被要求用非常短期限的 Treasury 作为 underlying asset。关键在于，underlying asset 产生的收益能够激励 Global Dollar Network participants 使用和持有 stablecoin。

Guillaume：这是一场平衡游戏。收益必须足够吸引人，让参与者持有 tokenized dollar 而不是兑换回 fiat。市场现在讨论 yield sharing，问题就是怎样激励用户使用 tokenized dollar。Paxos 对这一趋势非常兴奋，但也要注意，当前 USD stablecoin 总量大约 3,000 亿美元，相对于美元在全球经济中的规模仍然很小。

Guillaume：我们更期待看到真正管理数万亿美元的金融机构使用 stablecoin rails，提高效率，而不只是依靠 crypto bull run。牛市当然会带来 demand，但机构采用才会带来更稳定的使用量。只要大机构开始用 stablecoin 处理 payments、settlement 和 treasury movement，增长就会更具结构性。

Guillaume：Paxos 过去 14 年一直在监管框架内建设。PAXG 是把 gold 变成可以由任何 wallet 访问的 24/7 资产，USDP 与 PYUSD 体现了 stablecoin 发行经验。获得美国 CA1 license 后，Paxos 可以参与 securities clearing，这意味着我们可以在 tokenization、清算和结算的连接处提供基础设施。具体产品和资产范围仍然需要进一步决定。

Guillaume：USDG 必须能够被兑换回美元。无论某个周末链上 pool 的报价是高还是低，持有人都可以按监管要求与 Paxos 一比一兑换，且不收兑换费。需要区分的是，USDG 的一比一兑换能力，不会自动消除 tokenized equity 的价格风险。股票 token 的流动性可能很薄，周末可能没有真实股票市场作对手方，交易者依然会承受 slippage 和 price impact。

Guillaume：PAXG 的价格发现说明了 24/7 资产为什么有价值。在传统 gold market 休市时，链上的 PAXG 会先反映全球事件，等传统市场重新开盘后，两个价格再逐渐趋于一致。随着交易量增长，周日和周一之间的差异可能缩小，但不会在一夜之间消失。流动性需要时间积累，市场参与者也需要建立套利与风险控制流程。

Guillaume：Global Dollar Network 的 rewards 不是简单地把利息直接发给每个个人，而是从 reserves 产生的 revenue 中向 network members 进行分配。成员包括 OKX、Robinhood 及其他机构 partner。利率变化会影响 reserves 的收入，但 activity、minting、movement 和 acceptance 也同样重要。即使一部分 USDG 不由 network member custody，underlying reserves 仍能产生收入，相关价值可以通过 rewards 结构重新分配。

Guillaume：如果利率下降，储备资产的回报可能下降，但风险资产和链上活动也可能重新变得有吸引力，更多人会寻找其他 yield，stablecoin 的 movement 可能增加。反过来，如果利率很高，储备收入更高，但用户也可能更愿意直接持有短期无风险资产。stablecoin 的 adoption 不能只看利率，还要看支付、跨境结算、交易所流动性与机构使用场景。

Guillaume：当前全球 USD stablecoin 规模大约 3,000 亿美元，相对于全球美元体系仍然很小。真正的结构性增长，需要管理数万亿美元的金融机构把 stablecoin rails 用在 payment、treasury、settlement 和资产交互上。crypto bull market 会提高交易需求，但机构使用会让市场不必完全依赖情绪和价格上涨。美国与其他国家都在重新评估 stablecoin 对货币、债务和金融基础设施的意义。

### 末段市场细节补充

Andy：Lighter 的收入设计值得单独说明。它保留 retail trader 喜欢的 zero-fee standard trading，同时把 advanced order types、higher API limits 和更复杂的服务放进付费账户。Standard、Plus、Premium 形成分层，lit staking 还会对应不同折扣。这样可以在不直接破坏免费交易体验的前提下，向更高频、更复杂的用户收费，并增加 token buyback 的资金来源。

Andy：Lighter 对 integrations 收取约 0.5 basis point 的最低 protocol fee，而其他竞争者可能在 3 到 4.5 basis points。对于把 Lighter 放在后台的 partner，低费用可以提高整合意愿，收益留存也可能增加。这个策略需要持续验证真实交易量、用户留存、手续费收入和 token 价值捕获，不能只看公告中的费率设计。

主持人：我们还提到 1inch Aqua 的 shared liquidity。用户可以让一个 wallet balance 同时支持多个 positions、pairs、ranges 和 chains，不需要把 token 分散到多个地方，也不等于使用 leverage。对流动性提供者来说，资本利用率可能提升；对用户来说，跨链交易体验可能改善，但 smart contract、pool、清算和价格风险仍然存在。

Andy：Robinhood Chain 的 24/7 stock token 让美国以外的用户可以接触美国股票敞口，但“获得 exposure”不能自动等同于“拥有完整股东权利”。大家需要检查发行实体、底层股票的托管方式、赎回方式、投票和分红安排。节目中关于 90 个增长到 190 个、120 多个国家和全天候交易的讨论，描述的是产品方向，不是对每一个 token 的权利作统一保证。

主持人：周末的 AMC 与 MicroStrategy 价格例子，说明了市场开盘时间错位和链上低流动性如何产生剧烈波动。某个 market maker 可以在传统市场恢复交易后铸造 token，并以套利方式把价格拉回去。流动性池可能提供很高的 APY 或 APR 来吸引 capital，但高收益往往对应高风险、低深度、合约风险和价格损失，不能把收益率直接当成确定回报。

Robbie：我们持有或讨论的 HYPE、Zcash、Bitcoin、Pump、Lighter、NEAR、Purr、Plume、FRA、Zama、SOL、ETH、LINK、VVV 与 Aerodrome，都属于节目当天的市场观察或主持人披露。主持人的目标价、月线形态和仓位判断是个人观点，不能替代独立研究。尤其是“保证上涨”“written in the stars”“10x”之类的表达，属于直播气氛和叙事，不是已验证的收益承诺。

Andy：我们在节目结束时说市场可能处在 pre-bull phase，也提到 crypto-native capital、高净值个人、机构配置者和 retail 可能按顺序进入。这是一个市场参与者分层的叙事框架，不是已确认的资金流预测。任何真正的交易决策，都要额外核实发布时间、价格、流动性、持仓、法律权利、税务、托管、协议收入与退出路径。

Andy：再把 Base 与 Robinhood 的差异说清楚。Robinhood Chain 先把很多不同的 asset names 带到链上，因此在 breadth 上有先发优势。Base 的产品更强调真实股票、深 liquidity 和合规的 ownership structure。一个平台可以拥有更多可交易名称，但每个名称的 pool 可能很浅；另一个平台名称少一些，但可以把 volume 集中到少数 pool。交易者不能把资产数量直接当成市场质量。

Robbie：流动性也会随着价格发现地点改变。周末传统交易所休市时，链上 venues 可能成为更早的 price discovery venue。如果某个 venue 的价格先形成，其他 venue 的交易者和 market maker 可能跟随，流动性会进一步集中到那里。这样会形成 self-fulfilling liquidity loop，但也会放大薄市场中的错误报价、抢跑、滑点和套利冲击。

Antonio：对 Base 来说，最终用户不一定知道自己在用哪条 chain。用户只想进入一个 app，持有股票、赚取收益、借款、付款或者参与一个组合。资产提供方、middleware、bridge、oracle 和 settlement provider 仍然重要，只是它们不再直接出现在用户界面中。产品之间的竞争会从 bare metal chain 转向资产选择、合规保证、交易深度、融资能力、分发和用户体验。

Antonio：在一个真正的 portfolio margin 体系里，用户可以把不同资产放到一起评估风险，并用一个资产支持另一个交易。传统 prime brokerage 为机构客户提供这种服务，但普通投资者往往无法将自己的股票、预测市场仓位和 crypto 统一抵押。链上 composability 提供了技术可能性，但风险引擎、清算规则、法律隔离和托管责任必须同步建立，不能只因为 token 可以组合就忽略金融风险。

Guillaume：同样，对 Paxos 而言，tokenization 不是只做一个漂亮的 token。每一个产品都涉及 underlying asset、reserve、mint、burn、redemption、clearing、settlement、compliance、market access 和 partner economics。PAXG 让 gold 在传统市场之外也能被持有和交易，但这不意味着 gold 的价格风险消失。USDG 能够一比一兑换美元，也不意味着某个与 USDG 配对的股票 token 没有价格或流动性风险。

Guillaume：Paxos 与监管机构长期合作，是为了让这些边界在产品推出之前就被定义。机构愿意使用链上 rails 的前提，是知道谁托管底层资产、谁负责清算、发生错误时谁有义务处理，以及在市场关闭时如何管理价格。CA1 license 让 Paxos 可以更深入地参与 securities clearing，但具体产品仍要按战略与监管要求推进。

Andy：当银行推出自己的 stablecoin 时，它们需要考虑的不只是品牌和发行。stablecoin 必须在银行自己的生态以外获得流动性，必须被交易所、支付商、钱包和跨境使用者接受，也必须有清晰的 reserve 与 redemption。Paxos 的 Global Dollar Network 试图把发行、监管、分发和收益分享连接起来，这比单纯铸造一个 token 更复杂，也更接近真正的金融基础设施。

Guillaume：在利率高的时候，短期 Treasury reserves 可以产生更多 revenue，但如果用户只为了 yield 持有稳定币，一旦外部收益更高，资金可能重新流动。在利率低的时候，reserve revenue 可能下降，但支付和链上活动可能增加。长期采用取决于成本、速度、结算时间、跨境便利性、可编程性和合规，而不是只看某一时点的利率。

主持人：因此，tokenization super cycle 的核心并不只是“把股票放到区块链上”。它包括资产的合法性、真实所有权、价格发现、全天候市场、稳定币结算、借贷、组合、清算、归因与分发。meme coin pairing 是早期实验，PAXG 和 stablecoin 是已经运行的产品，Base 的 B20 与 Coinbase 的资产体系处在中间建设阶段。不同阶段不能混为一谈。

主持人：最后再提醒一次，节目里展示的收益、P&L、APY、APR、目标价和“bullish”表达，都是当天直播中的主持人观点或交易者案例。它们不能证明未来回报，也不能消除价格脱节、智能合约、托管、监管、税务、清算和流动性风险。我们提供的是节目完整语境，读者仍需对任何交易和资产权利做独立验证。

Andy：今天的完整讨论还可以压缩成一条清晰的传导链：更多现实资产被 tokenized，链上需要更多稳定币来结算；更多稳定币带来更多 payments、交易和借贷；更多交易会增加 liquidity、fees 和对 market makers 的需求；当链上资产获得真实所有权、清算和监管支持后，股票、黄金、商品和 crypto 就能在同一个可组合的金融系统中运行。每个环节都可能成为瓶颈，任何一个环节没有流动性、合规或可赎回机制，资产的价格发现和使用都会受到限制。
