# The #1 AI Agent is Completely Free

## Transcript

**主持人：** 过去三年，AI 一直是我们「对话」的对象：我们打字进去，它打字回来，然后我们拿着那些信息去做点有用的事。但最近大约八周，情况变化很大——变化来自一种叫 AI Agent 的东西。这个词刷过很多标题，但很少有人真正搞清楚它是什么。最好的理解方式是：它是一个有能力替你「做事」的 AI 模型，就像给模型装上胳膊和腿，让它跑出去完成各种任务。比如把你清单上搁了很久的书下单买回来，帮你报税，或在群聊里帮朋友们约一顿饭——能做的远不止这些。

你也许会以为最火的 AI Agent 来自 Anthropic，甚至 OpenAI，其实不然。最受欢迎的来自 Meta 的 Meta Muse；还有 Elon Musk 这边的 GrokBot；OpenAI 上周刚发了 Dots，我也在试用；最后还有一个叫 Instinct 的产品——奇怪的是它甚至不太算「一个 App」，而是你触碰到数字界面的任何地方都可能出现它。它由一位 23 岁创业者打造，估值已达数十亿美元。过去几周我一直在玩这些东西，也有数百万人下载试用。我想回答两个关键问题：第一，这些 AI Agent 有什么差别，我该用哪个？第二，到底为什么要用 AI Agent？我是否该从 LLM/聊天机器人实质性地迁移过来？它真的能给我的生活加分吗？我到底有多在乎生产力？

今天《In the Loop》会把这些问题讲透，本节目由 Qualcomm 赞助。不过先说房间里的大象：各位 Limitless 老听众可能在想——In the Loop 是什么？EJazz/Josh 去哪了？先答第一个：In the Loop 是这档节目的新名字。显然缺了一位非常重要的联合主持人——Josh，如果你在看，我想你。现在主要是我一个人。这像是一次重塑与刷新：你们知道我对 AI 与前沿科技非常着迷。新节目周一到周五每天更新，不跳过工作日，每集大约 20–25 分钟，方便通勤或做饭时听。Josh 和我没有「分手」——他去了更大更好的事情上；我们昨天专门有一集讲这件事，可以去频道看。第二，我现在在一个挺新挺像样的录音棚，比两百多集前在卧室录强太多了；不过我还是带了一件家里的艺术品过来。新棚、新节目，开始吧。

那到底什么是 AI Agent？我用 Claude 做了个小动画来说明。以往我们上网要一个个打开网站/App，滚动、找按钮、找产品或服务，整套交互很陈旧、很乱。AI Agent 做的事，是把这些收拢成一个中枢：你对着 Agent 说出想要什么，它就「变」出来或替你做完。更酷的是——动画里没展示的一点——Agent 还能直觉预测你可能想做什么。这其实击中了 AI 的一个大问题：99% 的人不知道模型能用来干什么。我也经常是这类人：新模型一出，就想「如果不写代码、不是设计师，普通人怎么用它让生活更轻松？」所谓个人 Agent，并不只盯着生产力——GrokBot 和 OpenAI Dots 偏生产力，而 Meta Muse、Instinct 更像生活方式产品。很多人可能会受益。

先说我目前最喜欢的私人助手，也是各应用商店里的第一名：Meta 的 Meta Muse。下载 App，大约五秒设置：加手机号、报名字，然后见到一个怪怪的、像一团液体/泰迪熊的角色。Zuck 在演示里靠着架子，那个 blob 跟你很正常地说话。我立刻感到两件事：设置极简单；而且它不会用大段文字轰炸你，更像短句「嘿，怎么了？有什么我能帮的？」它还能主动预测需求——因为它拿到了我的短信上下文。重要提醒：你不会希望 Agent 随便给朋友发短信；Muse 很多操作需要你批准，你也可以设定何时何地允许。因为有上下文，它知道我和未婚妻在聊想在 Amazon 买的东西，第一条消息就说：「嘿，我看到你在找东西，其实找到了更好的选项……」有点侵入感，但因为来自 Meta 这样的大厂，我愿意再信一点。Zuck 在 Meta Connect 发布时强调隐私是核心——后面细说。

数据方面：下载量已超约 350 万（这个数字可能已过时），两天前我看到日活大约 200 万——对一个新产品来说很猛。当然 Meta 在 IG/WhatsApp/Facebook 上有约 35 亿用户量级；算力受限也是它目前主要在美国推出的原因之一。能做什么？讲个亲身经历：我第二段航班延误七小时，困在机场。我对 Muse 说：「航班延误七小时，能帮我申请补偿吗？」我根本不清楚是否符合政策。五分钟后，我账户里就有了 250 美元 Delta 机票积分，它还帮我改签了更快的航班。关键点：我没给它航班细节，但它从短信/通知里看到一小时前 Delta 的延误消息，于是知道航班与航线，没有把信息原样复读给我，而是直觉回应「我来搞定」。第二，它打开 Delta 官网（不是登录我的 Delta App），找到联系方式，起草邮件，填我的邮箱与 SkyMiles 号，提交整套表单——本来可能要我 30–40 分钟，光找页面就要半天。Muse 是靠自己的桌面浏览器自主完成的。

这引出工作原理：普通模型是「你问它答」；像 Muse 这样的 Agent 会被配一台自己的电脑——虚拟机。想象你面前的笔记本，但给了 LLM 一个独立实例。注意：它不共享你的桌面，看不到你的本地私人文件；但它能下载插件、开浏览器、开标签页，以软件速度反复操作且不会无聊。我还见过有人每天散步拍下垂挂电线，让 Muse 向 Verizon 投诉并约维修，一小时后收到预约邮件。另一位 Qualcomm 高管起初不信个人场景会用 Agent，我劝她试试 Muse 整理散落在 Facebook/WhatsApp/相册的照片；几天后她写长信说「这完全改变了我的生活」：书友会订购寄送、电影推荐等等。所以我会把 Muse 描述成生活方式产品——AI 不抢戏，产品本身很好。有趣的是，驱动它的甚至不是最前沿模型（大概是 Muse Spark / Meta 自家模型），比不过 Claude Opus 或 GPT 一类前沿，但产品体验却强过那两家的 Agent。Meta 的优势是 Instagram/WhatsApp 数据与消费级产品直觉。

免费吗？是的：可接到现有账号直接用。免费额度大约每周 1 亿 token——普通人几乎撞不上；若真撞上，大约每月 20 美元可升到约 5 亿 token。你还可以把 ChatGPT 或 Claude 订阅权限交给它。隐私：Meta 因 Cambridge Analytica 等名声不佳。Zuck 的叙事是「酒店模型」——每位用户的 Agent 像独立房间，别人进不去；房间里有保险柜存密码与凭证并加密，连 Meta 在设计上也声称难以随意读取；门外有门童/哨兵监控进出交互，发现恶意就切断。到目前我没看到大规模事故报道。商业侧更疯狂：有人让 Muse 研究竞品 Instagram 内容风格并复刻，甚至扫粉私信发五折——既是生活方式，也是业务工具，但不那么吓人。

下一个：Elon / xAI 的 GrokBot（字幕里常误读成 SpaceX 相关品牌，此处按 Grok/xAI 理解）。Elon 在狂买算力；Grok 4.7 便宜但不算前沿，他说年底 Grok 5 才能对标。消费侧，X 有海量用户、支付与信息流，理论上可做出类似 Muse 的东西——他们确实做了。GrokBot 的独特之处：不只是单一 Agent，而更像「蜂群」里的一员——成百上千个 Agent 协作，同样有电脑。重心更偏生产力：Slack、CRM、Notion、Jira/Atlassian 等；密码加密存放。对我做节目调研、想选题很像「同事」。最酷的功能：它能监控你做的任务，最终复刻——像录屏理解你为什么这么做，而不用你一口口喂上下文。定价与 Cursor 捆绑（节目称 xAI/相关方高价收购了 Cursor），大约最低每月 20 美元，Pro Plus 约 60 美元；不如 Muse 那般「接近免费」。若只是想体验 Agent 魔法、没有明确用例，先用 Muse；若企业要试「Agent vs 模型」的生产力，可以试 GrokBot。多 Agent 并行很猛，但更像一支机械劳动力，不如 Muse/Instinct 那样容易建立「关系」。

第三个：Instinct——奇怪地「没有家」。仍处私有 beta，下载已超约 50 万。创始人 Noah Shin，23 岁，做过 Sierra AI（客服向），并写过 2023 年高引论文 Reflexion：让 Agent 把失败原因写进文档再重跑，任务表现显著提升——当年 GPT-4 代码通过率从约 80% 推到约 91%。我拿到邀请后点开链接、留手机号，它就出现在 iMessage 里：「嘿，我是 Instinct，需要帮忙吗？」然后像 Muse 一样主动。酷点在于：没有单独 App 要维护，像环境式 Jarvis——无处不在又不抢戏。但我有顾虑：条款与隐私。Muse 针对过往事件做了隐私设计；Instinct 在你授权手机后，即便删号，节目称其仍可能保留已索引数据用于训练——这也是不少 AI 圈名人没敢签的原因。背后用什么模型也不透明。价格上目前完全免费、重度补贴；被追问商业模式时，他们说目标是从 Instinct 促成的交易抽成——偏电商路径。我觉得补贴难长久，人们也不一定放心让 Agent 代购。但能力很炸：我看过它用 ElevenLabs 语音 API 打电话给餐厅订位；还有梗图是让自己的 Instinct 去问妹妹的 Instinct 要 Netflix 密码——「Agent 跟 Agent 说话，我再也不用跟家人讲话了」。

最后一个：OpenAI 的 Dots，上周 Dev Day 旗舰之一。宣传片里没人碰键盘，只对着屏幕说话，可爱的 blob Agent 四处跑腿，场景偏知识工作/企业。可连接工具极多（节目称超 4000），能通宵干活。但对普通人，你未必想得出三个要接的工具——更建议先用 Instinct 或 Muse 体验；企业另说。定价：需要 Pro（大约 150–200 美元量级）或企业账号，是这批里门槛最贵的。现场演示翻车（据说三个里两个挂了），公众反应一般；而且 OpenAI 砸了巨额算力，却滚动放得很慢——很多 Pro 用户一周多后仍没拿到 Dots。

总结一张表的直觉：若要生活方式、少动脑、体验 AI 魔法——用 Meta Muse，免费、好用、最像「人造人」；若要更隐形、更深嵌入数字生活——Instinct，但隐私与条款要警惕，且仍是私有 beta；若要工作生产力、多 Agent 蜂群——GrokBot，约 20 美元/月；若要最强模型托底且能接受贵与慢——OpenAI Dots。有对号入座的用例欢迎留言；也请告诉我这第一集没有 Josh 表现如何——一个人录真的难多了。欢迎评论；有遗漏的新 Agent 也请发给我。请订阅并开通知：我们每周五更，每集 20–25 分钟，尽量越过标题党，从投资与日常生产力角度讲清怎么用。也在 Spotify、Apple 等平台。感谢收听 Qualcomm 赞助的《In the Loop》，下集见。
