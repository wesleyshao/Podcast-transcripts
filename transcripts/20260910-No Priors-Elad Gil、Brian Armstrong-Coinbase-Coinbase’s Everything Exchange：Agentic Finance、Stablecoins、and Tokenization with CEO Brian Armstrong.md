# Coinbase 的 Everything Exchange、Agentic Finance 与 New Limit

## 访谈摘要

这是 No Priors 对 Coinbase 联合创始人兼 CEO Brian Armstrong 的访谈。对 Coinbase 的部分，核心讨论围绕三个方向展开：把多类资产放到同一个链上交易入口的 **Everything Exchange**；把稳定币变成全球支付层；以及让 AI agent 具备账户、钱包和支付能力的 **agentic finance**。访谈后半段转向 Brian 参与创建的 New Limit，讨论用 AI 加速表观遗传重编程和长寿研究。

## Coinbase 的三条产品主线

**Brian：** Coinbase 正处于重要阶段。一方面，各类资产正在上链，用户有机会在一个地方交易股票、商品、加密资产、衍生品、永续合约和预测市场；另一方面，稳定币支付增长很快，即使比特币价格下跌，稳定币支付仍在增长。第三条主线是 AI 对金融服务的改变，公司将其称为 agentic finance 或 AI fi。

### Everything Exchange

Brian 把 Everything Exchange 描述为 Coinbase 的核心业务方向：各种资产都可以在一个入口交易，具备流动性和交叉保证金，用户不必在多个彼此割裂的平台之间搬运资产。预测市场也被视为交易入口的一部分。随着更多国家出现监管清晰度，这种“一处交易多类资产”的模式可能覆盖更广的用户。

他同时强调，加密技术正在更新金融系统的各个部分，不应只把 Coinbase 看作比特币交易平台。访谈中提到，公司近期披露的一个口径是，Coinbase 收入中约 88% 已来自非比特币交易；主持人和嘉宾都提醒，这个数字需要以正式财报和具体定义为准，不能直接推导公司已经脱离加密市场周期。

### 稳定币支付

Brian 认为稳定币能够提供快速、低成本、全球化的支付层，理想状态是资金以接近信息传输的速度移动，跨境转账成本低于传统支付网络。Coinbase 正帮助全球企业接入稳定币支付，Coinbase Business 同时面向人类客户和未来的 agent 客户。

稳定币的意义不只是把美元换一种形式。它把银行账户中的美元或美国国债以一比一映射的代币形式放到可编程网络上，使支付、结算、持有和转账能够通过软件完成。Brian 认为，稳定币是资产代币化较早形成规模的用例，未来私人信贷、国债、银行存款和更多金融资产都可能被代币化。

## Agentic Finance：给 AI agent 一个金融身份

### AI advisor

Coinbase 已在产品中推出 AI advisor 的方向。Brian 的设想是，过去只有高净值客户能获得投资顾问，未来普通用户也可以用自然语言与 AI advisor 交流，让它协助理解投资组合、定投、税收损失收割、闲置现金收益和市场下跌时的分批配置。用户可以像和人对话一样提出需求，由系统执行相应的投资服务。

这里的关键并不是把“聊天”加到交易应用，而是把 AI 变成能够持续管理金融任务的接口。若市场下跌 5%、10% 或 15%，agent 可以依据预先设定的组合规则分批行动；闲置资金也可以按照授权规则获得收益。Brian 以“愿景”表述这些能力，实际可用边界、风险控制和监管责任仍需单独验证。

### AI agent 自己的账户和钱包

Brian 使用了一个很直接的表达：不希望 AI 被排除在金融体系之外，希望“给 AI 提供银行服务”。AI agent 没有政府身份证件，通常也无法像人一样完成传统银行开户，因此 Coinbase 正探索让 agent 通过一个命令获得自己的金融账户或自托管钱包。

访谈提到两种账户层级：第一种是与人类用户身份关联、资金隔离的 agentic account。用户可以只给 agent 一笔限定资金，让它代表自己进行交易或支付；第二种是面向任何 AI agent 的自托管钱包，agent 可以持有稳定币余额，甚至在未来筹资或发行代币。前者适合“代理人代表用户行动”，后者更接近具有独立经济活动能力的软件主体。

这解决的是当前 agent 经常卡住的支付问题。agent 在执行任务时可能遇到付费墙、AWS 资源账单、酒店预订或其他信用卡输入，传统网页要求人类在最后一步介入。若 agent 自己拥有支出账户，就可以按照预算和权限直接完成小额支付。为兼容现有商户，未来可能需要稳定币支持的信用卡；在原生 agent 交易中，则更适合使用机器可调用的支付协议。

### X402 与 agentic marketplace

Coinbase 参与孵化了 X402，并将其放入 Linux Foundation，Google、Cloudflare、AWS 等公司也在参与相关生态。X402 的设想是让 API、数据服务和软件工具能够用机器可读方式收取小额支付，而不要求人类每次手动填写信用卡。

Brian 提到 agentic.market，用来展示新型 agent 支付经济中的交易数量和服务提供者。典型交易可能是一个 agent 向另一个专门 agent 请求搜索、金融数据、招聘数据或其他工具调用。未来的 agent 市场未必由少数通用大模型包办，针对合规审核、设计、点餐、金融信息等垂直任务训练的小模型，可能凭借企业专有数据和强化学习超过通用前沿模型。

### 为什么小额支付需要加密支付轨道

传统借记卡或信用卡通常有约 30 美分的固定最低费用，再加上按比例收取的费用。因此用卡支付一美分没有经济意义。Brian 引用的口径是，约 76% 的 agentic commerce 交易金额低于 30 美分，主要包括检索资料、汇总付费数据、从 LinkedIn 等平台获取信息，或 agent 之间的工具调用。

这解释了为什么 agentic finance 不只是“把信用卡 API 接给机器人”。机器之间的大量交易金额很小、频率很高、需要自动结算，固定人工验证和传统收单费率都会成为瓶颈。稳定币和链上支付轨道的潜在优势，是让小额、跨境、机器对机器的结算变得可行。

Brian 还提出，未来 agent 数量可能超过人类，agentic economy 的总规模也可能超过只围绕人类劳动和消费的经济活动。这个判断是对长期趋势的推演，不是对 Coinbase 未来收入的承诺。

## 加密资产、稀缺性与 AI

主持人问到，未来 agent 交易会使用多少加密资产、多少传统金融轨道。Brian 认为，AI 和机器人可能使商品、食品和住房更便宜，但稀缺性不会消失。土地、能源、芯片和可用计算资源仍然稀缺，因此社会仍需要某种交换媒介。

他不同意“未来完全不需要货币”的简单表述，但承认在极限情形下，人类可能更多用能量、物质和资源计量经济活动。对较长时期而言，他认为加密支付轨道适合为 AI 提供金融基础设施：它可以被软件直接调用，能够跨境，且不需要每个 agent 先获得传统银行身份。

## 代币化股票与金融系统重构

Coinbase 正在美国以外市场推出代币化股票产品，并与 SEC 等机构讨论未来在美国开展的路径。Brian 将其描述为真正的 tokenized stock，而不是合成资产、衍生品或债务工具：代币与托管中的真实股票一比一对应。

他的长期判断是，世界上有大量人没有券商账户或美国投资账户，却希望持有高质量投资标的。若股票、国债、私人信贷和银行存款都能以代币形式存在，用户可以在同一个 Everything Exchange 中交易和转移资产，甚至直接把一股股票发送给亲属，而不必走传统股票过户流程。

主持人指出，代币化会改变全球资本流动，让过去因券商、托管和市场地域限制无法参与的人获得更多投资入口。双方也承认，房地产代币化等方向可能曾经过早，监管、法律所有权、托管和流动性仍是需要解决的实际问题。

## 预测市场

Brian 对预测市场持积极态度。他提到，预测市场在 Coinbase app 内增长很快，发布后数月内达到约 1 亿美元年化收入运行率，并保持超过 100% 的季度环比增长；具体数字需要回看公司正式业绩材料。

他认为预测市场不应只被理解为体育和政治竞猜。它可以用于评估政策效果，例如一项政策实施后一年、两年或三年的失业率；也可以用于聚合对科学、社会和长期问题的判断。即使某些问题没有明确的最终结算日期，市场价格仍可能反映新论文、突发事件或社会认知变化带来的概率调整。

预测市场的价值在于把分散的信息、判断和资金激励放在同一个价格机制中，但它也会面临监管、操纵、结算标准、流动性和事件定义等问题。访谈主要表达产品和社会机制层面的看法，没有提供完整的风险控制方案。

## New Limit：AI 加速长寿研究

访谈后半部分讨论 Brian 参与创建的 New Limit。Brian 认为，太空、AI、聚变能源和脑机接口等领域已有许多优秀团队，而长寿领域当时仍有大量“像蛇油一样”的说法，存在真正值得用工程和生物学方法验证、但融资不足的方向。

在与科学家和创业者多次晚餐讨论后，他关注到表观遗传重编程。相关研究尝试通过改变转录因子，让细胞恢复一部分年轻时的功能，而不是简单把细胞变成另一种细胞。Brian 将这段过程类比为自己早期理解比特币时的状态：一个问题不断占据注意力，促使他在热情消退前采取行动。

New Limit 的团队包括 Jacob Kimmel、Blake Byers、Greg Johnson 等人。Brian 负责早期投资和公司建设支持，但强调自己在 Coinbase 是全职 CEO，在 New Limit 更接近投资人和董事会成员。他也提醒，创业者不应过早同时经营多家公司，分心可能对主业不负责任。

## New Limit 的技术路线

Brian 介绍，New Limit 在南旧金山设有约 50 至 60 人的实验室。研究从 AI 开始：团队需要在巨大的转录因子组合空间中搜索，预测哪些组合可能重编程特定细胞。AI 模型负责提出下一批实验假设，实验室则通过大规模 pooled screens 移动原子和液体，测试细胞是否出现目标表型。

筛选出的候选物会进入功能实验，通常先用动物模型观察，再考虑人体临床试验。Brian 说，公司已经在 humanized mouse models 中证明至少一种人类细胞类型的成功重编程，并在非人灵长类动物中继续测试；他预计第一项一期临床试验将在下一年启动，未来几年平台可能产生 3 到 10 个其他候选药物。这些都是访谈时点的管理层计划，需以监管批准和后续披露为准。

这一路线体现了“AI 加速实验，而不是 AI 取代实验室”的模式。模型可以缩小假设空间、安排下一轮实验，但安全性、递送方式、剂量、长期副作用和临床有效性仍必须通过生物实验和人体试验验证。长寿研究尤其不能把细胞层面的重编程结果直接等同于人类寿命延长。

## 关于人类认知与进化的延伸讨论

Brian 还谈到一个尚未形成具体创业方案的方向：认知增强。他认为，营养、治疗和遗传相关技术可能影响儿童发育、成人认知、胚胎疾病预防等问题，但这些议题涉及伦理、平等、风险和社会接受度，不能简单当作产品机会。

主持人将其总结为“如何提高人类集体智能”。Brian 认为，人类正与 AI 进行一场智能进步的竞赛，未来可能同时存在生物增强、数字 AI 和脑机接口三条路径。即使 AI agent 数量超过人类，人类仍需要改善健康、认知和下一代的疾病负担。

他提到的可能方向包括更健康、更长寿、减少慢性疼痛、提升精力，以及通过疾病预防改善后代健康。涉及胚胎编辑等话题时，他承认这具有争议性，并强调应把疾病预防与“设计人类”区分开来；访谈没有形成可执行的政策主张。

## 结论与重要验证点

这期访谈对 Coinbase 的核心理念可以概括为：加密网络先把资产和支付变成可编程对象，再把 AI agent 变成具有账户、钱包、预算和支付能力的软件经济主体。Everything Exchange、稳定币支付、X402、代币化股票和预测市场，是同一条“金融基础设施软件化”路线的不同产品层。

对 Coinbase 的产品判断，后续最值得跟踪的是：agent 账户是否真的产生留存和支付量；小额机器支付是否在 X402 等协议上形成规模；稳定币支付是否从加密行业扩展到主流企业；代币化股票能否获得更广泛监管许可；预测市场收入和增长是否经得住正式财报核验。

对 New Limit 的判断，关键不是 AI 模型是否先进，而是候选重编程方案能否通过动物模型、临床安全性和有效性验证，最终形成经批准的药物。访谈提供的是创始人对技术和公司路线的解释，不足以证明 Coinbase 已经获得这些新业务的收入，也不足以证明 New Limit 的候选药物一定成功。

### 开场：为什么把 Coinbase、AI 和生物技术放在一起

Elad Gil 介绍 Brian Armstrong 时，先强调他既是 Coinbase 的联合创始人和 CEO，也参与了 New Limit 这家长寿生物技术公司。主持人希望把加密货币、AI、金融服务、生物学以及个人如何对社会产生长期影响放在同一场对话中。这个开场很重要，因为 Brian 的回答并没有把 Coinbase 只解释成一个交易应用，而是把它放在更大的“软件、资本和科学基础设施”框架里。

Brian 对 Coinbase 的第一层描述是，越来越多资产正在上链，交易者可以在一个地方接触股票、商品、加密资产、永续合约和其他衍生品。所谓 Everything Exchange，并不只是增加一个新的币种页面，而是希望把过去分散在股票券商、商品平台、期货平台和预测市场中的交易活动，放到具有共同流动性、保证金和结算机制的入口内。

他认为监管清晰度会影响这条路线的扩张速度。如果不同国家允许更多链上资产和支付产品，统一入口的价值会更明显；如果某些市场仍要求资产、托管和支付彼此隔离，产品就只能按地区分别推进。访谈没有给出各国具体批准清单，因此这里更适合视为公司战略叙事，而不是现状覆盖范围的确认。

### 稳定币为何比币价更重要

主持人注意到，即使比特币价格走弱，稳定币支付仍在增长。Brian 的解释是，稳定币的用途不必依赖投机交易，它可以充当跨境结算、企业收款、美元储值和软件调用的支付工具。对使用者而言，最重要的属性是速度、费用和全球可达性，而不是代币本身的价格上涨。

Brian 给出的理想化口径是，资金能够在不到一秒的时间里转移，成本低于一美分。他把这种体验比作信息通过互联网发送：用户不应因为所在国家、银行营业时间或传统清算链条而等待很久。实际成本会取决于链、钱包、兑换、合规和商户接入，因此这个口径不能理解为所有场景的普遍价格承诺。

Coinbase Business 的角色，是让企业能够接受稳定币支付。企业不用从头搭建钱包、清算和资产兑换系统，可以通过产品接入稳定币收款。Brian 认为，同一套企业支付入口也会逐渐接待 AI agent，因为对商户而言，付款方是人还是 agent，最终都需要验证资金、权限和交易状态。

### AI advisor 的产品逻辑

在 AI advisor 的设想中，Coinbase 并非只提供市场问答，而是让用户把部分持续性财务任务委托出去。例子包括解释投资组合、帮助用户做定期投资、判断闲置现金如何获得收益、进行税收损失收割，以及在市场大幅回撤时按照预设规则逐步配置。

Brian 以市场下跌 5%、10% 或 15% 为例，说明 agent 可以把一次性决定拆成多个阶段，减少用户在情绪压力下临时操作的需要。这种机制的好处是让投资计划更容易执行，风险是模型可能误解用户目标、超出授权、忽视税务和流动性条件，或者在异常市场中机械执行。因此 AI advisor 的核心不只是模型能力，还包括账户权限、策略约束、人工复核、审计记录和责任归属。

如果 AI advisor 真的成为金融入口，用户对 Coinbase 的依赖将从“什么时候买卖”扩展到“如何持续管理全部金融活动”。这也是 Everything Exchange 与 agentic finance 的交汇点：平台拥有资产、支付、数据和执行能力，AI 则负责把这些能力转换成用户可以用自然语言委托的工作流。

### agent 账户的两种身份模型

主持人追问，agent 的账户到底是现有 Coinbase 用户的附属账户，还是完全独立的新账户。Brian 的回答是，两种形式都需要。

第一种模型与人类身份关联。人类用户开设一个单独的 agentic account，将一笔隔离资金放入其中，并对 agent 授权。agent 可以在这个额度内交易、购买服务或付款，但不能直接动用用户的全部资产。它类似企业给员工的费用账户，也类似给个人助理一张有额度和用途限制的卡。

第二种模型是自托管钱包。一个 AI agent 可以直接持有稳定币余额，不依赖已经完成传统 KYC 的人类主账户。未来它甚至可能筹资、发行代币或向其他 agent 提供服务。这个模型更适合机器主体之间的经济活动，但也带来更复杂的责任问题：如果 agent 诈骗、误付、被攻破或违反制裁规则，谁来负责，钱包如何冻结，密钥如何恢复，都需要制度和技术配合。

传统银行账户要求政府身份证件，而 AI agent 没有身份证、没有实体，也无法走进银行网点。自托管钱包绕开了这条开户流程，但并不意味着所有监管问题自动消失。它只是把身份、权限和资金控制从银行开户表格转移到软件、密钥、协议和服务提供者的组合中。

### agent 执行任务时最容易卡在哪里

访谈举了几个具体场景。一个 agent 可能需要调用付费 API、临时启动 AWS 资源、抓取一组付费研究数据，或替用户预订酒店。它能够在网页上完成搜索和选择，却在最后一步遇到信用卡输入框。这种“最后一米”会迫使人类重新接管流程，使自动化收益大幅下降。

如果 agent 有自己的预算账户，它可以先判断这笔支出是否在授权范围内，再完成支付并把收据返回给用户。对用户而言，最重要的不是让 agent 自由花钱，而是能设置额度、品类、时间、商户、审批条件和异常报警。对商户而言，则需要确认付款可验证、可结算、不可轻易撤销或欺诈。

稳定币支持的信用卡可能是过渡方案，因为多数商户仍然接受卡网络；X402 等协议则更适合原生软件服务。前者把新型钱包接到旧有商户网络，后者让服务之间可以直接按调用次数、数据量或结果收费。未来两者可能长期并存，而不是一种支付方式完全取代另一种。

### X402 与机器对机器市场

X402 的核心想法是借鉴 HTTP 402 Payment Required，让网络服务在返回资源之前声明需要支付，并让 agent 以协议方式完成支付。这样，搜索、数据、计算、验证和内容服务都可以把价格写入机器可读的接口，而不是为每一个非人类客户设计人工注册流程。

Brian 提到，Coinbase 将这一方向放入 Linux Foundation，是希望它不只属于 Coinbase 自己。Google、Cloudflare、AWS 等参与者可以把支付能力接入自己的云、网络或 API 产品。若协议足够开放，服务提供者可以收取稳定币或其他数字资产，agent 则可以根据任务需要购买调用次数。

agentic.market 的意义更接近观察窗口。它展示哪些服务正在产生 agent 之间的支付、哪些数据和搜索服务更常被调用。随着市场成长，可能出现“专门做招聘数据的 agent”“专门做金融数据清洗的 agent”“专门做合规审查的 agent”。这些 agent 的价值取决于结果质量、响应速度、数据许可和可验证性，而不只取决于底层模型参数量。

Brian 认为，通用前沿模型在很多任务上都不错，但企业有时会用自己的十万条合规案例训练一个小型开放权重模型，使其在合规队列这一项任务上超过通用模型。由此推演，agent 市场的竞争单位可能从“谁拥有最大的模型”变成“谁在某个细分任务上拥有最好的数据、反馈和执行结果”。

### 低价值、高频率交易的经济学

信用卡的固定费用使它不适合一美分或几美分的交易。若一项搜索只值几美分，收单方仍要承担固定处理费、拒付风险、身份验证和结算成本，最终用户不会愿意支付。Brian 因此特别强调，agent 经济中的很多交易不是买一台设备，而是购买一次检索、一次数据补充、一次小工具调用。

这类交易可以发生在风投团队整理付费信息、招聘团队抓取公开或许可数据、研究 agent 向金融数据 agent 请求一个指标时。每一次调用金额很小，但数量可能极大。若支付本身比服务更贵，经济活动就无法发生；如果支付能够自动、低价、跨境结算，更多微型服务就可能被商品化。

“未来 agent 数量超过人类”的说法，放在这里并不是单纯的科幻判断，而是一个成本结构问题：软件 agent 可以同时服务多个客户、全天候调用工具，并且彼此产生大量机器交易。即使每一笔交易只有几美分，总量也可能很大。不过这仍取决于 agent 是否真正被部署、任务是否产生经济价值、支付系统是否解决欺诈与责任问题。

### 加密轨道的长期角色

主持人提到，有人认为未来不再需要货币，所有东西都可以用能量或资源表示。Brian 认为，在资源极其充足的极限世界中，这个说法可能有道理，但现实中土地、能源、芯片、计算能力和某些地理位置仍会稀缺。政府政策也可能影响通胀和相对价格，所以交换媒介不会很快消失。

他的判断不是加密资产将自动取代法定货币，而是加密 rails 对 AI 特别有用。agent 没有传统国籍和银行关系，却需要向不同国家、不同公司和其他 agent 付费。可编程钱包、稳定币和开放协议能够减少开户、清算和跨境结算障碍。对人类来说，这些 rails 已经有价值；对机器来说，可能是必需的协调层。

### Coinbase 收入结构与市场叙事

在被问到非加密交易业务占比时，Brian 引用近期业绩材料中的数字，称 Coinbase 约 88% 的收入来自非比特币交易。他同时说，比特币像数字黄金和 sound money，仍会长期存在。这里有两个层次：比特币仍可能是平台的重要资产和品牌入口，但平台收入可以来自其他资产、衍生品、支付、稳定币、托管和数据服务。

需要注意的是，“非比特币交易”不等于“完全不受比特币周期影响”。用户风险偏好、交易量、保证金、稳定币余额和平台估值仍可能与整体加密市场相关。主持人也指出，Coinbase 股价与比特币价格仍有相当相关性，因此产品扩展是业务结构变化，不是周期风险消失。

### 代币化股票的所有权表达

Brian 对 tokenized stocks 的强调点是，它不是只追踪股票价格的合成衍生品，而是由托管中的真实证券一比一支持。若这一结构在特定监管辖区成立，用户可以在链上持有并转移一个代表真实股票的代币。它的价值来自所有权记录、结算速度、可组合性和全球分发，而不只是交易界面更好看。

他以全球有数十亿人缺少美国券商或投资账户为背景，认为代币化股票可能让更多人获得美国股票和其他资产的投资入口。主持人补充，过去也有通过基金或跨境产品让投资者间接参与外国市场的方式，但这些产品仍有托管、地域、费用和资格限制。

代币化的挑战同样明确：真实资产由谁托管，代币持有人是否拥有投票权和股息权，跨境发行如何符合证券法，交易发生在什么时间，停牌和公司行动如何同步，以及代币能否在压力市场中保持流动性。访谈强调的是方向和产品愿景，没有逐项回答这些制度问题。

### 预测市场的范围扩大

Brian 对预测市场的理解比体育竞猜更宽。体育是容易理解、频繁结算的场景；政治选举是另一个已经被市场验证的场景。但他认为，预测市场还可以回答“某项政策会让一年后的失业率是多少”“某项科学发现会不会在特定时间发生”等问题。

对于没有明确结算日的观点，可以把它看成 opinion market。市场不一定等到最终真相出现才有价值，因为参与者可以随着新论文、灾害、政策或社会事件改变概率判断，并在变化过程中进行交易。它类似股票市场：股票没有一个固定的“真理日期”，但价格仍然表达市场对未来现金流的看法。

这类市场可能成为政策信息工具，也可能出现操纵和道德风险。事件必须被精确定义，结果必须可验证，参与者不能利用内幕信息或制造事件影响价格；不同司法辖区对赌博、衍生品、选举和金融市场的界线也不同。Coinbase 的产品增长数字应与这些监管约束一起观察。

### Brian 为什么参与 New Limit

Brian 回顾说，他和朋友曾讨论太空、AI、聚变能源、脑机接口等“大问题”，但这些方向已有很多优秀团队。长寿研究当时既受到大量夸张宣传影响，也存在真正重要、资本和工程投入不足的机会。他希望寻找一个自己能贡献、又不是简单重复已有团队工作的领域。

表观遗传重编程让他产生了持续兴趣。早期科学研究显示，某些转录因子组合可能把细胞的状态向更年轻的功能方向推回，但不能把小鼠寿命实验直接外推到人类。Brian 的观点是，必须通过大规模筛选、功能检测、动物模型和临床试验逐层推进。

New Limit 的建立方式也反映了他对创业的理解：先通过晚餐和问题讨论寻找真正高潜力且资金不足的科学方向，再聚集科学家和创业者，提供早期资金、公司建设和组织支持。Jacob Kimmel 成为 CEO，Blake Byers 和 Greg Johnson 参与共同创建。Brian 强调自己没有把 Coinbase 的全职工作交给 New Limit，而是保持投资人和董事会成员的角色。

### AI 如何进入实验室

表观遗传重编程涉及大量转录因子组合。单靠人工逐个尝试会非常慢，New Limit 因此把 AI 用在实验设计上。模型根据已有结果推荐下一组实验，实验人员在实验室中批量操作细胞、分子和液体，再把结果反馈给模型。这个循环的价值是缩小实验搜索空间，而不是让模型凭空证明一种药物有效。

大规模 pooled screen 可以同时测试很多候选组合，先寻找细胞表型上的信号，再将较好的候选物放入功能实验。功能实验更慢、更贵，通常会涉及动物模型；通过动物阶段的候选物才可能进入人体临床。这个漏斗意味着前端可以大量试错，后端必须高度谨慎。

Brian 声称已经在 humanized mouse model 中看到至少一种人类细胞类型的成功重编程，并继续在非人灵长类动物中测试。他预计第一期临床试验在下一年启动。临床一期主要验证安全性、耐受性和剂量，不等于已经证明延寿效果。未来 3 到 10 个候选药物的说法，也应区分“来自平台的研究候选物”和“最终获批并商业化的药物”。

### 长寿研究的风险边界

主持人与 Brian 都承认，长寿领域过去存在很多没有坚实证据的观点。某种干预让小鼠活得更久，不代表在人类身上同样有效；调整细胞状态也可能带来失控增殖、肿瘤、组织功能异常和免疫反应等风险。重编程的关键是恢复功能，同时避免把细胞变成错误的类型或引入不可逆损伤。

因此，New Limit 的验证链条需要包括候选物机制、递送方法、靶细胞范围、剂量窗口、动物安全性、长期观察和人体临床结果。AI 能够提高探索效率，但不能缩短所有生物学和医学验证的时间。这个判断也与 Coinbase 的 agentic finance 相似：自动化可以扩大探索和执行能力，但权限、责任、反馈和现实世界结果仍必须被制度化。

### 从公司建设到集体智能

Brian 还谈到，创业者容易低估同时管理多家公司的分心成本。他认为成功创业之前可能尝试过很多想法，但真正找到产品市场匹配后，需要把主要精力集中在一家公司上。参与 New Limit 的方式，是在不削弱 Coinbase 主业的前提下，通过资本、董事会和问题选择提供帮助。

最后，他把 AI、长寿、认知增强和脑机接口放进“提高人类集体智能”的长期问题。数字 AI 会变得更强，人类则需要改善疾病、健康、认知和下一代的基础条件。关于胚胎编辑，他提到疾病预防的社会接受度可能高于增强能力，但也承认这是有争议的方向。访谈最终回到一个较克制的原则：大的社会问题值得投入，但具体路径必须由科学、临床和伦理验证来决定。

## 产品架构层面的理解

从产品架构看，Coinbase 想做的不是一个单点 AI 功能，而是把账户层、资产层、支付层、协议层和 agent 执行层连起来。账户层决定谁拥有资金以及资金边界；资产层提供加密资产、稳定币、代币化股票和其他金融工具；支付层负责结算；协议层让机器可以通过 X402 等标准发现价格并发起支付；agent 层则负责理解任务、调用服务和在权限范围内执行。

这套架构解释了为什么 Brian 同时谈 AI advisor、agent wallet、稳定币、Everything Exchange 和 tokenized stocks。AI advisor 更像是人类用户的自然语言控制面板；agent wallet 是机器主体的资金容器；稳定币是跨境和小额结算媒介；Everything Exchange 是资产和交易的统一市场入口；X402 则把服务调用变成可收费的网络请求。单独看每个功能都不一定形成强壁垒，合在一起才可能形成闭环。

对 Coinbase 而言，真正的竞争不只是模型能力，而是能否安全地管理授权、身份、托管、合规、清算和争议处理。一个能回答问题的 agent 很容易被替代；一个能够在用户设定的额度和策略内，准确完成交易、支付、退款、记账和审计的 agent，才可能成为金融基础设施的一部分。

这也意味着产品增长要看比下载量更具体的指标：每个 agent 账户的活跃天数、每个 agent 的有效支付数、平均支付金额、重复调用率、失败率、人工接管率、欺诈损失、稳定币余额、商户覆盖和客户留存。访谈没有给出这些指标，后续需要通过公司公告、产品文档或真实使用测试核验。

## 访谈中的几个关键判断

第一，**AI agent 的经济身份会成为新产品对象**。如果 agent 只是聊天窗口，支付仍需人类完成；如果 agent 有钱包、预算和可验证的权限，它才真正能够代表人类或公司执行任务。

第二，**微支付可能是加密支付最早的 agent 用例**。机器之间的单次调用金额低、频率高，传统卡网络的固定费率不适配，稳定币和链上协议有机会从这里切入。但这要求协议、钱包、风控和服务目录都足够标准化。

第三，**代币化的目标是重做金融资产的流转，而不只是换一个显示形式**。如果真实股票、国债、存款和私人信贷能够在合规条件下互相转移、组合和抵押，金融系统的清算速度与全球可达性可能改变；如果只是价格跟踪凭证，价值就明显更接近传统衍生品。

第四，**Coinbase 的长期叙事依赖监管许可和真实使用**。Everything Exchange 要扩大资产范围，tokenized stocks 要扩大地域，agent wallet 要处理身份与反洗钱，预测市场要处理事件结算和市场操纵。技术路线可以同时推进，但每一条商业化路线都有自己的法律和运营瓶颈。

第五，**New Limit 是“AI 加速科学”的案例，而不是纯软件业务**。模型可以生成实验假设，实验室仍要完成细胞、动物和人类验证。这个案例对理解 AI 应用很有帮助：真正的瓶颈不一定在生成答案，而可能在实验周期、材料、设备、监管和长期安全性。

## 不应从访谈直接推出的结论

不能因为 Brian 预测 agent 经济会超过人类经济，就推导 Coinbase 必然获得主要市场份额；不能因为 X402 得到多家公司的参与，就推导协议已经形成大规模商业收入；不能因为 Coinbase 正在探索 tokenized stocks，就推导美国市场已经批准或产品已经普遍可用；也不能因为 New Limit 计划启动一期临床，就推导长寿药物已经证明有效。

同样，访谈中的 88% 非比特币收入、1 亿美元预测市场年化运行率、76% 低于 30 美分的 agent 交易和未来一年临床计划，都需要标注为嘉宾或主持人口述口径。正式研究时应回到 Coinbase 财报、监管申报、产品条款、协议数据、临床登记和同行评议材料逐项核对。
