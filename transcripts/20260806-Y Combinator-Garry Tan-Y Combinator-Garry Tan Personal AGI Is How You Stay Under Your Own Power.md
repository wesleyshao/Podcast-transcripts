### Markdown 就是代码：skill 文件与确定性计算

这是一个真实的，经过轻微编辑的。它说：当会议录音从 Circleback 传出时，用演讲者标签转录它。拿出做出的承诺、谁做出的以及最后期限。对照图书馆交叉核对每个被点名的人并链接他们的页面。此处归档摘要，此处归档完整记录。如果有任何事情与我们已经相信的事情相矛盾，请标记它。不要覆盖它。就是这样。这是一项技能。这是一页英文。一个聪明的实习生——任何真正能读书的人——都可以遵循它。实际上，这就是测试。如果聪明的实习生可以遵循它，那么 agent 就可以运行它。这实际上意味着一种深刻的事情。我知道我因为谈论这一点而受到了很多批评，但我认为这比以往任何时候都更加真实，尤其是现在。 Markdown 实际上是代码。如果你能用英语写出清晰的指令，那么你就是一名程序员。编译器是一种语言模型，这就是为什么它不再只是工程师的专利。

在 YC，我们的媒体人员、活动人员、财务团队（这些人一生中从未打开过终端）正在建立 skill 文件 和预定工作。我们的一位财务人员将大约一百本 Excel 工作簿编译到她与内部 agent 一起构建的一个应用程序中。她不是程序员。她现在是 agent 的经理。每个人都即将成为。

我有一个朋友，他的儿子患有一种罕见的癫痫症。没有实验室，没有资助，没有许可。他刚刚走了，你就可以做事了。他建立了一个包含 80,000 个 Markdown 文件的存储库，相当于一个小男孩的大脑，并将自己推向了人类对儿子确切状况的了解的绝对边缘。

每一次专家就诊、每一篇论文、每一份癫痫发作日志、每一次药物相互作用——都被索引和交叉链接并准备就绪，这样当新医生有了一个想法时，他可以在几分钟内知道它是否已经被尝试过。父亲、笔记本电脑和图书馆。这就是个人 AGI。不是基准测试，也不是演示。我今晚所描述的整个架构——图书馆、图书管理员、在正确的时刻打开正确的三本书，旨在实现一个人在世界上最爱的一件事。没有人来为他建造它，所以他建造了它。没有人会来为你建造你的。这是个好消息。

你被告知你需要的一切——团队、资金、许可、证书——都是一种解决方法，因为一个人可以在脑子里装七件事，每天工作十六个小时。这个事实刚刚过期。你现在可以飞了，不是隐喻的、机械的。你想到的每一个问题，我都希望有这个人。我希望我能雇用这个人，但我找不到他们。你可以。每个档案都太大而无法阅读。每个数据集都太粗糙而无法清理。每个海洋都被告知不要沸腾。我们现在可以煮沸海洋了。

我有一句话我一直奉行，我想把它留给你。 “一切都是编造出来的，但你必须编造出来。”世界上的每一个机构，包括 1656 年对 23 岁的人念咒语的机构，都是由不比你聪明的人建立的。你和你之前的每一代创始人之间的区别在于，他们必须招募数十名信徒才能建立任何东西。您需要一台笔记本电脑和您已经拥有的几年历史。整个活动约有7000人参加。 7,000 条连续线。 7000次努力。在历史的大部分时间里，几乎所有这些努力都没有得到观众的关注。它在等待资金、等待人数、等待许可、等待别人首先相信的过程中死去。今晚我向大家展示的机器是我所见过的第一项让努力直接发挥作用的技术。

一个人，没有中介，没有许可。我真的认为全世界还不明白 7,000 名拥有这种影响力的人走出大楼做了什么。斯宾诺莎在《伦理学》结尾写道这本不得不放在书桌上偷运出来的书，上面写着九个字：一切优秀的事物都像它们一样稀有而困难。困难就这样崩溃了。现在稀有度由你决定。去建造吧。谢谢。
