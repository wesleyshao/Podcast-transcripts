# Cloudflare CEO: We're Ready To Block Millions of Websites From AI — With Matthew Prince

## Transcript

**开场。**

**旁白：** 当 AI bot 的数量已经超过浏览网页的人类时，互联网会变成什么样？新闻、信息出版商和小企业还能不能活下去？本期节目邀请 Cloudflare CEO Matthew Prince，讨论 AI 流量、内容商业模式，以及一个越来越由 agent 代替人类浏览和购物的互联网。

**Alex Kantrowitz：** 欢迎收听 Big Technology Podcast。我们希望做的是对科技和更广泛世界进行冷静、细致的讨论。现在，网页上的 AI bot 已经超过了人类访客。也就是说，自动化流量已经多于人类流量，这当然会改变新闻出版商、信息出版商以及小企业的激励机制。Matthew，你大约一年前来过节目，当时我们讨论 Cloudflare 如何防止网页消失。网页还在，但可能已经没有一年前那么健康了。今天我们来谈谈，随着 AI 继续快速推进，这场变化会是什么样子。Matthew，很高兴再次见到你。

**Matthew Prince：** 谢谢邀请。

**Alex Kantrowitz：** 先从最重要的标题说起。Cloudflare 最近发现，浏览网页的 AI bot 已经多于人类。你觉得这件事意外吗？这背后既有为训练新模型而进行的爬取，也有 agent 像人一样采取行动，还有模型在回答问题时临时访问网页。你们看到的 AI 流量究竟是怎样升级的？这说明最近 AI 应用的发展速度有多快？

**Matthew Prince：** 我确实很意外。2025 年 11 月，我在 Web Summit 被问到自动化流量什么时候会超过人类流量。当时我们把数据调出来，按照当时的趋势估计，拐点应该在 2027 年下半年。2026 年 3 月，在西南偏南活动上，我又被问了一次。我们重新拉取数据，发现时间提前了，大概会在 2027 年上半年发生。

到了 2026 年 5 月，团队来告诉我：“你不会相信，我们第一次看到自动化流量已经超过了人类流量。”这说明增长有多快，也说明曲线的斜率在变得越来越陡。按照当前趋势向前推五年，我们估计线上自动化流量可能达到人类流量的一千倍。不是因为人类流量会消失，而是因为自动化流量会继续疯狂增长。

这会给互联网资源和基础设施带来巨大压力。Cloudflare 现在思考的核心问题之一，就是怎样让互联网为这场自动化流量的全面冲击做好准备。

**Alex Kantrowitz：** 很多人听说过“死亡互联网理论”。它认为，有一天网页主要由 bot 和自动生成的内容组成，bot 再操纵这些内容，算法筛选出来的社交信息看起来像真的一样。你们看到的趋势似乎不完全是这样。

**Matthew Prince：** 我认为实际趋势在某种程度上正好相反。Cloudflare 成立于 2010 年。大约 2015 年，网页总量停止增长，之后十年甚至略有下降。但从 2025 年 10 月左右开始，网页重新增长，速度最接近 2000 年代中期。

新产生的内容不能简单称为自动生成的垃圾。确实会有低价值内容，但网络过去一直有低价值内容。更重要的变化是，一些没有技术能力、没有很多资源，却有想法、有故事、有东西想分享的人，现在可以使用 Lovable、Replit、Base44 或 Wix 等工具，搭建出相当复杂的应用。

过去，只有受过技术训练或有钱雇人开发的人，才容易把想法放到网上。现在更多普通人可以创造东西。就 Cloudflare 目前看到的情况而言，正在发生的是创造活动爆发，互联网未必因此变差，甚至可能变得更好。变化更大的地方，是我们消费互联网的界面。未来人们可能更多通过 AI 界面进入网页，而不是直接打开一个个页面。

**Alex Kantrowitz：** 我想追问一下。有人研究发现，Apple App Store 里的应用数量越来越多，但评论质量在下降，周活跃用户并没有相应增加。你说这些不是垃圾，但其中是否有很多接近垃圾的东西？

**Matthew Prince：** 当然会有没有价值的东西。但我每天看到的，是原本没有资源或能力的人，第一次做出了有价值的产品。我的同事和家人中，有人告诉我，他们以前从未想过自己能创建某种东西，现在却做到了。AI 工具和 Cloudflare 这样的基础设施结合起来，让人们用很低的成本上线应用。

你刚才举的例子也很说明问题。过去要做一个网站，可能得先雇一整支团队。现在一个人可以让 Claude code 连接 Cloudflare agent，自动创建账户、设置服务并搭建网站。技术在最好的时候，就是让更多人接触到过去只有少数人能使用的能力。

直播制作也是类似的例子。十年前，如果要在两个地点做 4K 直播，可能要花几十万美元去租摄影棚、搭设备和准备传输链路。现在很多工作都可以被更低成本地完成。AI 同样会扩大创作能力，让更多人进入市场。

真正重要的问题，是未来五年、甚至未来三十年的互联网商业模式。如果商业模式设计正确，我们可能进入内容创作的黄金时代。如果设计错误，后果也很容易想象：内容创作者没有收入，网站无法承担流量成本，信息被少数平台控制，新的参与者很难出现。

**AI 流量到底在做什么。**

**Alex Kantrowitz：** 互联网内容一方面需要被创造，另一方面又越来越多地被 AI 爬取。你们能否区分这些流量？哪些是为了训练新模型，哪些是 agent 像人一样浏览网站，哪些是在回答问题时临时搜索？

**Matthew Prince：** 三种情况都有，而且未来都会增长。训练流量确实在上升。不是 OpenAI 或 Anthropic 单独把爬取量提高很多，而是有越来越多公司在做模型。世界不应该只有五家 frontier model 公司，也许应该有五十万家模型提供者。我们要让更多人可以参与模型建设。

目前真正自主运行的 agent 流量可能是三类中最小的，但未来会变成很大的类别。agent-to-agent 的商业和服务交互更像未来，而不是现在。与此同时，AI 已经开始替人类访问网站。

但不能把它简单理解为“像人一样浏览”。如果一个人要买数码相机，可能认真看五个网站，每个网站看十个页面。一个 agent 可能访问一千个网站，甚至把每个网站的每个页面都看一遍。由于它没有耐心限制，且抓取的边际成本很低，这会给服务器、带宽和内容生产者造成巨大负担。

从用户角度看，agent 可以不厌其烦地比较所有信息，这是好事。但每一个请求后面都有服务器、带宽和维护成本。内容也不是凭空出现的。AI 公司如果只拿走内容和基础设施，却不返回任何价值，这个经济关系就不成立。互联网必须建立某种价值交换。

**Alex Kantrowitz：** 你说五年后自动化流量可能是人类流量的一千倍，这个数字非常大。究竟是什么把它推到一千倍？

**Matthew Prince：** 我们只是把现在的变化率向前外推，而且随着更多人使用 agent，指数可能还会加速。现在经常使用 ChatGPT、Claude 或 Grok 的全球知识工作者比例仍然很低。假设将来所有知识工作者都有 agent，而且不是每天问一两个问题，而是每项任务都让 agent 去查资料、比较方案、执行动作，流量很容易继续上升。

可以做一个保守的 CPU 计算。假设地球上每一位知识工作者都拥有一个 24 小时工作的 agent，并且每个 agent 运行在传统 container 中，而不是独占虚拟机或服务器。仅考虑 CPU，不考虑 GPU，一年所需的 CPU 产能就可能超过当前产能的四十倍。而且这还只是假设每个人有一个 agent。实际情况可能是一个人有多个 agent。

Cloudflare 过去经历过从服务器到 VM，再到 container 的效率提升。但 container 仍然很重，它要带上完整操作系统、工具链和其他运行环境。Cloudflare 正在考虑更轻的运行方式，例如开发者平台 Workers，以及允许大量轻量服务运行的 Isolates 技术。互联网要承受未来的 agent 流量，就需要这种更轻、更高效的执行方式。

**内容成本和谁可以被爬取。**

**Alex Kantrowitz：** 去年我们谈到，出版商花钱写一篇文章，Anthropic 把它爬走并放进 Claude，出版商就被排除在价值分配之外。现在问题更广了。即使网站没有投入很多钱制作内容，只要遭遇大幅流量增长，维护成本也可能上升到无法承受。

**Matthew Prince：** 不同内容创作者的偏好不同。Cloudflare 想做两件事：第一，为希望内容进入 AI 系统的公司提高效率；第二，为不希望内容被 AI 使用，尤其是不希望在没有补偿的情况下被使用的公司，提供控制权。

绝大多数网站其实希望内容能进入 AI。Cloudflare 自己的知识库就是帮助用户理解如何使用 Cloudflare 的内容，我们希望各个 AI 系统都能访问它。因此，我们需要把交付做得高效，不能每次都发送沉重的 HTML 页面，而是尽可能发送模型真正需要的 Markdown。缓存和其他技术也要让内容更低成本地进入 AI 系统。

目标应该是，服务一次页面的成本降到过去的千分之一。只有这样，内容需求增长一千倍时，网站才不会被成本压垮。

**关于流量规模的进一步说明。**

**Alex Kantrowitz：** 这不只是把原来的人类点击换成 bot 点击。人类在访问网站时会受到时间限制，也会在看过几个页面后停下来。agent 没有同样的约束。它可以先读取所有评论，再对比价格、规格、运输政策和退货政策，然后把结论交给人类。对单个用户来说，这种服务很有价值，但对网站来说，每一个额外页面都意味着 CPU、带宽、缓存和数据库成本。

**Matthew Prince：** 正是如此。假设一个知识工作者每天让 agent 处理研究、写作、采购和安排工作，每项任务都会触发多个搜索和网页读取。今天真正稳定使用这些工具的人可能只有全球知识工作者中的很小一部分，未来如果普及到全部知识工作者，增长不是简单地把当前流量乘一个小倍数，而是把每个工作日中的大量判断都变成自动访问。

这也是为什么我们不能只盯着 GPU。模型运行需要 GPU，但网页访问会大量消耗 CPU、网络和存储。传统 container 比独立服务器高效，却仍然需要带上完整的操作系统和工具链。它适合今天的服务规模，却不适合每个人拥有多个持续工作的 agent 的场景。Workers 和 Isolates 的意义，在于把每个任务拆成更轻量的执行单元，让大量短任务可以共享基础设施，而不必为每个任务准备一套完整系统。

**Alex Kantrowitz：** 你提到 WordPress 的例子非常直观。一个托管商目前大约花 3.17 美元托管一个 WordPress 网站，向客户收取 12.99 美元。如果流量增长一千倍，成本可能超过 3,000 美元，而普通 WordPress 用户不可能接受这样的价格。

**Matthew Prince：** 这不是说 WordPress 的界面、社区和使用方式必须消失，而是底层技术需要改变。最理想的结果，是用户仍然使用熟悉的 WordPress 生态，但网页对 agent 的交付经过缓存、压缩和结构化处理，只有必要的信息被发送出去。否则，内容创作者即使愿意让 AI 使用自己的内容，也会被基础设施账单逼出市场。

内容创作者还需要不同的访问控制。一个公司知识库可能希望被所有 AI 系统索引，因为它希望用户得到准确的使用答案；一个依靠广告或订阅维持的新闻网站，可能只愿意在获得补偿后提供文章。系统不能把这两类公司强行放在同一个规则里，而是要让创作者明确选择：开放、限制，或者按照费率表收费。

**从爬取到点击的变化。**

**Alex Kantrowitz：** 对新闻出版商来说，最令人不安的地方，是 AI 答案可能让用户根本不再进入原始页面。过去搜索引擎抓取页面后仍然把人送回去，今天模型把答案直接放进聊天界面，用户甚至不会点开脚注。

**Matthew Prince：** 出版商看到的经济关系已经发生变化。随着回答变得更准确，原始来源得到的点击会进一步减少。用户觉得自己已经得到了答案，于是不会再打开十几个链接核对。这并不意味着原始内容价值下降，反而意味着 AI 需要更多高质量内容才能给出答案，但价值没有回到创作者手里。

如果一次内容访问只带来一次很小的成本，却能支撑一个有商业价值的回答，那么支付应该在访问发生时完成，而不是要求创作者继续依赖原来的广告展示。微支付的金额可以低到一美分的很小部分，但对新闻、研究和专业资料而言，大量小额交易可以成为新的收入来源。

这里的规模很容易被低估。Cloudflare 每秒处理约五亿次互联网交易，这些不是金融交易，但其中如果只有百分之一到百分之十可以在 agent 访问时收费，第一天就可能需要每秒处理约一千万笔金融交易。随着比例提高，系统必须向每秒一亿笔以上扩展。支付系统不仅要收钱，还要知道哪家内容创作者提供了什么、哪一个 agent 获得了什么、怎样结算、怎样处理退款和争议。这也是为什么微支付不是简单加一个付款按钮。

支付还必须和身份、授权及访问记录结合起来。网站需要知道访问者是哪个 AI 服务、代表哪个用户、使用了哪一类内容；AI 服务则需要知道自己拿到的内容是否可以用于训练、是否只能用于一次回答，以及费用应该归属于哪一个创作者。若这些记录不能被可靠地核对，出版商无法证明自己获得了应得的收入，AI 公司也无法计算自己的内容成本。

这套机制应该允许内容创作者分层开放。一个博客可以让搜索摘要免费，把完整文章留给付费访问；一个研究机构可以让学术引用开放，但限制整库训练；一个商家可以让产品规格被 agent 读取，却要求下单和库存查询经过授权。不同规则可以由机器直接识别，而不是让网站所有者每天手动回复爬虫。

同时，Cloudflare 不能把“想被访问”和“不想被免费访问”混为一谈。很多公司希望自己的知识进入 AI，因为这能让潜在客户更容易发现它们；它们真正反对的不是被看见，而是访问量上升以后仍然没有任何回报。另一些出版商则需要把完整内容留在自己的订阅体系内。未来的协议要同时支持开放、授权和收费，而不是只有全部放开或全部封锁两个选项。

**Alex Kantrowitz：** 如果默认拦截发生在九月，出版商怎样知道这不是一次对搜索的自我伤害？

**Matthew Prince：** 它们需要观察不同来源带来的价值。过去一个点击可能代表一次广告展示、一次注册或一次订阅机会，但 AI 界面把很多价值留在了界面内部。出版商不能只看访问量，还要看内容是否被引用、是否带来付费用户、是否得到授权收入。Google 也需要证明，继续免费爬取带来的价值足以抵消创作者收入的下降。

真正的公平规则不是让所有人都支付同样的金额，而是让任何访问者都不能在不说明身份、不接受条件的情况下无限制获取内容。大型出版商可以自己谈价格，小型站点则需要共享的计费和验证基础设施。Cloudflare 的角色可以是执行规则、降低传输成本，并把访问行为交给支付和内容市场处理。

对小企业来说，信誉数据也不能只由大平台掌握。发货时间、退货率、库存准确率、产品安全记录和用户服务质量，应该由商家授权后形成可验证的商业档案。agent 看到这样的档案，才有机会把一个没有广告预算的新商家与成熟品牌进行公平比较。否则 agent 所谓的“深入研究”只会把已有信息最多的公司排在前面。

如果能让消费者、支付网络、电商平台和商家共同维护这些证明，agent 就可以按产品质量、实际履约和价格做判断，而不是按品牌知名度或广告预算做判断。这是小企业仍能进入市场的必要条件，也是 agentic commerce 能否带来更好产品的关键。我们目前还没有最终协议，但 Shopify、PayPal、Visa、MasterCard、American Express 和 Intuit 等公司都掌握问题的一部分，必须把这些部分连接起来。

因此，未来的默认设置不应被理解为 Cloudflare 替出版商决定是否开放，而是把决定权交回网站所有者。希望获得分发的公司可以继续开放，让 AI 帮助用户发现自己；依靠广告和订阅的公司可以要求授权或微支付；小企业可以先免费提供足够的信息，等积累履约和口碑后再扩大交易。关键是所有选择都要能够被 agent 读懂，并且访问者不能因为平台规模大就自动获得免费通行权。

这也是内容市场和基础设施市场必须同时解决的问题。降低传输成本只能让网站更能承受流量，却不能回答创作者如何获得报酬；支付机制只能分配钱，却不能解决 agent 访问大量低效页面造成的容量浪费。Cloudflare 需要做的是让内容更轻、访问更可控，同时和支付、电商、出版商及 AI 公司一起建立可执行的交换规则。

这套安排也必须允许网站随时调整自己的决定。有人可能为了获得发现机会而开放训练访问，后来发现成本过高，再改成只开放摘要；有人可能与某家 AI 公司合作，却不想把同样权限交给所有平台。可选择、可验证、可撤回，才能让创作者真正拥有内容，而不是在一次默认同意后永久失去控制。

最终要保护的不只是单个网页，而是一个仍允许新作者、新商家和新服务进入的市场。如果所有访问都被少数平台控制，互联网就会失去原本促进竞争的作用；如果规则和收费透明，AI 才可能成为内容与商品的发现工具，而不是把流量和收入单向集中到平台手中。

**控制工具和真正的支付系统不是一回事。**

**Alex Kantrowitz：** 所以你们去年首先提供的是拒绝访问的技术，而不是已经完成付款和分账。

**Matthew Prince：** 对。我们先让出版商知道谁在访问，以及怎样阻止没有遵守规则的 crawler。大型出版商可以把这些控制能力用于谈判，要求 AI 公司签订授权协议。下一阶段则是让没有谈判能力的小博客、小商店和独立作者也能写出自己的规则，并且让 agent 在访问时自动遵守。

对于小网站，最重要的不是复制大型媒体的法律和商务团队，而是提供一个简单的 rate card。它可以写明：公开摘要免费，完整文章每次收取一个很小的费用，研究资料按套餐计费，或者某类 AI 可以访问而另一类不可以。AI 公司和网站都需要一套机器可读的规则，不能每次访问都靠人工谈判。

Google 的特殊地位会让这个问题更难。Google 既有搜索 crawler，又把搜索的入口与 AI 结合起来。出版商如果想保留传统搜索流量，就很难只拒绝 Google 的 AI 使用。这样，Google 就能把旧业务的分发能力转化成新业务的训练和回答能力，而其他 AI 公司却要单独谈许可。

如果所有 AI 公司都按同一规则访问，市场才有可能出现公平竞争。Cloudflare 的目标不是把所有内容都关掉，而是让创作者决定是否开放、是否收费，以及谁要为基础设施和创作成本付费。

**未来的内容市场。**

**Alex Kantrowitz：** 这是不是意味着，出版商实际上在利用 Cloudflare 的默认设置给 Google 一个期限：如果你不改变条款，我们就让 Google 失去内容？

**Matthew Prince：** 这正是谈判中的一种可信选择。以前出版商即使不满意，也担心失去搜索带来的收入。现在 AI 已经让这些收入继续下滑，出版商发现自己没有理由永远免费提供高价值内容。它们可以选择让 Google 和 OpenAI、Anthropic 遵守同样规则。

我仍然比一年前更看好媒体的长期机会。2026 年可能是一个转折点，因为内容创作者、出版商和 AI 公司都会认识到，广告和订阅不能自动解决 AI 读取内容后的价值分配。Google 最终是否在 Cloudflare 设定的日期前付费，我无法确定，但它需要内容，而记者和创作者需要收入，这两个事实会把谈判推向某种结果。

如果出版商选择切断 AI crawler，影响不会只体现在某个网站少几次访问。大量网站从 Google 的索引中消失，可能改变搜索结果的基础结构，也可能让用户在 Google AI mode 中得到更窄、更旧或更偏的信息。因此，对 Google 来说，向创作者支付合理费用不是单纯的成本，而是维持产品质量和搜索可信度的条件。

另一类是广告支持或订阅支持的出版商。它们担心，AI 把内容直接交付给用户后，用户不再看到广告，也不再点击原始页面，出版商就会失去收入。它们需要能够规定：只有在你补偿内容创作者时，才可以访问我的内容。与此同时，agent 也要有方便的方式支付这笔钱，形成真正的价值交换。

**Alex Kantrowitz：** 也就是说，大多数公司希望被爬取，新闻出版商可能希望有条件地被爬取。你以前提到过，用户越来越少点击 AI 答案下方的脚注。去年你给过一组数字：十年前 Google 爬两次网页带来一次点击，后来变成六次爬取带来一次点击；Google 推出 AI Overviews 后，可能变成十八次爬取带来一次点击；OpenAI 约每 1,500 次爬取带来一次点击，Anthropic 和 Claude 可能要六万次爬取才带来一次点击。现在这些数字怎样？

**Matthew Prince：** 从出版商角度看，情况大约又恶化了一倍。每个比例都差不多翻倍。可是从用户角度，体验可能变好了，因为 AI 系统更聪明，回答更完整，用户觉得不必再核对原始材料。

这两件事并不矛盾。AI 公司的界面和行为没有根本改变，改变的是回答质量。回答越好，用户就越不需要点击原始来源。Google 也已经说过，传统的“十条蓝色链接”会消失，界面会越来越像 AI。

过去三十年支撑互联网的广告和订阅模式，未必能支撑未来三十年。大型出版商和 AI 公司之间的授权交易会增加，但还必须有一套能让小型出版商、学术作者和普通内容创作者参与的机制。

一个方向是微支付。如果 agent 访问一条信息，网站可以收取不到一美分的费用。最低金额可以覆盖基础设施成本；对于真正做新闻、学术研究或专业内容的人，费用也可以帮助承担创作者成本。

这里有一个很难的技术问题。Visa 在假日高峰每秒处理大约两万笔金融交易，而 Cloudflare 每秒处理大约五亿笔互联网交易。我们估计，其中百分之一到百分之十的请求从第一天起就可能通过 agent 微支付变现。这意味着支付基础设施一开始就要支持大约每秒一千万笔金融交易，并且最终扩展到每秒一亿笔以上。每笔金额很小，但它们仍然需要记账、结算和审计。这是非常难、也非常有意思的基础设施问题。

**Cloudflare 对 Google 的规则。**

**Alex Kantrowitz：** 你去年说过，如果出版商页面希望被爬取，可能需要付微支付，否则就会被拦截。但当时似乎还没有真正完成微支付系统。

**Matthew Prince：** 当时我们没有微支付基础设施，现在也还没有完整的微支付基础设施。我们先提供了一套控制工具，让广告支持或订阅支持的内容创作者可以决定谁能访问他们的网站。

People Inc.、Condé Nast、The New York Times、The Financial Times 和 The Atlantic 等大型出版商已经使用这些工具控制 AI 公司，然后与 AI 公司谈判交易。下一步有两个方面：一是让所有 AI 公司遵守相同规则，二是为无法自行谈判的小网站提供基础设施。

最大的问题之一是 Google。Google 把同一个 crawler 同时用于搜索和 AI，并把过去的搜索优势延伸到未来的 AI。按照 Cloudflare 看到的数据，Google 爬取的网页数量超过 OpenAI 的两倍，超过 Anthropic 的四倍，超过 Microsoft 的五倍。这种爬取优势会转化成 AI 优势。

如果 Google 只是另一家 AI 公司，它就应该像其他 AI 公司一样被对待。如果 OpenAI 或 Anthropic 需要为内容付费，Google 也应该付费。Google 不能仅仅因为过去三十年的互联网商业模式属于它，就在新的商业模式里得到特殊待遇。

Cloudflare 计划从 2026 年 9 月中旬开始，对广告支持或订阅支持的网站默认限制 Google 访问内容。网站可以选择退出，也可以继续免费向 Google 开放，但默认设置将变成：如果不是对内容创作者进行补偿，Google 就不能访问内容。

**Alex Kantrowitz：** 这会怎样影响出版商在 Google 搜索里的排名？

**Matthew Prince：** 我希望 Google 会主动付费，因为如果失去内容，Google 的产品会明显变差。但从更长远看，SEO 已经不再是核心。十条蓝色链接正在消失。出版商不仅要考虑自己是否出现在 Google 中，还要考虑是否进入 OpenAI、Claude 以及其他 AI 系统。

如果企业是广告支持或订阅支持的，它们现在面临的是生存问题。它们需要建立一种新的商业模式，而不能要求 Google 永远免费使用内容。行业实际正在说，旧的 SEO 世界已经过去，必须为未来创造新的价值分配方式。

**Alex Kantrowitz：** 近期《华尔街日报》一篇文章说，Google 曾经是出版商的生命线，但现在一些出版商考虑切断 Google 的访问。文章还引用了 People 的 Neil Vogel 和 USA Today 联席 CEO Mike Reed，他们表示，全面关闭访问已经在考虑范围内。你的技术让出版商有能力阻止 AI 爬取后，它们是不是在公开谈判，告诉 Google：如果你不给出想要的条款，我们就使用 Cloudflare 把你挡在外面？

**Matthew Prince：** 我认为这是正确方向。如果 Google 是一家普通 AI 公司，就应该按照普通 AI 公司的规则被对待。Google 的搜索业务曾经为互联网提供了巨大支持，但新的商业模式不会只是过去那种广告和订阅。Google 也必须跟着互联网一起变化。

Cloudflare 预计，很多广告支持或订阅支持的网站会采用这套默认规则。网站可以选择退出，但大多数被 AI 访问、同时又靠广告或订阅赚钱的网站，都有理由要求补偿。从 2026 年 9 月中旬开始，我们会把“不要进入”从一块标识牌变成真正的门卫：除非访问者补偿创作者，否则不能获取内容。

**Alex Kantrowitz：** 这意味着数百万网站可能从 Google 的可见范围里消失。

**Matthew Prince：** 是的。互联网有很大比例使用 Cloudflare，所以我们处在一个可以帮助修复基本市场问题的位置。Google 正在把昨天的垄断优势变成明天的垄断优势。如果不纠正这一点，内容创作的激励就会消失，最后包括 Google 在内的所有人都会受损。

Google 的 PageRank 本质上是在建立一条信息归属链，用它进行搜索和排名。如果大量出版商突然从可见范围中消失，这条链会被破坏，Google 的搜索和排名机制也会受到系统性影响。我希望 Google 能认识到，自己可以成为内容创作者的支持者，而不是拖延者。

Google 在 YouTube 上已经证明自己知道如何支付创作者。很多创作者选择在 YouTube 发布内容，就是因为 YouTube 比其他平台更会给创作者报酬。问题不是 Google 在整个公司里都反对补偿，而是它需要承认 The New York Times、The Atlantic、People 和 Vogue 的创作者，也应该像 YouTube 上的创作者一样获得报酬。

**Alex Kantrowitz：** 你觉得 Google 会在这个期限前付费吗？

**Matthew Prince：** 我不知道它是否会在期限前付费，但我认为它最终付费是不可避免的。Google 需要这些内容，也应该理解记者、内容创作者和学术作者需要靠劳动生活。

**小企业和 agentic web。**

**Alex Kantrowitz：** 休息之后，我们来谈小企业。随着互联网变成由 agent 或 super app 主导的浏览和交易环境，小企业可能在这个过程中被淹没。你担心的究竟是什么？

**Matthew Prince：** 一年前我们主要讨论媒体会怎样。围绕媒体商业模式，我们已经做了很多工作，也取得了一些进展。但进一步思考后，我开始非常担心小企业。小企业不是注定要消失，但我们必须先明确风险，再有意识地设计解决方案。

我希望看到的未来不是五家 AI 公司，而是五十万家 AI 公司；不是只有少数内容创作者，而是任何人都能创作和发布内容；不是商业活动集中到少数超级公司，而是互联网继续让新企业出现和成长。

想象一个刚开始做 direct-to-consumer 品牌的小企业，比如销售灯泡、化妆品或其他消费品。现在它要触达客户，通常会在 Instagram、Facebook 或 Google AdWords 上购买广告，把产品展示给消费者。它可能拿到一点 venture capital，也可能借了小企业贷款，先做出一个宣传视频。只要视频触动了消费者，品牌就有机会成长。

人们与小企业做生意，常常是因为有情感联系，或者因为方便。比如我知道社区杂货店卖鸡蛋更贵，但我没有时间去寻找全城最便宜的鸡蛋，所以我还是选择它。品牌本来就是一种人类的价值捷径。看到 Marriott 的标志，我大致知道酒店体验会怎样；看到 Walmart 的标志，我也知道进入店里会得到什么样的服务。

但 agent 没有这种情感，也几乎没有耐心限制。它不会因为“我一直喜欢 Marriott”就自动选择 Marriott，而是会持续研究，比较所有选项，找到它认为最适合的结果。表面看，这似乎对小企业有利，因为 agent 不会只看品牌知名度。可新的问题是，小企业在线上没有足够的信息。

如果我推出一个新的灯泡或化妆品品牌，消费者的 agent 如何找到我？大型企业已经有丰富的网站、评论、历史数据和服务记录。agent 会优先找到信息最丰富的公司。这样一来，AI 驱动的商业反而可能成为集中化工具。

最终可能出现一种看起来很方便、实际上高度集中的经济：大型企业互相收购，消费者可以通过 agent 买到极度定制的产品，但当地农场或小店很难让 agent 发现自己。前 PayPal CEO、曾经负责 Intuit 小企业业务的人曾说，他担心未来只有几家公司：一家掌握资金，一家掌握房地产，一家制造商品，一家负责运输，再加上一家 AI 公司。现实未必真的只有五家公司，但集中化确实是一个自然趋势。

我有时会从科幻作品里观察未来。《The Jetsons》看上去很轻松，但它其实是一个非常压抑的世界。里面似乎只有两家雇主：Spacely Sprockets 和 Cogswell's Cogs。George Jetson 只需要按按钮，机器人完成其他工作。购物也由 Rosie 这样的家务机器人完成。

问题是，Rosie 会不会去社区杂货店？当然不会。她会去能提供最多质量信息的地方，那里很可能是一家超级公司。agentic commerce 如果没有新的准入机制，就会把大公司拥有的历史信息变成越来越强的优势。

**Alex Kantrowitz：** 反过来想，品牌过去本来就更偏向大公司，因为大公司有钱做广告。一个忙碌的人没有时间研究陌生的小公司，于是会买 Nike，而不是一个新品牌。agent 如果能做无穷的研究，可能反而让消费者有机会发现更好的小品牌。

**Matthew Prince：** 这可能是我们最终希望得到的乐观结果，但关键问题是信息如何进入系统。一个新品牌怎样积累足够的客户评论？怎样把实际发货时间、退货率、拒付率、产品质量和用户体验组织起来？在 agentic commerce 中，品牌不会只是几块漂亮的颜色和一个标志，而应该是对质量和体验的真实证明。

我们需要把 Amazon 的星级评价、实际履约速度、退货数量和 chargeback 等数据汇总成一个可验证的模块。这样，当消费者的 agent 看到它时，能够判断这是一家质量可靠的商户。

但在还没有声誉之前，小企业只是在证明自己的产品更好。它怎样获得第一批客户？怎样让系统愿意给它机会？我不认为这不可能，但如果完全放任市场发展，agentic commerce 很可能首先推动集中化。

Cloudflare 不可能独自解决问题。我正在和 Shopify、PayPal、Visa、MasterCard、American Express、Intuit 等真正服务小企业的公司讨论：能不能把工具组合起来，让小企业在未来的 agentic commerce 中生存？旧的 SEO 做法不适用于这个世界，我们需要新方式。

**小企业需要什么技术。**

**Alex Kantrowitz：** 从技术角度看，这会不会只是一个小企业在 ChatGPT 后台开一个门户，然后老板周末花时间口述企业的所有信息？你们已经讨论过哪些解决方案？

**Matthew Prince：** 去年我们谈媒体时，我也没有很清晰的答案。我之后花了大量时间与媒体公司、支付公司和 AI 公司交流，向它们说明问题并询问怎样解决。我认为我们已经有了很大进展。

希望明年我们再次谈话时，会有更好的答案。但答案只能来自很多人的参与：有人听到这里后提出一个想法；Shopify 的 Toby 说他们正在做某件事，希望 Cloudflare 帮助分发；American Express 说他们从大量小企业中发现了一种有效办法。我们现在是在尽量收集这些信息。

Cloudflare 不会单独解决这个问题，但希望成为解决方案的一部分。如果设计正确，agent 能帮助更好的产品找到最适合的消费者，让更多小企业触达客户，这会是非常好的结果。可是我们也必须提前看见下一个问题。

**AI 带来的分化。**

**Matthew Prince：** AI 可能成为贫富之间巨大的分化器。如果未来人们每年为自己的 agent 支付数千美元，就不会希望 agent 被广告影响，而是希望它完全诚实。这样，富裕地区的人会得到能力很强、能够深入研究和执行任务的 agent，贫困地区的人可能无法负担同样的能力。

因此，不能只讨论 AI 如何提高效率，也要讨论谁能使用它、谁能从它获得经济机会。我们可能从广告支持的互联网转向更直接的支付模式，但这个变化如果没有公共讨论，可能扩大已有差距。

我不认为 Cloudflare 能独自解决收入分配和全球不平等问题。但我们必须把这些风险说清楚。只有先把可能出错的地方讲明白，再去设计支付、身份、内容访问和小企业准入机制，未来才更可能接近乌托邦，而不是反乌托邦。
