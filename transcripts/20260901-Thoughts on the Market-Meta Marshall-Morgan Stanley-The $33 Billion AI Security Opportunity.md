# The $33 Billion AI Security Opportunity

## Transcript

**Meta Marshall：** 欢迎收听 Thoughts on the Market。我是 Meta Marshall，Morgan Stanley 美国网络安全、电信及网络设备分析师。

今天讨论一个正在出现的新市场：agentic identity security，也就是面向 AI agent 的身份安全。随着 AI agent 开始访问企业的敏感系统，公司需要新的方式来控制这些 agent 能做什么。

AI 助手正在工作中代表我们采取行动，这带来一个关键问题：这些 agent 应该被允许做什么？又应该如何授予它们权限？现在是纽约时间2026年9月1日星期二上午10点。

越来越多时候，AI 正在帮助我们完成日常工作。我们让它总结文件、分析数据、整理会议笔记。但这些工具正在逐渐超越回答问题，开始代表我们采取行动。

这样一来，安全挑战就从管理一个工具，转变为治理一支全新的数字化劳动力。未来几年，这个问题可能会进一步扩大。我们的估计是，平均每名人类员工将对应79个 AI agent 和109个 machine identity。

传统的工作场所身份安全，主要是回答两个基本问题：你是谁，以及你能访问什么。可以把它想象成办公门禁卡。门禁卡能够识别你的身份，并决定你可以打开哪些门。

但 AI agent 让问题复杂得多。它们可以自主运行，跨应用和数据库移动，还可以与其他 agent 协作。它们会在没有人直接介入的情况下采取行动。

因此，公司不仅需要知道一个 agent 能访问什么，还需要知道它为什么需要这些权限、权限应当持续多久，以及它实际做了什么。这正是 agentic identity solution 的核心基础。

这个问题带来的风险已经相当大。目前，工作环境中大约80%的数据泄露涉及被盗用或被滥用的凭证。过去一年，十分之九的组织经历过与身份相关的安全事件，其中83%至少经历过两次。现在，如果每名员工之外还增加数百个 machine identity 和 AI identity，而且这些身份持续以机器速度运行，问题的规模就会更大。

管理 AI agent 的一种方案是 zero standing privilege，也就是零常驻权限。

它不是给 agent 永久访问权，而是针对一项具体任务临时授予权限，工作完成后就撤销权限。但这里存在一个问题：目前只有39%的特权访问通过这种即时授权或 zero standing privilege 架构进行管理。现实中，人类不可能批准每一项权限请求。因此，越来越多的决定需要通过 runtime governance，也就是运行时治理，在实时环境中自动完成。

因此，我们估计，单是 agentic identity 就可能在基准情景下成为一个约330亿美元的全球机会，并使整个 identity market 在未来几年的机会规模超过600亿美元。

AI 带来的 agentic identity 需求，也可能推动一个长期碎片化的行业走向更加统一的平台。在一项行业调查中，85%的组织表示，碎片化的身份系统会延误其对身份威胁的响应。受访者称，每起事件平均需要12小时才能响应。

我们认为，这种环境有利于能够把人类身份与机器身份放在一起管理，并动态作出安全决策的平台。这样的平台整体上可以构建更安全的环境。

这个转变不会一夜之间发生。agentic identity 产品仍处于早期阶段，我们不预计它们会立即带来财务影响。但当企业从试验 AI agent 转向更广泛地部署它们时，保护这些 agent 的支出可能在2027年成为更有意义的增长推动力。

长期增长机会归结为一个简单的动态关系：agent 越多，自主性越高，就越需要控制。而这可能使身份安全成为 AI 在企业内部规模化扩展的必要条件。
