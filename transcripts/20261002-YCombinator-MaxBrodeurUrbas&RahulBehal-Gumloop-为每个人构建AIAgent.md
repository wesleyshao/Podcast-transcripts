**主持人（Gustaf Alströmer）：** 很多向企业推销 AI 工具的人基本上都在说：这个工具会自动化这类工作，因此就需要更少的人。听起来你描述的其实是完全相反的东西：每个人基本上立刻就拥有了更多的“人手”，能做更多事。谈谈这个。

**嘉宾（Gumloop 联合创始人）：** 是的，我想部分原因在于未来的这样一个世界：每个人都是管理者，我们都在监督 agent，让 agent 替我们干活。我觉得这似乎就是我们正在走向的方向。所以我们的看法是，你不一定需要更少的人，但你现有的人可以做多得多的事。我们在 Gumloop 自己的工程团队里也看到了这一点。我们有八名核心工程师在做产品，包括我自己在内，每个人基本上都能借助 agent 完成五个人的工作。是的。

**主持人（Gustaf Alströmer）：** 你们现在面临的最难的挑战是什么？对于考虑加入 Gumloop 的人来说，他们会做什么？

**嘉宾（Gumloop 联合创始人）：** 是的，我认为很多正是各大实验室也在面对的问题，也是实验室在应用层面临的最大挑战：如何在 agent 和模型的现有形态下最大限度地发挥它们的作用？如何让它们做真正的工作？如何让它们执行持续好几个小时的长时任务？如何让它们高效地使用电脑和浏览器之类的东西？我认为在 Gumloop 这样的公司工作，很大的吸引力在于你真正处在前沿，在推动用 AI 和当前模型所能做到的事情的极限。我认为这对人们来说非常令人兴奋，尤其是那些在更传统的公司里工作的人。

**嘉宾（Gumloop 联合创始人）：** 每一个大家觉得我们应该做、而我们也开始做的功能，底下都会附带一百个功能，而那些才是暗藏的难点。比如，浏览器自动化是我们正在做的。但接下来：好，如果人们可以让 agent 在云端和本地桌面上通过浏览器实现自动化，怎么确保它们不会去访问某些网站、不会做任何不良的事情、并且能够回看会话录像？然后他们又会问：我怎么回看 5000 段会话录像，并从整体上理解 agent 在做什么？我怎么确保从成本角度看它是高效的？这些功能附带的一切才是难点。所以当我们在一家公司部署时，必须考虑整体图景，而每个功能都有太多细小的边角，我们需要优秀的工程师来做。

**主持人（Gustaf Alströmer）：** 和各大实验室之间是什么样的关系？因为你过去提到过，你们的客户已经和实验室有合作关系，其中一些实验室还有竞争产品。我猜在这个领域也有“Cowork”（音，可能指 Claude Cowork 一类产品）。

**嘉宾（Gumloop 联合创始人）：** 完全是。是的，竞争非常多。我认为我们处在各实验室之间的一个“甜蜜点”上，我们有点像实验室之间的瑞士：你可以从任何地方获取推理服务。这对 IT 负责人或公司里的任何负责人都相当有吸引力——我可以在全公司构建 agent，而不被锁定在其中某一家供应商身上。下周 Twitter 上出了一个更好的模型、大家都为之疯狂时，我可以一键切换到那家推理服务商。而当那些公司拿着一份八位数的合同来找我们，觉得我们都在用他们的方案、哪儿也去不了时，我们实际上有能力转身去另一家推理服务商。还有“你拥有自己的 agent”这个理念——也就是 agent 主权：你把它部署在自己的云上，你拥有存储执行轨迹（trace）的数据库，你拥有完整的集成栈，你拥有你的 agent 未来——这变得相当诱人。尤其是，是的，我认为模型层会被商品化，实验室需要在其他地方创造收入，它们会去抢客户的生意。我们已经在几个客户身上看到了这一点：实验室推出了直接与他们竞争的产品，他们在这件事上吃过亏。大多数公司未来可能都会面临这种情况。所以拥有自己的 agent 相当重要。

**主持人（Gustaf Alströmer）：** 你们的客户需要前沿模型吗？

**嘉宾（Gumloop 联合创始人）：** 是的，我想需要。

**主持人（Gustaf Alströmer）：** 在他们的很多任务上？

**嘉宾（Gumloop 联合创始人）：** 他们肯定需要选择权，因为有些事情太复杂了，比如你要向 CEO 汇报一个增长指标，而它下周就会出现在董事会材料里，那最好用你能找到的最合格的模型。但如果你在跑一个每小时 8 万次的客服用例，用市场上最便宜的模型实际上会对你的……

**嘉宾（Gumloop 联合创始人）：** ……收入产生影响。是的，我认为这是关键：你确实需要选择权，因为即使在我们的客户中，也不是所有用例都需要前沿智能。所以要给人们向下切换和向上切换的选项，而且我认为要在组织层面有这种控制权。管理员和懂行的人可以强制大家使用特定模型，或者强制特定团队、特定用例使用特定模型。因为如果让每个员工自己选，很可能每个人都会直接用前沿智能，因为没有上限，谁在乎呢，对吧？但如果你让真正懂行的人有能力去强制执行不同的规则，我们发现这对每个人都更好，每个人的体验都更好：对终端用户来说更便宜、更快，对公司来说也更高效。

**主持人（Gustaf Alströmer）：** 通常每个产品类别有一个买家，但听起来在这种情况下仍然可能有一点自下而上：有人先发现了它。那它是怎么一路上升到决策者那里的？

**嘉宾（Gumloop 联合创始人）：** 每次都像一个谜题，每次都不一样。我们确实在形成更多的规律，但它最终上升到的那个人、也是最兴奋的那个人，通常是一位 IT 负责人——负责 AI 推广和安全的人，他面对的是每个人都在用 80 种不同的工具、数据到处流动的局面，他们需要把这一切管起来。是的。

**嘉宾（Gumloop 联合创始人）：** 他们往往是我们最兴奋见到的人，因为他们看到我们的功能集时眼睛都会亮起来。是的。

**嘉宾（Gumloop 联合创始人）：** 然后正是他们为销售团队做销售相关的用例、为客户成功团队做他们的用例扫清障碍，因为他们给了这些团队访问所有内部数据的权限。但是的，它往往会上升到他们那里。有时候它始于某个人在 Twitter 上发现了我们，或者在 LinkedIn 上看到了我们的帖子，然后他们给自己的经理看，经理再给他的经理看，我们给他们一个试点，结果比如一个小型销售团队在一周内创造的收入是之前三个月的 3 倍。

**主持人（Gustaf Alströmer）：** 你们能在没接触到决策者的情况下给他们试点吗？

**嘉宾（Gumloop 联合创始人）：** 我们必须和 IT 沟通才能让试点跑起来，对吧？

**嘉宾（Gumloop 联合创始人）：** 这就是难点所在。是的，这是我们仍在逐步学习和摸索的事情，但如果你有一个试点，他们却连不上任何工具，那没什么用。我们过去就犯过这个错误。

**嘉宾（Gumloop 联合创始人）：** 是的，你能访问的连接数量，与你使用产品的体验好坏直接相关。

**主持人（Gustaf Alströmer）：** 加入 YC 并搬到旧金山对你们来说有多重要？

**嘉宾（Gumloop 联合创始人）：** 我认为相当关键。

**嘉宾（Gumloop 联合创始人）：** 是的，[笑声] 它给了我们即时的认可，我想……

**主持人（Gustaf Alströmer）：** 是内部认可还是外部认可？

**嘉宾（Gumloop 联合创始人）：** 也许有一点内部认可，但主要是外部认可：人们会接我们的电话。你知道，在那之前我们只是两个拿着笔记本电脑的家伙，说着“是的，我们在自动化工作”，没人在乎。但它给了我们一个起步助推，让我们开始积累势头，然后还有大量指导，教我们如何把这种势头转化为更大的东西。所以对我们来说，那绝对是一个分水岭时刻。

**主持人（Gustaf Alströmer）：** 在我看来你们一直都非常有自驱力。多跟我们讲讲这一点。

**嘉宾（Gumloop 联合创始人）：** 我想那是一种对平庸的恐惧。我就是害怕 30 年后回头看，发现自己浪费了一个机会。我不知道这来自哪里。那你的动力是什么？

**嘉宾（Gumloop 联合创始人）：** 是的，我想当我大学毕业在亚马逊工作的时候，我的目标就是进一家大型科技公司，我想：“哦天哪，如果我做到了，这辈子就稳了。”于是我就去了。结果不到一周我就想：“我不可能一辈子做这个，我绝对没法在这里干下去。”因为事情推进得太慢了。我觉得一个 10 人团队交付的东西，我和我的哥们一个周末就能做出来，你懂我的意思吗？所以我必须待在一个节奏很快、能快速交付东西的环境里。这就是激励我的东西。是的。
