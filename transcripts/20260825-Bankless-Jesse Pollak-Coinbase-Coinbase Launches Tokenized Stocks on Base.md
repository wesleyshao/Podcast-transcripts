# Coinbase Launches Tokenized Stocks on Base

## Transcript

**David Hoffman：** Coinbase 推出了 tokenized stocks，这是一个很大的公告。Jesse，欢迎回到节目。请介绍一下这次公告。你们要把股票放到 Base 上，具体是什么安排？

**Jesse Pollak：** 我们认为，全世界都会逐步迁移到链上。我们正在建设 Base，希望它成为全球金融的 blockchain。股票和 equities 是世界上最大的资产类别之一，所以我们要把这些股票 token 化并放到 Base 上。

这样做以后，资产可以 24/7、全年无休地交易，全球用户都能使用，执行也会更即时、更快、更便宜。人们一开始会交易这些资产，但交易只是起点。之后，开发者可以围绕它们构建借贷体验、收益产品，甚至把 meme coin 与它们配对。我们是在把这个庞大的资产类别接入 Base 这套可编程经济，让世界各地的创新者都可以围绕 equities 构建产品。我对它非常兴奋，也预计会看到大量采用和创新。

产品名称就叫 Coinbase tokenized stocks。简单说，Base 上有一个 token，现实世界某处有一家公司的股票。两者在法律上如何关联？

我们重点确保它们是真正一比一对应的股票。每个 tokenized stock 都有一个一比一的底层代表，用户对这个底层代表拥有直接权利。我们与 Abu Dhabi 和 Alpaca 合作完成了这套安排，认为这是 token 化 equities 的最佳模型。它有望让产品更广泛地被消费者和机构采用，让市场更信任它，也让实际持有者获得更好的资产属性。

这很符合 Coinbase 的做事方式。有人对我说，Coinbase 像一支海军。有时我们行动稍慢，是因为需要把世界各地的船只集合起来，但我们一旦到来，就会以很大的力量出现，成为市场可以信赖的团队，带来最好、最值得信任的版本。这就是我们对 tokenized stocks 的处理方式。我很期待看到人们围绕它们构建什么，也期待这种信任如何带来更多采用和增长。

**David Hoffman：** 持有公司股票还涉及很多细节，例如治理权、投资者权利和股息。这些权益如何处理？

**Jesse Pollak：** 用户会获得股息，并对股息拥有直接权利，也会拥有治理权。这些 token 会再次与美国股票一比一对应。我们希望通过这个产品解锁这些属性，这也是它与市场上其他产品的重要差异。

**David Hoffman：** 假设我持有一只派息股票，股息到底怎么到我手里？是 USDC 发到钱包，还是通过其他机制？

**Jesse Pollak：** 这些 token 采用 rebasing 机制。股息产生时，会计入 stock token，用户持有的股票余额会相应增加。token 内部还会有一个 multiplier。如果有人在 token 之上构建 brokerage，就可以向用户展示这次增加的数量，以及股息为用户带来的价值，同时仍然保持一比一的股票表示。

**David Hoffman：** 这与传统券商不同。传统券商会显示本季度收到 75 美分的股息，而你们是把现金股息用于购买 Coinbase tokenized stocks，再按比例把所有人的余额略微向上调整。

**Jesse Pollak：** 对。这样做可以让这些资产更容易与 DeFi 的其他部分组合。如果只是直接把股息付出去，当股票又被作为抵押品放进另一个资产时，处理会变得复杂。rebasing 模型则能更好地解锁借贷和收益生成的可组合性。

随着更多股票上链、用户希望以不同形式持有它们，我们会继续试验。token 化的强大之处在于，它把资产带入一个几乎可以无限创新的环境。我们不知道人们会在这些 tokenized stocks 之上构建什么，但他们现在拥有一个图灵完备、全球可用的超级计算机，可以用来构建各种金融应用。未来出现的东西，可能远远超出我们今天的预期。

**David Hoffman：** 持有这些 tokenized stocks 是否需要 KYC 或地址白名单？它们是否像普通 token 一样，完全无需许可、公开可用？

**Jesse Pollak：** 它们是无需许可、公开可用的，不需要 KYC。不过，美国用户在界面层面会被限制交易。因此，各个平台需要自行决定是否做白名单或地理围栏，并为美国用户调整体验。但在 Base blockchain 上，它们会完全开放。你可以围绕它们构建任何东西，它们不会被限制在特定交易池内，也会在 Aerodrome 和其他 DEX 上可用。

我们与 Abu Dhabi 的合作很重要。双方一起研究如何在合规、可信的前提下，把它做成一个尽可能强大的可编程金融基础设施。ADGM 在当地金融创新方面非常领先，这次合作也让我们看到政府如何拥抱链上创新。

**David Hoffman：** 第一批会 token 化哪些股票？

**Jesse Pollak：** 我们先从散户需求最大的股票开始。第一批是 NVIDIA、Meta、Apple 和 Google，几天后还会再增加八只，随后继续扩大，目标是在不久之后达到数千只。最终目标是让人们可以在任何地方交易自己想要的资产。

如果 Base 要成为全球金融的 blockchain，关键就是把每一种资产都带入生态，再为开发者和交易者提供强大的工具，让他们能够交易、获得杠杆，并在资产之上构建新的金融产品。

股票价格大部分时间会在传统 equities 市场的交易时段内有最深流动性，这给 AMM 带来一个问题：当流动性停留在 AMM 中时，如何管理它？Aerodrome 团队对于如何让 LP 获得收益、同时让消费者得到足够流动性和良好价格，有一些很好的想法。我们的目标是利用它已经建设的基础设施，在链上形成股票最深的流动性。

**David Hoffman：** 产品第一天如何上线？是直接铸造 token，然后让人们购买吗？

**Jesse Pollak：** 起初只有较小范围的参与者可以 mint 和 burn。我们正在引入这些参与者，让他们准备好提供流动性，再把流动性带入更广泛的生态。随着需求增加，他们会带来更多流动性。长期目标是任何人都可以 mint 和 burn。如果消费者把股票转入 Coinbase 或其他 brokerage，就可以立即把它 token 化：既可以留在中心化交易账户内，也可以 token 化后转到平台外，开始自行使用。

这会是一个自由时刻。用户可以 self-custody 并控制自己的资产，而不是被限制在传统 brokerage 的围栏里。

**David Hoffman：** Coinbase.com 或 Coinbase app 会怎样参与？美国用户已经可以在 Coinbase 上购买股票，如果可以购买普通股票，为什么还要购买 tokenized stocks？

**Jesse Pollak：** 初期在美国仍然会是传统股票体验，因为 tokenized stocks 主要面向非美国用户。但对美国以外的市场，它是打开新市场的强大工具。把传统 equities 系统整合到产品中，成本高、速度慢，而且不同地区有不同的服务商和监管要求。把 tokenized stocks 放在单一平台上，就可以逐步在 20 个、50 个、100 个地区开启股票服务，扩大 Coinbase 能触达的用户，也能扩大 Base 的流动性。

我们看到世界各地有大量 neobank 正在出现。它们利用 crypto rails 提供美元 stablecoin 储蓄和可以在任何地方消费的卡。现在这些 neobank 正在向 neobrokerage 或 neo super financial app 转变。基于 crypto rails，它们不只可以提供美元 stablecoin 和支付卡，还能让客户访问世界各地的股票、交易 perpetuals、进行 covered call 和其他收益策略，并以 portfolio-backed loan 的方式借款。

我们希望 Base 成为这些金融产品的后端。一个金融产品只要接入一个平台，就能以最佳执行和最低成本获得全套金融产品。这包括储蓄、消费、投资，以及之后的借贷。我们已经取得了很大进展，而 tokenization 对股票的解锁会是下一步。

如果你是一家希望成为 neobrokerage 的 neobank，没有比 Base 更好的地方。我们可以帮助你提供美元储蓄、银行卡消费、股票和其他金融资产，以及信用和借贷服务，让客户可以把积累的资产转化为现金灵活性。储蓄、消费、投资、借贷的组合，会给用户带来更大的经济自由。

**David Hoffman：** Coinbase 还需要在许多司法辖区逐一处理合规，例如巴西、法国和欧盟。是否正在形成一种新的“tokenized stocks jurisdiction”，让事情更简单？

**Jesse Pollak：** 这就是 crypto 的全球司法辖区。Bitcoin 从一开始就让我们能够建设全球金融系统，Ethereum 又为这个系统带来了可编程性，现在我们正在把各种资产 token 化并放入其中。

这并不意味着每个地区都不需要合规，但从技术和底层基础设施角度看，新产品现在可以使用同一套 stack，用一个 API 完成交易、借贷或支付，而且这套 stack 在全球范围内 24/7 可用。产品可以在底层使用同一套全球金融基础设施，再在 UI 层根据美国或其他地区的要求关闭某些功能，或与当地监管机构沟通。

旧世界要求产品在每个国家获得银行通道、银行账户和用户余额，并重复一百次。这就是为什么很少有银行能横跨多个司法辖区。crypto 带来了全球、去中心化的 banking rail，开发者可以在上面构建更多产品。

**David Hoffman：** 美国股市收盘或周末时，链上的 tokenized stocks 会有什么变化？

**Jesse Pollak：** 产品本身不会改变，它仍然是与股票一比一对应的 token。变化在于流动性：传统美国 equities 市场开放时，机构更容易 mint 和 burn，也更容易设定价格。市场关闭后，我预计价格发现会逐步转移到链上。Hyperliquid 等平台已经出现类似情况，随着 Base 流动性加深，Base 也可能发生这种变化。我们会自己建立价格，而不是完全依赖外部参考价格。

**David Hoffman：** 除了 neobrokerage，你还期待开发者用这套新技术构建什么？

**Jesse Pollak：** 我觉得 Base 现在像一个 barbell。一端是现实世界资产和企业级产品，另一端是长尾 meme、纯链上创新和我们无法预先想象的产品。

在企业端，我们已经看到交易、融资和支付存在很强的 product-market fit。金融企业开始意识到，它们可以接入这套技术，让客户以更低成本交易更多资产，获得新的借贷和收益体验，并通过 stablecoin rails 实现全球支付。我们正在建设一套更偏 enterprise 的 go-to-market，与 Coinbase Developer Platform、Privy 等合作伙伴一起，为客户提供完整方案，把他们带到链上。

另一端是世界各地的 crypto innovators。他们可能用 Base 作为创新平台，利用 AI 形成一人公司，再把 crypto 当作产品创新的 rails。他们可以发行与 stock token 配对的 meme coin，围绕股票 token 建立社区，也可以让 NFT 项目分发 stock token，或者在借贷和收益生成上做更高风险、更高回报的集体化实验，例如通过互相担保获得更多信用。

我认为市场头部会继续由大型企业接入 rails，长尾则持续产生新产品。随着头部企业提供了分发渠道，长尾中起初看起来有些疯狂、分发有限的创新，最终也会向上游扩散，获得更多用户和收入。

现在我们终于拥有了想要的积木：高扩展性的 blockchain、带股息和治理权的 tokenized real-world assets，以及无需许可的基础设施。接下来主要取决于我们的想象力。三年前 Base 刚开始时，stablecoin 还在成熟过程中，tokenized stocks 也不存在，wallet 体验慢且笨重。现在我们拥有更好的 wallet、美元 stablecoin，以及来自世界各地的约 25 种本地货币，可以在链上构建本地化体验并进行 FX。

**David Hoffman：** 既然这些积木已经具备，当前还缺什么？

**Jesse Pollak：** 我仍然关注如何把世界各地的货币都带到链上。我们目前大约有 22 或 23 种货币，但仅仅发行还不够，还要围绕它们建设基础设施和采用场景。

美元 stablecoin 花了三到四年才真正形成生态，因为除了发行，还需要建立金融基础设施，让人们可以用 stablecoin 做有趣的事情。发行阿根廷比索或尼日利亚 Naira stablecoin 后，要建设分发、流动性和金融产品。

对全球 neobank 来说，非美元 stablecoin 很有价值。它可以让用户在尼日利亚拥有本地化的 Naira 余额，同时只使用一套全球 rails。现在给 neobank 充值往往需要 crypto on-ramp，美元充值可能收取 1% 到 2%，这对普通用户并不现实。更好的体验是本地货币一比一进入账户，而且用户甚至不必意识到背后使用的是 crypto。

这样，尼日利亚用户可以用 Naira 充值，然后接入由 stocks、dollars、bonds 等构成的全球经济。人们可能想投资 ETH，但不一定想一开始就持有 ETH；他们可能只想使用 Naira、阿根廷比索或自己国家的货币。Base 目前已经拥有链上最大的 FX 市场之一，但还有很多工作要做。

另一个重点是把资产和金融程序真正连接起来。现在已经有美元 stablecoin 和 equities，下一步是提供 portfolio line of credit，让用户把所有资产放进 portfolio 后，可以直接借出其中 30% 或 40%。这类基础设施已经部分存在，但仍需要把它连接起来，让消费者开箱即用。

我们也看到很多客户对 earn products 有需求。拥有美元或其他货币现金余额的客户，希望让用户获得略高于 base SOFR 的收益，例如 4% 或 5%。如果市场足够有流动性，可以通过即时清算的贷款实现相对低风险的收益。接下来可以从 earn 开始，再扩展到 borrow、equities、commodities、options 和 perps，所有服务都建立在同一套简单基础设施上。

**David Hoffman：** 这意味着会有大量创业机会，例如长尾法币进入 crypto 的 on-ramp，以及本地 stablecoin 发行方。

**Jesse Pollak：** 是的。发行本地货币的强大之处在于，像美元 stablecoin 发行方一样，可以通过持有储备产生的收益来赚取 float 收入。这样就能把 on-ramp 做到一比一，先吸引用户，再通过 float 变现。

在美国，Circle 和 Coinbase 可以提供一比一的美元 on-ramp，因为它们能赚取 float 的收益。但其他国家如果没有本地 stablecoin，就很难复制这种经济模型。一旦有了本地 stablecoin，发行方就能对每一个想在当地推出的金融产品提供一比一 on-ramp，并通过 float 产生商业收益。

这对尼日利亚本地建设者是机会。未来十年，尼日利亚会逐步上链，但不可能完全放弃 Naira，因为主权货币是国家实现政策目标的重要工具。如果有人构建 Naira stablecoin 与美国股票之间的借贷市场，就可能形成有价值的本地金融基础设施。类似机会也存在于阿根廷、巴西、土耳其等 crypto 采用率高、但目前主要使用美元的市场。
