# SharpLink & Lido: Ethereum Doesn't Need To Change Issuance (Here's Why)

## Transcript

**主持人：** 如果以一个理想世界为前提，你们会不会修改 Ethereum 的 ETH 发行机制和货币政策？现在的发行机制是否已经足够好？

**Kean Gilbert：** Ethereum 当然不是完美的，ETH 发行也不是完美的。但在我看来，还有很多事情比修改发行机制更值得优先投入时间。所有人都希望 Ethereum 在机构层面、零售层面和个人使用层面扩大采用。与其持续讨论一个未必是最高优先级的参数，不如把精力放在让 Ethereum 更容易使用，以及在 Ethereum 上建设能够带来真实采用的应用。

这不是说协议层面的研究没有价值，而是要比较机会成本。开发者和社区可以把有限的时间花在提高可访问性、降低使用门槛、建设应用和改善用户体验上。只要这些工作能够让更多人真正使用网络，发行机制是否在某个细节上最优，就不再是阻碍采用的主要问题。

**主持人：** Joseph，你们更像是 ETH 收益的使用者，而不是单纯的供应者。对你来说，当前 Ethereum 最应该优先解决什么？

**Joseph Chalom：** 当 Ethereum 感觉正在主动进攻时，应该看比分板，而不是只盯着发行机制。要看 stablecoin 的采用、tokenized real-world assets 的规模，以及 DeFi 的使用情况。现在是一个重要时刻，我愿意把时间和资金投入到推动机构采用上。

世界上最大的机构正在把资产放到链上。以前在 BlackRock 工作时，团队花了几年时间规划 BUIDL，把一个新建的 tokenized fund 做成规模最大的 tokenized fund 之一。但在我离开 BlackRock 大约一年半之后，他们已经开始把既有的 money market funds 进行 tokenization，直接把约八十亿美元的既有资产带到链上。这一批既有资产就占到当时全部 tokenization 活动中相当大的比例，说明市场已经从实验新产品，转向把成熟资产迁移到链上。

所以，我会优先支持这些真实用例，而不是马上修改协议。我还会关注怎样在 Ethereum 上建设有差异化的 Agoric offering。这个说法听起来可能像一句口号，但如果 stablecoin 是货币层，tokenized real-world assets 是资产暴露层，DeFi 和 on-chain finance 是执行层，那么自动化或 agent layer 就可能成为把大量新用户带到 Ethereum 的一层。

这些新用户可能由 agents 代表，但他们仍然是需要交易的用户。他们需要去中心化的 rails，需要在链上完成支付、资产管理和金融执行。只要交易量和真实使用达到足够规模，ETH 的 burn 自然会增加。ETH 的重要性不应只依赖一个人为调低或调高发行量的决定，而应当来自它在链上金融里作为 trust commodity 和结算基础的作用。我的重点不是改协议，而是让世界上尽可能多的人能够使用 Ethereum。

**主持人：** 具体到 Lido，SharpLink 已经把大量 ETH 放进协议并获得 Lido 的 staking rewards。Lido 也在做 enterprise 和 commercial 的机构服务。行业里最近出现了一个叫 revenue meta 的说法：协议已经有真实产品市场匹配和收入，收入来自 perps、trading、yield、staking 或 stablecoin，然后开始重新设计 token model，把 token holders 当作企业的第一等参与者。你怎么看这种变化？

**Kean Gilbert：** 这是一个很宽的问题，也有很多层次。首先，我认为 Lido 是经过实战检验的 tier-one 协议。Lido 很擅长获取反馈和认真处理反馈。任何人都可以在 Lido research forum 发帖，提出问题、获得指导或推动讨论。我可以很确定地说，Lido 的 contributors 会阅读这些反馈，并把它们当作重要输入。

Lido 长期受到的一个批评是，staking 和 stETH 产生了大量收入，但这部分收入并没有传递给 LDO token holders。过去一年，这个问题变得越来越重要，最近几个月尤其明显。Lido 已经推进 LDO buyback program，这是回应这个反馈的第一步。这个计划的目标之一，是让 token holders 能够从 Lido 产生的收入中获得更直接的利益，也让他们在协议的经济结果中拥有更明确的 skin in the game。

但这只是第一步。Lido 的 contributors 仍在研究，怎样进一步满足 token holders 的反馈，怎样处理收入、支出、透明度和治理之间的关系。Lido 是否会采取更多行动，仍需观察，不能仅凭一次 buyback announcement 就推断最终的 token value 或长期收益。

**主持人：** 你是否认为这种从叙事转向收入、产品市场匹配和 token holder 价值的变化是健康的？它会不会走得太远？

**Kean Gilbert：** 我认为这是非常积极的成熟信号。我进入 crypto 大约十年，以前行业很少认真讨论 P&L 和 risk management。过去不少项目更像是把东西投向市场，看看什么会留下来。现在机构进入这个领域，人们开始从企业和投资的角度提出严肃问题：收入从哪里来，风险怎样管理，产品是否有 product-market fit，token holders 是否应当分享协议创造的经济价值。

从 Ethereum 的角度看，围绕 institutional adoption 建设的组织也在增加。Joseph 在推动机构采用方面承担了类似 Ethereum de facto head of business development 的角色。除此之外，还有 Ethereum institutional 相关工作，以及 Enterprise Ethereum Alliance 等更正式的机构和结构。这些变化都说明 Ethereum 正在形成更成熟的商业和机构基础，而不再只是一个由个人用户和短期投机推动的网络。

**Joseph Chalom：** 我同意重点应该放在采用和真实经济活动，而不是用一次技术修改解决所有问题。发行机制当然值得研究，但如果 stablecoin、tokenized assets 和 DeFi 没有足够使用者，仅仅讨论发行量无法让网络取得长期成功。Ethereum 需要让机构能够合规地使用，让产品能够被更多人理解，让链上金融拥有更清楚的执行路径。

在一个机构真正使用 Ethereum 的过程中，机构需要稳定的基础设施、清晰的风险边界和可审计的流程。它们也需要知道 staking 的收益从哪里来，如何处理托管、流动性和治理。我们现在看到的变化，是机构不再只购买一个 token 作为叙事暴露，而是开始把它放进资产负债表、产品和金融流程里。这个过程不一定会一帆风顺，但它比单纯的价格叙事更能证明采用是否真实。

**主持人：** 过去市场里也出现过 Hyperliquid 通过大规模 buyback 让 token holders 直接受益的做法。你认为这种模式会成为新的标准吗？

**Kean Gilbert：** 它可能代表市场正在重新寻找 token 的合理经济关系。协议如果已经有真实的产品收入，却继续进行大量 emissions，同时把所有收益留在协议内部，投资人自然会问，为什么 token holders 不是这个业务的第一等参与者。另一方面，buyback、利润分配、透明度和开放性也会带来新的治理和监管问题，不能只看 token price 是否短期上涨。

Lido 的情况有自己的特点。Lido 的收入与 staking、stETH 和协议的使用相关，LDO 的治理角色、协议支出、风险管理和长期发展都需要一起考虑。buyback program 是当前可见的一个行动，但节目的讨论没有提供完整的规模、时间表或每个 token holder 能得到的确定金额。因此，这个行动可以作为需要跟踪的政策变化，不能直接当作确定收益或投资目标。

**Joseph Chalom：** 对 SharpLink 来说，核心问题是如何让 ETH 资产真正发挥作用，而不是把 ETH 当作一个静态符号。机构持有 ETH 时，会考虑收益、流动性、托管和风险。通过 staking，可以让资产在网络中参与验证并获得相应收益，但这不是没有风险的现金利息，仍然会受到 ETH 价格、协议运行、流动性、托管和监管环境影响。

我们也应该把 ETH 放到更大的链上金融背景里看。stablecoin 是资金转移和结算层，tokenized real-world assets 是把传统资产带到链上的方式，DeFi 则提供借贷、交易和其它金融执行。若这些活动增长，Ethereum 的区块空间和结算需求会增加，ETH 的 burn 可能因此增强。但这是一个有条件的机制路径，不是对价格的保证，也不是对某个时间点的预测。

**主持人：** 那么，对 Ethereum 的投资和建设者来说，当前最重要的判断变量是什么？

**Joseph Chalom：** 第一是机构采用是否真的从试点进入常态。机构把一个产品放到链上，和持续把现有资金、产品和交易流程迁移到链上，是两件不同的事。第二是 tokenized assets 是否有真实用户和交易量，而不只是发行数量。第三是 stablecoin 是否能成为广泛使用的 money layer。第四是 DeFi 是否能在风险可控的情况下承接更多链上金融活动。

**Kean Gilbert：** 对 staking 协议而言，还要看产品质量、风险控制、透明度和参与者之间的激励是否匹配。Lido 需要继续证明自己可以稳定运行，也需要让社区能够看到收入如何产生、费用如何使用、协议如何处理风险。token holders 的反馈会继续影响后续设计，但任何新的 token economic change 都应该经过明确的公开讨论，而不是依靠短期市场情绪决定。

**主持人：** 最后，ETH 发行机制是否需要马上改变？

**Kean Gilbert：** 我的答案仍然是，Ethereum 不完美，发行机制也不完美，但这不代表它是现在最值得优先处理的问题。让应用更可用、让更多用户加入、让机构能够安全使用，可能产生更大的长期影响。

**Joseph Chalom：** 我也更愿意把时间和资金放在 adoption 上。若 Ethereum 成为 stablecoin、tokenized real-world assets、DeFi 和自动化执行的重要基础层，交易量自然会影响 burn，ETH 的网络角色也会变得更清晰。届时，货币政策的讨论会建立在更大的真实经济活动之上，而不是脱离使用情况单独讨论一个参数。

这次讨论没有给出 ETH、LDO 或 SharpLink 的目标价，也没有给出确定的买入或卖出建议。节目中的判断是：Ethereum 的长期价值更依赖机构采用和链上金融扩张，Lido 的 LDO buyback program 是 token holder 价值讨论中的一个待观察行动。以上属于嘉宾观点和条件路径，不等同于已验证的财务预测或投资建议。

## 核心观点

1. 讨论者认为，当前 Ethereum 更应该优先扩大 stablecoin、tokenized real-world assets、DeFi 和机构采用，而不是立即修改 ETH 发行机制。
2. Ethereum 的潜在价值路径是：真实交易和链上金融活动增长，带动网络使用和 ETH burn，进而强化 ETH 的结算与抵押角色。这是条件推演，不是价格预测。
3. Lido 面临的核心争议是 staking 和 stETH 产生的协议收入没有直接传递给 LDO holders；LDO buyback program 是一个回应，但节目未给出规模、时间表和确定收益。
4. revenue meta 反映 crypto 项目开始接受 P&L、risk management、product-market fit 和 token holder economic rights 的检验，讨论者把它视为行业成熟信号。
5. SharpLink 作为 ETH treasury 使用者，需要同时面对 staking rewards、ETH 价格、托管、流动性、协议和监管风险，不能把 staking 收益等同于无风险利息。
