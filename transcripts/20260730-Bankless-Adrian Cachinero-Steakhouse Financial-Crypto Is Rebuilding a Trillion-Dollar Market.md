# Crypto Is Rebuilding a Trillion-Dollar Market

核心理念是，人们可以在不需要中介、不放弃资产托管，或者只允许操作方执行严格限定的事务性动作、而无自由裁量权的情况下，连接价值交换。对金融而言，这很新。只要 vault 能实现这一点，我就看好，因为它代表更高效的市场，而且我们相信它还能提供更好的投资者保护。

这里的重点不只是把传统基金包装成 token。传统资产管理通常要求投资者把资产交给某个机构，再相信该机构会按授权行事；vault 则可以把权限本身写进 smart contract。操作方可以负责执行，但不能随意挪用资金，用户也不必因为寻求专业管理就完全交出 custody。对我们来说，这种把“执行工作”与“资产控制权”拆开的能力，才是 vault 真正的新意。

Morpho 也许不是第一个发明者，但它开创并普及了借贷的隔离风险市场（isolated risk market）。这个思路早已在不同场景里被试过，Morpho 把它正式化，给了它合适的 go-to-market，并找到了产品市场契合。

隔离借贷市场的难题是，它会失去池化借贷模式的很多网络效应。例如 Aave 把流动性集中到同一池子，就能对抵押品进行再质押：用户既可以存入抵押品，又可以同时以它借款。Morpho 在隔离模式中失去了这部分网络效应，于是用 vault 把多个隔离市场的流动性聚合起来，重新打包并找回一部分网络效应。

**David：** 可以说，Morpho 创造了市场的基本原子单元，而vault 把它们组合成更大的结构。对 vault 行业的基础来说，隔离借贷市场非常重要，因为它们可以很精确、很有偏好地拟合不同市场需求。当借贷市场被拆到最基础层，就能用这些隔离风险原子单元建起更稳定的上层结构。这样形容准确吗？

**Adrian：** 完全准确，这也是我们很认同的哲学。DeFi 中效果最好的实验往往都走向这个方向。智能合约是非常敏感的基础设施，一旦出错就会错得很严重，所以应尽可能缩小风险面。

DeFi 早期有很多治理很重、由 DAO 高度控制的模式。Morpho 的做法是追问：能不能把智能合约简化到像一张电子表格？我只要一条公式，计算一端累积了多少利息、另一端应付多少，然后就停在这里。这会大幅缩小风险面。代价是失去网络效应，但它可以重新组合，稍后再用 vault 打包。

这也是“原子单元”思路的重要性：底层合约越简单，越容易审计和复用；复杂性不必消失，而是被移到上层、由不同 vault 按自身目标重新组合。用户可以选择更简单的组合，也可以选择愿意授予管理人更多权限的产品，而不是让所有人共同承担一个巨大协议中所有治理选择的后果。

**David：** 那么网络效应只是在技术栈更高层重新出现。单个 Morpho 市场没有太多网络效应，但当这些原子单元在 vault 中重新组合，网络效应就会涌现。

**Adrian：** 没错。Morpho Blue 隔离借贷市场里的单笔借款仓位几乎没有网络效应。当它们被汇总进 vault，使用同一 vault 聚合流动性的人越多，价值增长就越快。流动性增加后，可发放的贷款更多；贷款更多后，市场变得更高效，于是又吸引更多参与者。

单个仓位的价值不会因为旁边多了一个用户就明显提高，但 vault 会。更多存款让它能覆盖更多借贷市场，更多借款需求又改善资金利用率和价格发现。网络效应并未消失，只是从单一隔离市场上移到了流动性聚合层。这种分层让协议既能保留隔离风险的边界，又能重新获得规模经济。

**David：** Morpho 做出隔离市场，vault 把它们组合起来。那么 vault 通常在哪里被创建、又在哪里被用户访问？

**Adrian：** Vault 在很多地方。Morpho vault 只是其中一种。最简单的理解是，vault 是一种为特定目标聚合流动性的 token。从这个定义开始，才能分辨各类 vault 的差别。

我们很喜欢 Morpho vault，因为它简单、极小化，也不依赖复杂治理。当然，vault 也可以更复杂。例如 Veda vault 有更复杂的执行层，它同样用 vault 聚合流动性，但给操作方更多行动选项和自由裁量空间。用户可以在 vaults.defiy.com 等地方比较不同产品，Beefy 也创建很多 vault。就像 token 一样，选什么取决于你要什么。

**David：** 那么 Morpho、Veda 和 Beefy 可以统称为 vault infrastructure。最底层是 vault 基础设施，它产生许多隔离借贷市场，或者像 Veda 那样稍微带有更多偏好。往上一层是 curator，这里才可以表达很多观点。请先从最 Cypherpunk、完全非托管、最安全的一端开始，再逐步走向更有管理偏好、裁量权更大的另一端。

**Adrian：** 如果用户想保留最高程度的托管权和控制权，没有任何东西阻止他们自己直接在 Morpho 市场借贷。但这样做有交换条件。

一个 Morpho 借贷市场的目标通常是任何时候都有约 90% 的流动性被借出，实际比例会随供需波动，但均衡水平大约就是 90%。这意味着任意时点只有约 10% 可以提取。如果你的单笔头寸比这 10% 还大，又只配置到一个市场，就可能无法一次取回全部资金，因为其中一部分正在被借用。

使用 vault 后，用户可以同时访问多个市场，享受跨市场共享流动性。这就是把流动性聚合到更高层的收益。用户也可以只为自己建一个 vault，自己是唯一存款人。这是很简洁的抽象，交互也很容易，同时可以把多个借贷市场的网络效应重新组合，并获得额外流动性保护。

这里并不是承诺 vault 里所有资金都能随时提取。如果底层市场约 90% 资金已被借出，流动性约束仍然存在；差别在于 vault 可以在多个市场之间重新配置，让一个市场的可用资金弥补另一个市场暂时不足。对大额存款人而言，这比把全部资金压在一个隔离池里更稳健，但仍必须理解底层借贷期限、利用率和清算风险。

这可能是最 Cypherpunk 的做法：自己建 vault，自己配抵押品，自己调整借贷市场。Morpho 的门槛几乎为零，只要知道如何与智能合约交互，就能自己“打印”一个 vault。

Steakhouse 处于这层上方的紧邻一层。我们不愿说自己是 vault 中介，因为我们并不站在借款人与贷款人之间。我们运行后端基础设施，使 vault 保持平衡，并驱动高效借款利率的价格发现。这种再平衡对借款人和贷款人都有价值，因为双方能更快、以更低利差找到彼此。

但 Steakhouse 也会尽量降低自己干预 vault 的能力。Morpho vault 最大的干预向量是新抵押品市场的引入。Curator 如果建议新增一种抵押品，对 vault 用户而言就是一个新风险源，而且这个治理杆杆原本只有 curator 能操作。

因此，Steakhouse 的价值不是“代替用户持有资金”，而是持续做再平衡、借款利率发现和市场选择。借款人希望更快找到资金、支付更低 spread，贷款人希望资金利用率更高又保留安全垫。Curator 的专业工作让双方更快匹配，但又必须防止这种专业权力演变成对用户资产的无限管理权。

**David：** 这就是你们的专业领域，可以详细说。

**Adrian：** Steakhouse 对 vault 的看法是，用户使用 Steakhouse vault，是因为不想自己做再平衡、价格发现等复杂工作。这些工作绝不简单，非常繁琐；但用户又不想承担中介风险和托管风险。所以我们一直思考，如何让自己尽可能不成为 vault 用户的交易对手。

一种做法是通过 veto 机制，让用户有能力停止我们的决策。我们在 vault 周围建立一个 Aragon DAO，让 vault 用户参与其中。如果他们不同意我们拟议引入的某种抵押品，就可以阻止这个决定。这类链上机制的目标，就是把 curator 的自由裁量从方程式里拿掉。

这个流程并不要求每个存款人每天主动管理策略。Steakhouse 仍负责提出抵押品和参数方案，用户通常只需接受并继续留在 vault，或者选择退出；只有在极端情况下才动用 veto。与传统基金相比，重要变化是用户对新增风险拥有可执行的制衡，而不是只能在损失发生后追究管理人。

还可以继续往另一端走。Vault 归根结底是一种聚合流动性的抽象，与传统金融中的 ETF 并不完全不同。ETF 也是流动性聚合器。未来某些 vault 可能会替代或竞争 ETF，某些则可能存在托管。一些 vault 基础设施平台已经运行受监管基金，他们可能在 Machina 或 Veda 上运行，主要是因为链上头寸的会计处理更简单。

所以范围非常广，谈论 vault 时必须明确是哪一种。大多数 vault 的共性是：更方便的会计、理想情况下对底层头寸的透明暴露，以及长期上更好的投资者保护和整体市场效率。

**David：** 你形容 Steakhouse 在 vault 中的角色时，它似乎与 Aave 和 Yearn 都有很大重叠。Aave 必须管理引入新抵押品的风险，无论是隔离市场还是跨保证金抵押品，都需要治理决策。Yearn 则专注于收益优化。Steakhouse 似乎位于两者的交叉处，使存款人得到更好收益，使借款人支付更低利率。这个比较准确吗？

**Adrian：** 这是合理比较。但在 Aave 和我们运作的借贷市场，也就是我们称为回购协议市场（repo market）的地方，目标未必是最大化收益，更多是最大化底层借贷市场的效率。

如果你愿意，可以说 Aave Labs 就是 Aave 的 curator。Aave 有新抵押品上线流程，对部分决策和区域保留控制，同时也有降低自身作为交易对手风险的机制。这就是 Aave 价值主张的一部分。用户如果想参与决策，可以成为 AAVE token 持有者并投票。两种模式处理的实质很相似，只是方式不同。

**David：** Aave 可以被称为一个完成垂直整合的巨大 vault 吗？

**Adrian：** Aave 确实是最大的 curator。我们喜欢说自己是最大 curator，但现实是 Aave 更大。

**David：** Aave 是 Aave vault 的 curator。Steakhouse 的不同是把治理权直接与存款人整合，存入 Steakhouse curator vault 的人同时拥有你前面所说的否决权。而如果我把 ETH 或 USDC 存入 Aave，并不因此获得治理权，只有 AAVE token 持有者有。但除这个区别外，它们都有治理、风险管理、抵押品选择和利率效率优化，只是产品形态不同。

**Adrian：** 这个对比刚好说明 vault 构造有多灵活。它几乎可以以无限种方式搭建，因此很难用“vault”一个词精确涵盖所有产品。Aave 还有 Umbrella、安全模块、两种治理 token 等复杂机制。我们建在 Morpho 技术栈上，风险面简单得多，当然也有相应代价。用户可以根据自己需要选择，但在核心功能上，两者都是流动性聚合 vault，底层原语都是借贷市场或借贷活动。

**David：** Steakhouse 在做 curator 时，必须做出关于产品形态和行为的管理决策。你们对风险和抵押品接受有怎样的哲学？哪些参数需要管理，你们如何画出可接受与不可接受的边界？

**Adrian：** 我们的方法与 Aave 的抵押品引入流程不会太陌生。最简单的理解是，它是一套框架，而不是抵押品上线后就每天不断进行主动管理。最关键的转折点是引入抵押品的提案，之后市场会围绕它自己形成均衡。

有些抵押品市场上线后完全没有人用，那就是失败产品。Aave 也有很长一串无人使用的抵押品市场。另一些则会吸引大量使用。在 repo market 中，借款人是在寻求风险，贷款人是在寻求安全。我们的目标是尽可能降低贷款人本金的风险。

降低风险的杆杆很多，最重要的是 haircut，也就是折价安全垫。借款人不能按抵押品价值的 100% 借款，而是必须承受一定比例的折价。这为贷款人提供缓冲和时间，使贷款有机会在抵押品大幅贬值前被偿还或清算。我们通过抵押品选择来保护本金，再让市场在这套边界内找到最合适的均衡。

抵押品评估主要看底层资产的信用风险，以及具体贷款的市场与平台风险。某种资产可以没有太多信用风险，但以它建立的借款头寸仍然可以很危险。例如 wrapped Bitcoin，我们认为它的信用风险很低，由 BitGo 托管，流动性也很好。但如果你以 98% 的贷款价值比（loan-to-value，LTV）引入它，2% 的 haircut 可能根本不足以阻止坏账落到贷款人身上，所以整个头寸仍然过于危险。关键是在资产质量、LTV、流动性和清算时间之间找到平衡。

Aave 的风险团队会采用相近方法，但其参数讨论通常需要与 token holder 社区反复互动。Steakhouse 的流程更接近二元选择：我们提出方案，用户满意就继续参与，不满意可以退出，极端情况下可以否决。抵押品是否优质只是第一层问题，还要看可借比例、市场深度、价格预言机、清算机制，以及治理者能否突然改变资产规则。

**David：** 其他 curator 接受了哪些 Steakhouse 不接受的风险参数？距你们最近的边际风险承担者，正在接受哪一类你们认为不合适的东西？

**Adrian：** 很多抵押品市场很成功，信用增强也足够，可能完全没问题，只是我们没时间研究，或者暂时还没有足够理解。Steakhouse 没上线某种抵押品，不代表它就是坏资产。

大多数情况下，我们更偏好受监管或某种形式监督的资产，或者有很强链上保证的资产。我们会审计项目治理结构。最近我们与 EtherFi 就经历了一次很好的例子。之前我们把它归入高收益抵押品，EtherFi 主动来问：“我们想被视为 prime collateral，你们认为 prime 需要什么？”

我们的答案是：你们的管理层必须变得更不方便。对 token 的管理裁量权必须显著减少，用户必须有充分时间退出，或至少有充分预警来理解即将实施的变化。具体做法包括设置很长的 timelock，以及为 minter 等关键角色增加治理防护。EtherFi 接受了这些要求。这是一个从高风险向 prime 升级的例子，而不是被拒绝的例子。

**David：** 我之前与 Herod 的 Andrew 谈 vault 时，讨论了 vault 业务一个非常基础的激励：每家公司都想新增下一个边际 vault。所有 vault 都有风险，有些很低，有些更高。Curator 通常从 vault 收益中抽成，所以想增加 TVL，也想增加 vault 收益率，因为这会让自己赚得更多。它们当然会设置风险上限，但增加 TVL 和 APY 的激励永远存在，也就是默认存在增加风险的激励。你们怎样阻止自己的风险范围不断蔓延？

**Adrian：** 我们过去想了很多。我希望行业已经跨过一个拐点。过去几年，这个问题确实不断发生。但 DeFi 也有快速学习和自我修复的能力。Stream Finance、Elixir 和 10/10 那样的风险事件，就是上一轮高风险 vault 出清的催化剂。

每次出现这类事件，我都希望普通 DeFi 用户会重新理解，最高 APY 未必最好，应该看清 vault 底层究竟暴露于什么。只要用户的风险容忍是完全无弹性的，无论多大风险都只挑更高 APY，那么 curator 就有反向激励，会不断引入更多乱七八糟的资产，最后必然爆掉。我希望用户已变得更有辨别力、更愿意思考风险。Andrew 等人建立的工具正在帮助用户自己评估 vault 内容。

**David：** 我同意 DeFi 有自我纠正机制，但不愿意把责任交给用户。永远会有新手、年轻用户和经验较少的人。Crypto 想做的是让全世界进入链上，而现在只有很小一部分人经历过你说的这些周期。风险管理、审查 vault 的责任可能应该落在技术栈的其他位置，才能大规模扩张。我们的目标不是压制 vault 生态某一端来保护另一端，而是同时把收益和安全做到尽可能高。如果新用户必须自己审查每个广告给他的 vault，这个行业怎么大规模扩张？

**Adrian：** 这是公平的批评。我并不是要把责任踢给用户，只是说，你所描述的不良激励，只有在用户按特定方式行为时才能持续。历经多个周期后，更冒险的 curator 应该会淘汰，剩下的则是累计为用户做出了更好决策的人。

我们希望 Steakhouse 在五年后仍在剩下的那批 curator 中。这就是我们脚下的火：不要搞砸，继续做出好决策。Curator 确实对不做坏决策负有很大责任。对 repo market 来说，决策主要是要承担多少抵押品风险。我们认为不应该承担太多，也没必要引入 Stream Finance 或 Elixir 那样的异常复杂风险。只需要把少数事做好。

我再强调一次，我们不把目标称为收益最大化，而是市场效率最大化。当 vault 为借款人和贷款人带来更高效的市场，并通过 vault 结构提供更好的投资者保护时，它才算成功。这是我们的两个关键价值主张。

**广告：** 主持人介绍了 NEAR。他说，自己在过去十年中用过很多钱包、交易所、聚合器和前端，一直想找到一个同时拥有跨多链与多资产深度流动性、隐私交易和资金自主控制的统一界面。他认为 near.com 让用户能从任何链执行操作，同时保持活动机密。广告称 NEAR 已用后量子签名方式处理超过 230 亿美元跨链资产，并稳定运行超过五年。该内容明确声明不构成投资建议。

第二段广告介绍 Bitget Stocks 2.0。主持人说，市场往往在 Bitcoin、NVIDIA、黄金和 S&P 之间轮动，但交易者仍在不同平台、账户和资金池之间分散管理组合。Stocks 2.0 让用户在同一应用里用 USDT 交易 tokenized equities，广告声称费率为 0.04%，并按一比一提供对底层股票的经济暴露，股息、拆股等公司行为会自动反映在头寸中。该内容同样明确声明不构成投资建议。

随后，主持人介绍了新播客 The DeFi Report。他说 Michael Nadeau 是自己认识的最好的 crypto 周期投资者，在 10/10 价格下跌前向他发出了卖出警报。两人每周讨论投资组合、市场结构、入场目标、Bitcoin 和 Ether 的公允价值，以及市场处于周期何处。最后，主持人推广了 Bankless Premium RSS，说付费订阅包含他为 Bankless Ventures 和个人组合所做的额外研究访谈，并且无广告。

**David：** Curator 与存款人之间是否存在 principal-agent problem，也就是双方对风险的暴露并不对齐？Curator 通常从收益中抽取绩效费。如果 vault 收益率是 6%、7% 或 8%，curator 从中拿一部分作为收入。但如果 vault 被攻击，或风险管理不当，curator 除了未来费用收入受损外，未必损失本金，而存款人会损失本金。这个委托代理缺口应该如何弥合？

**Adrian：** 的确存在 principal-agent 差异。用户是委托人，使用 vault 就隐含着把运行 vault、选择抵押品的责任委托给 curator 这个代理人。

对低风险 vault 而言，差异较小。例如只对 BTC 和 ETH 做超额抵押贷款的 vault，核心更多是效率，而不是信用风险。对高收益、高风险、低流动性 repo market 而言，不对称就显著得多。

这种不对称来自收益与损失的不同分配方式。Curator 的上行收益通常是持续收取一部分利息或绩效费，下行损失首先由存款人的本金承担。即使 curator 因品牌受损失去未来业务，这种损失也不会自动补偿已经亏钱的用户。因此，产品越依赖管理人的判断、底层抵押品越不透明、流动性越差，就越需要额外资本、保险或可执行的责任机制。

Steakhouse 作为一家公司，把自己的资金全部配置到自家 vault，而且公开承诺在出现损失时最后退出。这是因为 vault 在违约情况下的损失分配机制并不完美。具体取决于 vault 配置和坏账计算方式，有时损失会更多落到最后留下的人身上。

**David：** 这就会发生银行挤兑。

**Adrian：** 没错。先退出的人可以完整拿回资金，剩下的人留得越久，所承担的资产减值就越大。所以我们公开承诺，自家财库全部在自家 vault 里。如果是我们搞砸了，我们就会尽可能多承担损失。

**David：** 这个做法的确缩小了缺口，但它是你们自愿承诺，并不是结构性修复，也没有通过密码学强制执行。

**Adrian：** 没错，它不是结构性修复，我也并不满意。Vault 的优势就是密码学强制执行，而这只是一项社会承诺。当然，如果 curator 给存款人造成损失，即使 curator 没有直接亏掉本金，也不等于没有经济损害。它的未来业务前景和品牌价值会严重受损，甚至归零。已经有 curator 从行业领先者变成完全关闭。

但对真正丢钱的用户而言，curator 的品牌价值归零并不能帮他们拿回本金。所以我理解这个问题，也认为密码学机制更好。

应该采用多强的机制，要看 vault 类型。如果管理人有完全自由裁量权，可以随意新增或删除策略，那么至少应该通过密码学强制设置缓冲资本、盈余、保险或第三方监督。如果只是一个针对 Bitcoin 和 ETH 的 prime vault，且只做超额抵押贷款，是否值得为此牺牲市场效率，就未必。两者之间还有很大范围，所以必须精确说明讨论的是哪种 vault。

总体上，我们更偏好密码学机制，而不是社会承诺。社会承诺不是没有价值，但与密码学保证比较就不完美。我更愿意有一种机制，能确定无疑地 slash curator，并让用户直接受益，而不是只能口头承诺。现在行业已有很多提案试图解决这个问题。

**David：** “Vault”这个词之所以难谈，是因为它覆盖的范围几乎没有边界。风险谱的一端，是只接受 Bitcoin、ETH 等高质量 crypto-native money 的超额抵押 vault；另一端则可能把存款人的钱直接打进一个外部账户（externally owned account，EOA），由管理人转到银行账户并全权投资。后者的管理裁量和信任要求都非常高，而中间还有无数种组合。

机构、Wall Street 和 TradFi 已经看见 vault 的价值。短中期内，这个行业的 TVL 可能增长到数千亿美元。未来五年，增长会集中在接近完美安全的超额抵押 vault、风险适中的产品，还是更接近传统受托资产管理人的高风险产品？

**Adrian：** 这个答案可能不够刺激，但我们预计更“无聊”的 vault 会增长得更快、规模也更大。Vault 基础设施的规模效应在标准化、低风险市场中最明显。现在链上已经有受监管 hedge fund 通过 vault 运作这种位于风险谱极端的产品，反而还没有一个足够高效的链上美国国债隔夜回购市场。这是一种倒置：高风险的小市场先出现了，支撑金融体系的基础层却还没建好。

传统 repo market 每天承载的是数万亿美元活动。我们最兴奋的方向，是先让链上市场达到传统市场的效率，再利用透明、全球可访问和可组合的特点进一步提升效率。相较于追逐高 APY，这些无聊、学术化、位于金融底层的业务反而最有吸引力。

**David：** Hester Peirce 最近对 vault 提出了一些根本问题。Curator 是否实际上在充当资产管理人？他们是否从事类似证券或投资公司的活动？她建议每个 curator 都问自己，当前行为是否已经等同于 investment company 或 asset manager。按照你的判断，监管最担忧的可能只是 vault 市场高风险、degen 的边缘，而不是未来规模最大的低风险主体，对吗？

**Adrian：** 可能如此，但 Hester 的 memo 很有思考，我们会接受邀请去与 SEC 交流。Vault 的确可以被视作一种资产管理，我们称之为“互联网原生资产管理”（internet-native asset management）。它与传统资产管理相似，但在一些有意义的方面是新的，因此值得重新审视。

她说得很对：不能为了规避现行法律而做各种法律上的“翻跟头”。不过，链上 repo 和 vault 也确实能用传统框架没有覆盖的新机制保护贷款人与用户。风险低并不代表管理人没有自由裁量，也不代表产品天然符合证券法。同一种低风险 vault 可以合规地构造，也可以因构造不当而违法，所以必须认真设计。

如果产品按照 Hester 所描述的原则配置，用户会得到更多保护，curator 与用户之间也会有更清晰的隔离。这正是 vault 存在的理由。Mutual fund、hedge fund 和 ETF 已经存在，没有必要为了上链而重新复制一遍。只有当 vault 能实质改善用户或投资者的处境时，才值得采用。

**David：** 那么，vault 行业与 SEC 之间还有哪些问题没解决？谁承担法律责任？某些管理人是否只需注册为 hedge fund 或 investment manager 并承担责任，还是链上产品的特殊性需要一个新类别？

**Adrian：** 更可能需要行业与 SEC 坐下来逐项厘清。Vault 是一个非常宽泛的词，其中几乎肯定有参与者从事现有证券法已经覆盖的活动，这些参与者可以直接使用现有注册框架。Steakhouse 一直尽量认真评估自己的情况，我们不认为当前业务落在该范围内，但我更愿意先和 SEC 确认。如果确实需要登记，那就登记，没有问题。

问题不能靠给所有 vault 贴一个统一标签解决。一个仅由个人自用、规则完全由合约锁定的 vault，与一个把资金交给管理人、允许其自由交易的 hedge-fund vault，在经济功能和风险承担上截然不同。后者很可能已经落入现有资产管理法规，前者却可能只是用户管理自己资产的软件。监管讨论需要先按实际功能分类，再决定登记、披露和责任要求。

与此同时，vault 中也有值得单独考量的新元素。法律责任、保险和信息披露制度，都是现行监管体系中重要的投资者保护，但纯粹的 vault 市场还没有完全对应的机制。并非所有 vault 都应该达到同一标准，但行业很可能需要一定程度的标准化和最低要求。

监管也不能把开放创新一并封死。Vault 的重要特征之一就是进入门槛很低，个人可以创建仅供自己使用的 vault。法律如果连这种用途都禁止，会损害竞争和创新。希望监管者能同时看见这一点。

行业真正需要的是与风险和权限相匹配的保护。管理裁量越大，越应该明确法律责任、信息披露、保险和独立监督；权限已由合约严格锁定的产品，则可以更多依赖链上透明度和即时执行。最低标准能提高用户信任，但如果标准高到只有大型机构才能创建 vault，就会失去开放网络允许小团队和个人实验的价值。

**David：** 我把 vault 的未来归纳成两条主线。第一条是低风险端：Apollo、BlackRock 等机构以优质抵押品进入，用 stablecoin、Bitcoin 和 ETH 在链上重建 repo market。它有机会在长期扩张到数万亿美元，并进一步改变 stablecoin、Bitcoin 和整个链上经济的规模与经济性。

第二条在风险谱另一端。Hedge fund 式 vault 给管理人更多裁量，也更吸引追求收益和风险的 degen。要让这部分大规模增长，就必须建立法律责任、保险、资本结构和消费者保护。低风险链上 repo 的潜在规模明显更大，但两条路线会并行发展。

**Adrian：** 这是合理的框架。使用 blockchain 的核心理由，是用密码学保证（cryptographic guarantee）替代“相信我”的承诺、社会性承诺，甚至法院事后执行的承诺。Ethereum 这类网络提供的保证具有确定性、终局性和即时执行性。

这意味着 vault 可以在聚合流动性的同时，强力限制管理人的自由裁量。例如在 hedge fund 场景中，正确配置的 vault 可以通过合约保证管理人不偏离授权范围，或者规定只有独立 administrator 才能修改策略。Vault 不仅能扩大 repo market，也能实质改善投资者保护。

当然，密码学保证也有反面。如果用户把 stablecoin 转进 Stream Finance 那样的黑箱，就等于把全部管理权交给某个人，资产可能就此消失。但同一种技术也可以严厉限制管理人，使产品甚至比传统 hedge fund 更安全。传统金融的“墓地”里同样充满了偏离授权或过度冒险而倒闭的 hedge fund，crypto 并不是凭空发明了风险。

**David：** 我理解你的意思是，先把低风险、可规模化的 repo 基础层做大，行业就会获得更成熟的工具和网络效应，再逐步把这些密码学约束带到风险更高、管理裁量更多的产品中。这样不必完全依赖社会契约和法院，也能保留 Cypherpunk 的特征。

**Adrian：** 对，但这不意味着可以否认法律责任或规避监管。恰恰相反，vault 可以更快、更安全、更明确地执行监管要求和投资者保护。它能够把原本只写在披露文件里的限制直接编码并强制执行，形成比单纯信息披露更强的制度。

例如，传统基金文件可以承诺不偏离某类资产或风险上限，但管理人仍可能先违反授权，投资者只能事后诉讼。Vault 可以让不符合授权的交易在技术上根本无法执行，或者要求独立管理员与 timelock 共同批准策略变更。法律规则仍然存在，只是其中一部分从事后追责变成事前阻止。

Trustlessness 和 permissionlessness 的价值，在于降低搜寻成本、摩擦和价差。Vault 聚合流动性后，可以更快找到市场效率的均衡点，同时又提供很高程度的投资者保护。法律责任不会神奇消失，但它可以被更清晰地编码和执行，而不是等待两年才得到法院和解。如果确实需要对管理人采取行动，vault 也可以提供无需先经过仲裁或法院的执行工具。

理想状态下，先约束管理人的行为，就能减少系统中的总信用风险。不过，法律仍会在边界情形发挥作用。重点不是消灭责任，而是尽量降低需要依赖事后司法救济的频率和损失。

**David：** 最后谈谈 distributor 与 curator 的权力平衡。Robinhood、Coinbase、Kraken 这样的消费者前端聚合了大量存款，掌握高价值的客户关系，因此可能拿走相当大的收益分成。后端 curator 的利润会不会被压缩，甚至威胁 vault 商业模式？

**Adrian：** 每条价值链都存在向上下游延伸的压力。某一方积累超额利润时，另一方就会尝试进入它的环节。Aave 作为最大的 curator 就有动力推出自己的 savings app，不再完全依赖 Robinhood 或 Coinbase，而是部分争夺端到端客户关系。

分成压力取决于谁掌握稀缺能力。消费者前端拥有流量、品牌和存款入口，因此议价权很强；curator 则掌握抵押品研究、持续监控、再平衡和风险声誉。前端如果把 curator 的工作当成标准化商品，会压低后端利润；但一旦产品发生信用损失，前端也会承担客户关系和品牌代价，所以它需要可靠的专业合作方。

但垂直整合不是唯一结果。专业化也能提高整体产品价值。Curator 是范围较窄、难度又不低的专业活动，对 Coinbase 这类平台而言，为了吃掉最后一点利润而自建整套能力未必值得；较小平台也可能没有技能或意愿，只想快速为用户提供 earn product，把精力放在客户体验上。

Steakhouse 与 Robinhood、Coinbase 等合作伙伴目前更多是建设性协作。我们不会主动去和这些前端竞争。只要 curator 的专业能力足够独特，它在可预见的未来仍有价值。当然，如果利润过度集中，价值链仍可能向另一方向整合。

**David：** Steakhouse 或类似公司被大型平台收购，并被垂直整合的概率有多高？

**Adrian：** 有可能。但 Steakhouse 与很多 crypto 公司不同，我们没有 VC 投资，是一家家族企业，所以习惯用“世纪”衡量时间。我们不需要为了投资人的退出期限经营，而是希望把业务做到尽可能大，为用户创造最大价值。也因此，要买下 Steakhouse，出价就得更高。

我们的目标是提高市场效率、增加投资者保护，并通过持续提供价值来扩大规模。并购和垂直整合是任何行业的压力，但 vault 管理还没有走到大规模整合阶段。成长中的行业通常会推迟整合，因为机会仍在扩张，更多参与者可以找到自己的细分市场。

Aave 是最大的 curator，但 Steakhouse 在不到两年里已经做到与其可比较的规模。市场还会扩大，会出现 Aave、Steakhouse 都没有覆盖的新垂直领域。整合最终会发生，我们并不反对，也不会拒绝足够有吸引力的收购，但经营时间表非常长，首要目标仍是对用户负责。

David 进一步追问，如果 Steakhouse 不愿出售，Robinhood、Coinbase、Kraken，甚至 BlackRock、Apollo、Vanguard 是否会直接招聘团队或收购竞争者。Adrian 承认这种压力真实存在，但认为快速增长会先扩大机会集合。只要新资产、新分发渠道和新风险垂直仍不断出现，专业 curator 就能继续找到尚未被大型平台覆盖的位置，行业整合不会立刻完成。

**David：** AI 会怎样进入 vault 业务？更多数据和智能能否把大量人工工作交给 AI？

**Adrian：** AI 会深度参与，它已经显著加快了我们的研发和工作节奏，团队的可扩展性还会继续提高。但我现在不会把资金放进完全由 AI 自主管理的 vault。

**David：** 这可能像放射科医生。早期有人认为 AI 会取代 radiologist，因为识别影像更准确，结果需求和供给反而增长了。关键不仅是谁读得准，还在于需要一个专业人士对最终答案负责。未来可能不是 AI 真正担任 curator，而是 AI 帮 Steakhouse 做分析，最后由 Steakhouse 盖章并承担责任。

**Adrian：** 这类似 Jevons paradox。效率提升会加速使用和能力增长，让更少的人完成更多工作。市场对 vault 的需求仍然很强，所以 AI 更可能增加 vault 数量，而不是消灭 curator。

**David：** 未来 18 个月，Steakhouse 最重要的增长机会是什么？外部资本和 TradFi 都在看这个市场。

**Adrian：** 大方向是继续做好现有工作。我们已经把自己定位成 fintech 与 distributor 的产品和专业后端。接下来最感兴趣的是现实资产如何进入这一体系。

这意味着 Steakhouse 不准备靠不断推出高 APY、靠积分补贴的短期产品增长，而是希望成为平台可以长期嵌入的基础设施。Fintech 负责用户体验和分发，Steakhouse 负责底层市场、抵押品和风险框架。现实资产进入后，vault 之间不再只是奖励积分不同，而会因资产质量、期限、流动性和监管结构形成真正差异。

我很高兴行业开始离开 point farming，转向常规、实实在在的 carry trade。这会改变 vault 的性质，让不同 vault 之间的差异更明显，同时也增加产品复杂度。监管者正在关注这一领域，行业需要留出空间，让他们理解并负责任地处理。短期内，我们想做的是减少积分游戏，增加真正的资产和真实收益。

**David：** Vault 业务里，什么问题最让你睡不着？

**Adrian：** 信用风险事件。即使事件没有发生，这种压力也一直存在。我们每天检查 vault、流动性、抵押品和价格预言机。这是一份很有压力的工作，我不会轻易推荐给别人。

风险监控不能只看 APY 或 TVL。团队要持续确认抵押品是否仍有足够流动性、oracle 是否正常、市场价格是否偏离、借款利用率是否逼近无法提现的水平，以及某个治理变更是否改变了资产的信用属性。真正让人失眠的往往不是已知波动，而是这些变量在全天候市场中同时恶化。

Steakhouse 是全球化团队，在澳大利亚、非洲、香港、美国和欧洲都有人。随着太阳跨越时区，团队会像接力一样交接监控。大量工作已经自动化，但仍然保持 human in the loop，我们一直有人盯着系统。

自动化可以持续发出流动性、价格和抵押品异常警报，却不能独立承担最后的风险判断。全球团队的意义，是让每个时区都有人接手告警、核对上下文并决定是否干预，而不是把 curator 责任完全交给一个无人值守模型。
