Patrick O'Shaughnessy：你在硅谷有没有看到一些更长期的效率创新？无论是推理服务、模型训练，还是其他环节，它们未来会怎样影响公开市场？

Gavin Baker：很多人似乎认为，continual learning 和 sample-efficient learning 已经接近突破。如果这两件事解决了，训练需求可能暂时出现不连续变化。有人告诉我，过去一个重要系统大约用 200 亿 token 训练，而今天的大模型可能使用 300 万亿 token。假设未来只需要先用 10 万亿 token 训练，再让模型进入现实世界后高效学习，初始训练需求显然会下降。

Gavin Baker：不过，训练占半导体和总算力需求的比例，长期会收敛到一个不为零、但相对很小的数字。continual learning 到底会在短期还是长期实现，我们还不知道。SSI 表示会在 8 月发布模型，还有一代新实验室专门研究这个问题。

Patrick O'Shaughnessy：这对世界是好事。

Gavin Baker：会是非常好的事，我们当然希望它发生。我只是很难相信它最终会降低 AI 基础设施的总需求。但我仍然把它当成最重要的潜在技术反证之一。NVIDIA 与许多研究这类技术的创业公司合作得很深，Safe Superintelligence 也已经开始与 NVIDIA 合作，所以 NVIDIA 并不是站在变化之外。

Patrick O'Shaughnessy：如果一定要列出一组能彻底改变你观点、让你真正害怕的条件，会是什么？最核心的是经营现金流没有按预期增长，导致整个建设周期必须靠债务融资吗？

Gavin Baker：经营现金流不能继续加速，肯定是负面信号。它又取决于 Anthropic、OpenAI、Grok、Cursor 和开源模型的总需求。如果 GPU 价格出现持续的大幅下跌，市场会立刻反应，那也很令人担忧。如果 GPU 开始很容易拿到，也是明确反证。但你有没有听过任何人说自己 GPU 太多？一个都没有。现实反而像某种稀缺品地下市场，所有人都在找货。

Gavin Baker：如果所有主要实验室的需求总和平台化甚至下降，那就非常负面，除非只是开源 token 在扩大总盘子的同时抢走份额。我认为未来一定是多模型世界。AI 原生公司会拿开源模型，用自己的数据做 supervised fine-tuning 和 reinforcement learning，然后放到 router 后面。router 先把请求发给企业自己的模型，再由 Claude、Grok 等 frontier model 检查。很多情况下，结果可以略好于只用 frontier model，成本却只有一半。

Gavin Baker：很多人听到成本减半，就认为 AI 基础设施需求会下降。其实成本差主要来自 token 层毛利率的变化。用户把需求从毛利率约 90% 的昂贵 frontier token，迁移到毛利率约 30% 的开源 token。生成 token 的底层算力成本并没有同比下降。企业建立 router 后，AI 预算可能稳定甚至下降，但所消费的 GPU 小时数反而可能上升，因为便宜 token 可以用得更多。

Gavin Baker：不同采用浪潮还处在完全不同的阶段。最前沿的公开公司已经发现 AI 支出在三个月内增长 20 倍，于是开始用 router 优化。AI 原生公司不再大量雇人，而是把资源投入 token。美国东海岸还有很多企业刚开始采用 AI，美国内陆企业整体更慢，欧洲甚至还在试图先想清楚怎样监管 AI，再决定怎样使用它。

Gavin Baker：有个数字一直在我脑中挥之不去。全球可能只有 25 万到 50 万人在真正使用 agentic AI，我们却已经处于严重算力短缺。地球上有七八十亿人。如果用户规模从 50 万上升到全球人口的 1%，再到 1 亿、5 亿，会发生什么？

Gavin Baker：质疑者会问，即使 hyperscaler 现在少赚了、旧合同重新定价后经营现金流会加速，最终付钱的客户在哪里？这些现金流只能来自两个方向：生产率提升带来的更快经济增长，或者劳动替代。Satya Nadella 的说法很直接，AI 要么推动经济实现接近 10% 的增长，要么就无法支撑现在的投入。

Gavin Baker：在很多 AI 原生公司里，劳动替代已经发生，但不是因为它们大规模裁员，而是因为它们从一开始就少招很多人。每名员工创造的 gross profit dollars 相比上一代创业公司呈垂直上升。a16z、Iconiq 等机构都做过类似研究。

Patrick O'Shaughnessy：我们也会看企业 token 支出占总薪酬的比例。最彻底采用 AI 的公司，这个比例能到 20% 至 25%。

Gavin Baker：Dylan Patel 是 ASI maximalist，他的比例大约是 30%。我甚至听过 50% 的例子。全球知识工作支出约 25 万亿美元。如果用 20% 这个比例计算，对应 5 万亿美元。它最终要么来自劳动替代，要么来自更快的经济增长。我们当然非常希望主要来自后者。

Patrick O'Shaughnessy：我今天早上从一位连续创办多家公司的优秀科技 CEO 那里听到一个观察。把疫情期间过度招聘的修正剔除后，由创始人控制的公司并没有出现全面大裁员。这些公司本应是最早用 AI 提效的一批。它们没有大规模裁员，可能说明管理层看到的机会足够多，仍然需要人和 AI 一起扩张。

Gavin Baker：这正是多头情形。Cognition、Ramp 和 Stripe 都发布过数据，显示 AI 支出最高的公司增长速度也明显更快。Cognition Index 很有意思。怀疑者正确地指出，它没有充分控制行业差异，但深入看，连水管工或 HVAC 承包商这样的传统行业，也能因 AI 提高效率。

Gavin Baker：接下来必须谈 memory LTA。现在几乎所有东西都短缺。如果局部数据显得弱，往往只是因为电力供应还不足以让新吉瓦产能通电。监管政策正在改善，燃气轮机和柴油发电机厂商都在扩产，甚至有人把旧飞机上的涡轮机拆下来翻新，再用于数据中心。资本主义很擅长处理这种约束。

Gavin Baker：但市场正在发生一个我起初判断错了的重要转变，memory 尤其明显。供应商正在用短期业绩上行空间，换取 supply chain agreement 或 Long-Term Agreement 的稳定性。这些 LTA 有很多形式，常见结构是客户预付款，并约定价格下限和上限。

Gavin Baker：理解 LTA 要从博弈论出发。真正具有规模的 AI 加速器玩家大约只有四类：Amazon 自研芯片、Google TPU、AMD，以及规模远超其他玩家总和的 NVIDIA。memory 对 token 输出极其重要。在给定 FLOPs 的情况下，配更多 memory 是提高 token 产出的最有效手段之一。它能降低 token 单位成本，因此 memory 涨价并没有引起需求负反馈，因为 memory 是压倒其他变量的主导轴。

Gavin Baker：假设到了 2027 或 2028 年，一家大客户因为短期供给过剩，想撕毁 LTA 以获取更低价格。可未来几年市场份额很大程度上取决于供应链配额，以及你预先锁定了多少产能。如果你在过剩期违约，两三年后议价权重新回到 memory 厂商手中，你的业务可能直接出局。即便严重过剩，博弈逻辑仍成立，因为这个行业有周期性，过剩之后通常会出现短缺。

Gavin Baker：比如 Google 撕毁 LTA，短期价格下降、产能自然收缩。下一轮短缺到来时，Google 的分配顺位会怎样？供应商当然会优先照顾守约者。过去 Apple 是压倒性的最大买家，没有真正同级的竞争者，即使把 SK hynix 得罪透了，Micron 也会接下订单。今天不同，至少有四个大玩家，还有大量创业公司。你若违反价格协议，供应商也可以取消数量协议，把产能给竞争对手。对 AI 公司而言，这可能意味着永久失去市场份额。

Gavin Baker：当前环境如此有利于 NVIDIA，我很难理解它为什么以这么低的估值交易。GPU 必须能被融资，而世界上没有任何 GPU 比 NVIDIA GPU 更容易融资。数据中心还需要土地和电力，NVIDIA 正通过撮合供需方参与这场棋局。它又推出了一个很聪明的新商业模式，可以把它理解为带收入分成的信用包装：只要 GPU 租金高于某个下限，NVIDIA 就参与收入分成。

Gavin Baker：这种安排可能让 NVIDIA 很快通过 royalty 形成一项巨大的准云业务，也能缓解现金流错配。它不是传统 vendor financing，因为 NVIDIA 并没有直接把贷款发给 GPU 买家，而是第三方出资。NVIDIA 仍会做股权投资，并明确写入条款，投资款不得用于购买 NVIDIA 芯片。虽然资金天然可替代，但这种约束至少能让各方更安心。

Patrick O'Shaughnessy：如果你是 SK hynix 的 CEO，你会怎么做？

Gavin Baker：我会照着 NVIDIA 的办法做。找到 GPU 买家、云厂商和融资方，参与 NVIDIA 式的信用包装。memory 业务本身更不稳定、可预测性更低，但 memory 公司现在有现金，可以先投入一笔确定金额，作为对债权人的增信，然后换取未来收入的一部分。Blackstone、Apollo 之类的资本提供方很可能也会向 memory 公司设计类似方案。

Gavin Baker：这相当于 LTA 的自然延伸。LTA 是用短期上行换稳定性，信用包装则能把一次性销售转化为 recurring revenue 的 royalty。NVIDIA 正在这样做，但市场明显低估了它的意义。NVIDIA 应该更清楚地解释这套模式。

Gavin Baker：第一，NVIDIA 对 AI 非常乐观。它过去没有在某些生态公司取得股权，事后看往往是失误。如今它几乎投资了所有关键方向，包括后来也投资 Anthropic。Jensen 能接触每个实验室，看到所有技术进展，包括 continual learning 团队和 Safe Superintelligence。所见信息让他保持乐观。因此 NVIDIA 在拥有强劲现金流时取得生态股权很合理。

Gavin Baker：第二，它还能取得收入分成。NVIDIA 每年产生数千亿美元级现金流，可以帮助客户跨过当前自由现金流转负、但经营现金流尚未加速到足以自筹全部建设资金的缺口。这样做会提高 NVIDIA 每吉瓦的收入，也会加强其竞争位置。

Gavin Baker：创业公司的芯片即使设计得很好，实际采购价格也往往高于 NVIDIA。它们买 HBM DRAM 的价格更高，融资成本也更高。如果架构依赖 HBM，就会直接暴露在供应链博弈中。除非它们选择完全不同的架构，否则很难绕开这些约束。

Gavin Baker：从模型实验室的博弈看，Anthropic 如果像 OpenAI 一样激进采购算力，可能早就拉开了无法追赶的距离。现在 OpenAI 回到了竞争中，Grok 也借 Grok 4.5 和 Cursor 进入 Pareto frontier。四个月前 Dario Amodei 说过，这是一项极难做的决策：买太多算力，公司可能因投入规模破产；买得不够，又可能输掉竞争。现在我们已经看见“买得不够”的后果。还有谁会在短期内松油门，尤其当大部分建设可能由经营现金流支持时？

Patrick O'Shaughnessy：你这次在硅谷遇到的人里，有没有比你明显更乐观的？他们相信什么，而你还没有相信？

Gavin Baker：这里几乎每个人都比我乐观。我读了 Dwarkesh Patel 写的文章，他推演过一年租用一张 H100 可能花到 25 万美元，大约是当前现货价格的 15 倍。这种结果原本甚至不在我“考虑过但认为极不可能”的分布里。Dwarkesh 很聪明，也非常接近行业核心。他的逻辑是，算力毛利、算力规模和推理毛利同时上升，三者相乘，就解释了模型实验室与开源推理收入总和的疯狂加速。开源本身的毛利率当然没有明显上升。

Patrick O'Shaughnessy：所以所有人都比你更乐观。

Gavin Baker：对。我看着股票市场，会觉得自己像个愚蠢的乐观主义者；可一旦和实验室或生态公司交流，我相对他们几乎又成了悲观者。这是一种很奇怪的状态。

Patrick O'Shaughnessy：中国 DUV 设备的消息应该怎样理解？市场观点跨度很大。一种说法是，这只相当于 ASML 在 2001 年掌握的技术；另一种说法是，这是全球先进算力供给新故事的起点。

Gavin Baker：两种说法可能同时正确。做个不完美的类比，DUV 像螺旋桨飞机，EUV 像喷气式发动机，或者 DUV 是普通喷气发动机，EUV 已经接近 warp drive。中国以前没有，而现在据称有了，这本身就是 phase transition。即使设备落后 25 年，也不应被忽略。

Gavin Baker：但股票市场会立刻大幅反应。即使这件事最终影响 ASML 订单，也可能要五年后才发生。期间市场可能反复担心、忘记、再担心、再忘记很多次。这次抛售很可能反应过度，但不等于事件本身毫无意义。对中国来说，独立掌握半导体设备极其重要。

Gavin Baker：还有未经证实的报道称，一台 EUV 设备可能被走私进中国。EUV 是极其庞大的机器，如果真能做到，会是惊人的情报行动。我不知道传闻是否真实。可以确定的是，中国工程师非常聪明、工作强度极高，而且国家把这件事视为战略重点。

Gavin Baker：问题在于，他们能否从 2001 年水平直接跨到 2026 年，甚至 2030 年水平。设备制造高度依赖 learning by doing，必须经历一轮又一轮真实制造和调试。这个过程不能简单压缩，也无法瞬移到未来。因此，这个进展很重要，市场大概也反应过度。作为美国人，我们很难完全理解中国内部正在发生什么，更难拥有绝对确信。中美正在脱钩，而且两边的行动逐渐相互强化。这很遗憾，但过程已经启动，双方都不会停止。

Patrick O'Shaughnessy：除了那十来家核心 AI 和半导体公司，美国其他公司会怎样？

Gavin Baker：上个月几乎所有非 AI 资产都在上涨。开源模型更接近 frontier，以及 Fireworks 让企业很容易定制模型，对软件行业和 AI 原生公司都是巨大帮助。两年前就有人说，从成立到年收入 5000 万美元并产生现金流，只需要九个月的公司数量从未这么多。过去人们会把它们贬低为 ChatGPT wrapper，也很难判断是否耐久。

Gavin Baker：现在情况变了。AI 原生公司已经围绕垂直场景积累了专有数据。Fireworks 推出了 Nexus。如果你在用 Claude Code、OpenAI Codex 或 Grok Build，只需几行代码就能把数据交给 Fireworks，用 reinforcement learning 定制一个模型，再通过 router 分配请求。他们展示的效果很强。这套方法几乎适用于每个 AI 原生公司。Harvey、Legora、Cursor 等都在积极采用。

Gavin Baker：企业过去可能把全部 token 都交给一两个 frontier model。现在可以只把 30% 到 60% 的 token 用在最适合的 frontier model，其余交给自己的 RL model。这样一来，公司不再只是 wrapper，产品防御性会大幅提高。

Patrick O'Shaughnessy：Cursor 那个实验很有意思。它像是在 AI 世界复现人类组织已经知道的做法：让最强模型负责规划，再把子任务分发给更弱、更便宜的模型，效率能提高约 15 倍。

Gavin Baker：可能出现一个很反直觉的结果。毛利更低、略落后于 frontier 的开源 token，反而会提高最先进 frontier token 的价值。有一种 Anthropic、OpenAI 或 Grok maximalist 观点认为，一旦 frontier model 达到 RSI，它可以通过 distillation 在每个智能水平上都以极低成本服务，开源就没有位置了。任何结果都有可能，我们必须谦逊，特别是在经历这个月之后。但我认为这种单一路径并不太可能。

Gavin Baker：原因之一，是许多 AI 原生公司已经积累了相当多的领域专有数据。在开源、推理云与 router 成熟前，企业别无选择，只能接受 frontier provider 的服务条款。现在它们可以脱离这种依赖，获得独立性、耐久性与更高安全边界。

Gavin Baker：便宜 token 还可能大幅放大最先进 token 的价值。假设今天有很便宜的“120 IQ”开源模型，那么能够编排这些模型的“160 IQ”frontier model 会不会更值钱？上次节目我提到，AI 经济回报出乎意料地集中在 frontier 层。现在随着 Together AI、Modal、Baseten、Fireworks 等推理云增长，这种集中开始松动。这些公司的增速接近 frontier lab 早期，却只消耗很少现金，按传统 rule of 40 衡量也非常夸张。

Patrick O'Shaughnessy：能不能把组织内部的薪酬分布类比到这里？CEO 的报酬是中位员工的很多倍，也许 CEO 对应 frontier token，普通员工对应开源 token。

Gavin Baker：完全可以。frontier token 可能丢失一些份额，但总市场增长很快，它们仍可能获得绝大多数经济价值，只是不再拿走全部。开源 token 则可能占 token 处理数量的大多数。对基础设施而言，这依然是好事，因为生成 token 都需要 FLOPs、电力、空间和散热。

Patrick O'Shaughnessy：AI 最坏的风险是什么？监管吗？

Gavin Baker：监管必须是最大的风险，也是最明显的风险。我来硅谷就是想找到足够可信的坏消息，让自己不再像一个看着股票越跌、却认为预期回报越高的疯子。7 月的现场基本面相比 6 月明显改善，但我最后仍认为，监管风险不可忽视。New York 推动 data center moratorium 就是警报。我们正生活在一个后事实、后逻辑的政治环境中。

Gavin Baker：AI 行业的公共沟通做得很糟。它至少已经意识到问题，但还没有完全修复。Washington 和很多普通美国人的主流叙事是：data center 会抬高电价、用光水资源、抢走工作。

Gavin Baker：现实往往相反。按照现在越来越常见的 behind-the-meter 协议，新 data center 落地后，周边居民电价通常会下降。这也是政府推动 data center pledge 的原因。过去开发商可能只需给当地警察和消防部门买一些新车辆或设备，现在常见条件是建设医院、学校、警察局、消防站，并帮助降低电费。

Gavin Baker：data center 还会持续需要水管工、电工和 HVAC contractor。就蓝领工资而言，data center 可能是我一生中发生过的最好事情之一。可自称代表蓝领劳动者的政治力量，反而可能阻止这些岗位出现。

Patrick O'Shaughnessy：关于算力，我们还漏掉了什么？

Gavin Baker：一个被忽略的变量，是 SRAM-based accelerator。它们不受 HBM DRAM 同样的约束，而且常用较成熟制程，不会直接和最先进 GPU 争夺同一批产能。把推理解耦后，通常会谈 prefill 和 decode，但 decode 本身还可分为 attention 与 feed-forward network。

Gavin Baker：理想架构可能是，在一种芯片上做 prefill；在高性能、带 HBM DRAM 的芯片上做 attention；再把 feed-forward network 交给 SRAM 芯片。对 feed-forward network 而言，SRAM 的效率很难被击败。无论怎样设计片上算力、HBM DRAM 与 SRAM 的比例，工作负载总在变化，不同任务的最优比例也不同。把三部分解耦，再把 SRAM accelerator 加入现有和新建算力集群，可能显著提高 AI 基础设施的回报率。
