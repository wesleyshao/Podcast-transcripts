### 从情人节小镇到 generative agents

**Harry Stebbings：** 你的投资人与朋友都说，必须从你独特的研究经历谈起。你曾因一个发生在情人节前夕的模拟项目受到广泛关注。发生了什么？它又怎样促成 Simile 的早期想法？

**Joon Sung Park：** 那是在 2023 年。当时 LLM 多用于分类或简单生成任务，但我们认为模型的潜力远不止于此。它们在训练中看过海量人类行为与情绪表达。如果从合适的角度向模型提问，就能从中提取相当真实的人类行为。

这不仅在研究上有趣，也具备很强的实用性，因为它不依赖某一个具体领域。计算机科学几十年来一直想创造可泛化的 agent，让它在任何环境中都能像人一样行动。我开始思考：也许 LLM 让这个愿景真正有了机会。

我们反过来问，如果把这条路线快进很多年，最雄心勃勃的终局是什么？答案是创造一座小镇的完整生活体验。于是我们构建了一个游戏小镇，放入 25 个 NPC。与传统 NPC 不同，这些角色早晨会醒来、执行日常安排、上班、建立关系，记得自己和其他人的互动，还会规划接下来的一天。

模拟设定在情人节前一天。令人惊讶的是，agents 会自行组织活动：有人提出办派对，消息在人际关系网络中传播，其他角色开始邀请朋友、协调时间，甚至装饰咖啡馆。没有人把完整流程写进脚本，这是小镇中的角色自行形成的行为。

这项工作有两个基础贡献。第一，它是最早的一批 generative agents 实例。当时我们使用 GPT-3.5 时代的 Text-Davinci，甚至还没有今天意义上的 ChatGPT。第二，我们在架构里显式加入 memory、planning 和 reflection，这些后来成为 agentic workflow 的常见组件。

原因很直观：只要把多个 agent 放在一起，它们就必须记得彼此。早期语言模型没有真正的 memory。如果不补上这一层，角色每次见到室友都会重新说“很高兴认识你”。为了让它们在长期环境中保持连续性，我们让每个角色拥有记忆、规划与反思能力。

**Harry Stebbings：** 今天大家仍然说 agent 有 memory problem。你们当时怎样解决？

**Joon Sung Park：** 最初的方法非常简单。语言模型很擅长处理自然语言，因此我们把经历全部写进 Markdown 文本文件。这个方法确实能工作，但模型有 context window。即使今天窗口更大，一个角色在游戏小镇里能够积累的经历仍然很多；如果搬到真实世界，人一生的记忆量更是巨大。真正的问题不是“有没有记录”，而是怎样理解如此大量的记录。

假设一个角色一周吃了五次 omelet，仅仅记住“五次”不够。于是我们设计了 reflection：每隔一段时间，让 agent 抽取一批具体记忆，像人在洗澡时突然产生的思考一样，对它们作更高层归纳。为什么这周总吃 omelet？是因为忙，还是因为喜欢？为什么每天都去图书馆准备这场考试？这个研究主题为何如此重要？

角色会从地面层的事实逐渐形成更抽象的认识：我真正投入于某个研究问题，它可能和童年经历或更根本的记忆有关，这件事正在塑造我是谁。reflection 因而不仅压缩记忆，也让 agent 形成个性、世界观和稳定的判断方式。

**Harry Stebbings：** 所谓 simulation model，就是创造一组 agents，让它们产生行为，再观察未来世界可能怎样演化。这个定义对吗？Simile 是否就是一家 simulation model 公司？

**Joon Sung Park：** 对。Simile 正在构建人类行为的 foundation model。它可以模拟个人，也可以模拟某一类 sub-population，最终还可以模拟完整生态系统乃至整个市场。

### 人类行为模型与独特数据策略

**Harry Stebbings：** 你们建立在 OpenAI、Anthropic 这类 frontier model 之上吗？两者是什么关系？

**Joon Sung Park：** 大型语言模型公司的任务，是创造高度理性、智能的机器，让它们擅长编码、自然科学和数学。Simile 对这些目标本身并不关心。

如果人在某个情境中会犯错，我们希望模型犯同一种错误；如果人类带有某种偏见，我们也希望模型以相同方式呈现偏见。我们要表示的是人的价值观、偏好和品味，也就是大脑中更主观的那一半。我们的目标不是制造比人更理性的机器，而是准确表示真实的人。

因此，Simile 与 frontier model provider 不是简单的上下游替代关系。前者可以把后者提供的通用语言与推理能力作为基础组件，但训练目标几乎相反：frontier model 往往想消除错误、偏见和非理性，Simile 却必须保留具有代表性的人在相同环境中会出现的错误、偏见与有限理性。否则，模型得到的只是一个“理想人”，无法预测真实消费者、选民或组织成员的行为。

**Harry Stebbings：** 人们嘴上说的，常常和实际做的不同。这个鸿沟会怎样影响模型？

**Joon Sung Park：** 互联网数据主要记录人们说过什么，而不是做过什么，今天的大模型又主要依赖这些 web data。Simile 会收集大量行为数据，包括交易数据和观察数据，也会与客户及数据供应商合作获取相关资料。

不过，我有一个可能不那么主流的看法：observational behavior data 很适合建立“过去观察与未来结果之间的相关性”，因此适合预测任务。但无论是做研究还是服务客户，我越来越确定，人们并不真正满足于预测。除了预测股票市场的人，很少有人只想知道未来会发生什么；他们更想塑造未来。

假设你是 Starbucks。得知两个季度后 Frappuccino 销量会下滑，并不能直接解决问题。管理层第一反应一定是：“那我们现在应该做什么？怎样避免这个结果？”他们要知道现在采取哪些措施，才能改变未来。

这需要 causal mechanism 和 counterfactual reasoning。模型不能只发现相关性，还要理解干预怎样改变结果。因此，我们非常重视 randomized controlled trials，也会运行大量 A/B testing，把“人们看到方案 A 和方案 B 后行为怎样变化”作为核心训练资产。这类数据超越了单纯观察，也是 Simile 数据获取策略的关键。

**Harry Stebbings：** 对 simulation model 来说，data、compute、algorithm 是几个核心支柱。数据是不是最困难的一环？

**Joon Sung Park：** 数据当然非常重要。我的根本判断是，这一代 AI 公司必须拥有有趣而且可防御的数据策略。

Simile 的数据挑战有两个层面。第一是找到合适的人。其他 AI 公司可能寻找顶尖程序员或科学家来标注专家任务，我们需要的是普通人，以及他们真实的日常生活。关键在于样本是否具有代表性，我们拥有的人群结构是否能代表现实世界。

第二是问对问题。什么样的实验和问题能触及一个人最核心的特征？我们有时会先请参与者讲述自己的一生：在哪里长大，经历过什么，遇到过哪些最困难的问题，做过哪些关键决定。这些信息能让模型理解一个人为何以某种方式行动。

**Harry Stebbings：** 我仍想追问“人们不关心预测”这句话。如果 Starbucks 预知两个季度后销量下滑，它就能提前调整采购周期和库存，这难道没有价值？

**Joon Sung Park：** 当然有价值，但企业想知道预测，最终仍是为了改变策略。它要决定为了服务市场需要配置多少资源，以及怎样应对需求下降。问题的核心还是 counterfactual：既然我们想服务这个市场、最大化公司价值，现在应该采取什么行动？Simile 模拟的是人，提供的是消费者或某一人群在不同干预下会如何行动。

**Harry Stebbings：** 这对 CVS 等大品牌做调查、收集客户反馈、判断消费者需求非常有价值。请允许我说得尖锐一点：你们怎样避免只成为下一代 Qualtrics？

**Joon Sung Park：** 我们构建的核心 primitive 很直接：你告诉我们想了解哪一群人，我们为你建立他们的模型。

过去的创新大多发生在工具层，例如怎样做更好的问卷或访谈。simulation 不同，它要建立最可泛化的人类模型，以规模化表示人的观点。长期看，我们会模拟许多人相互作用，让企业看到一个决策的所有下游影响。新产品发布前，可以先模拟完整 launch，观察受众怎样反应、市场怎样移动，而不只是再做一次问卷。

作为科学家，我还相信 simulation 可以帮助处理 wicked problems。例如，气候变化要求许多激励不同的利益相关方采取集体行动，难点在于找到所有参与者都愿意接受的均衡。我们能否模拟这一决策过程？在什么条件下民主制度会失败？这些都是 simulation 最终可以回答的问题。

**Harry Stebbings：** 既然模拟选举、民主失效等问题可能成为政府的强大工具，你们怎样判断应该和谁合作、又不应该和谁合作？

**Joon Sung Park：** 这正是原则极其重要的地方。我喜欢科幻作品。在关于高级文明的故事里，通常有两根技术支柱：一根是某种 AGI，另一根就是 simulation。任何强大技术都有被滥用的真实风险。

我们给自己的 North Star 是“representation at scale”。人们有不同观点、偏好和品味，而许多重要决定发生时，受影响者并不在房间里。组织总说“我们倾听员工、客户和利益相关者”，现实中很难真正做到。simulation 的最佳用途，是让每一次决策都能在规模上听见这些人的声音。

### 准确性、数据飞轮与计算成本

**Harry Stebbings：** 需要多少人，才能对模拟结果有信心？100、1,000，还是 100 万？

**Joon Sung Park：** 如果研究对象是很窄的一群人，社会科学研究通常在约 1,000 个样本时就能取得统计显著性。但客户经常临时组合筛选条件，要求研究某个非常具体的 sub-population。为了在任意筛选条件下都能模拟，我们最终希望代表的是整个人群。因此，样本越广越好。

**Harry Stebbings：** 随着使用增多，你们会不会像自我强化一样越来越准确？

**Joon Sung Park：** 会。我们获得更多模拟结果，再观察现实世界真正发生了什么，就能形成 data flywheel。对早期合作伙伴而言，这也是核心价值之一：Simile 会在它们自己的业务语境里不断变好，形成复利优势。

**Harry Stebbings：** 有点像 AlphaGo 通过反复自我对弈学习。世界每天发生的活动和结果，都是一盘新的棋局。模型可以据此纠正哪些判断错了、漏了什么、什么没有发生。积累一万天以后，你们可能比任何人都更理解模型自身。

**Joon Sung Park：** 可以借 coding agent 解释数据飞轮为什么成立。编码模型进步极快，一个重要原因是 reward function 非常清晰：模型提出建议，用户点击 accept，信号很好；用户 reject，同样提供明确的负反馈。系统很快知道什么是好结果。

simulation 看起来更难，因为要预测的事情发生在未来，回报似乎很晚才能验证。但它也有更强的机制：现实世界本身就是 ground truth。我们每天可以生成数万条 hypotheses，每条都映射到一个可验证的终局陈述。之后持续观察现实，在相应时间点判断假设对错。一个月后，也许已经生成 100 万条假设，并能统计其中多少实现。这是学习世界的最好方式。

这个机制与一次性市场研究不同。系统不必等客户提出一个问题才学习，而是可以持续提出关于现实的可证伪判断，并在不同时间尺度上回收答案。有些假设第二天即可验证，有些需要一个月或一个季度。每一批现实结果都会修正模型对人群、因果关系与环境变化的理解，所以合作时间越长，客户自身语境中的专用优势越强。

**Harry Stebbings：** 大规模、高质量运行这些环境，需要非常多 compute 吗？

**Joon Sung Park：** compute 很重要，但我们也持续提高效率。最初的大量算力主要用于寻找技术突破，例如探索不同训练方法和 dataset。一旦形成明确观点，就能很快优化。

我们有一个已经投入 production 的模型。现在运行它的成本只有早期的大约 1%，也就是降低了约 100 倍。我们并没有改变 reward model 或基本理念，而是找到了推理阶段更高效的建模方法。科学进展和工程技巧可以显著降本，但找到最初正确方向仍需要很大投入。

### 市场空间与 synthetic panels

**Harry Stebbings：** Simile 的 TAM 有多大？一端是 CVS 这类巨型企业，另一端也可能是想运行个人场景模拟的普通消费者。它最终服务所有人，还是主要服务世界最大的公司？

**Joon Sung Park：** 我的职业起点是研究。研究者的工作归根结底是在服务人类。我们当然享受发现新事物的过程，但基础信念是，科学突破最终应当让社会中的每个人受益。我也以同样方式看 simulation。

现阶段先服务企业有几个原因。第一，企业有明确预算，而且我们已经看到清晰的 product-market fit。第二，企业环境是验证技术的最佳方式。我们需要很紧的反馈回路，知道模拟什么时候正确、什么时候错误，并每天改进。

我在 Stanford 时，隔壁办公室是 Pat Hanrahan。他是 Tableau 创始人之一、计算机图形学教授，也是 Turing Award 得主。他曾给我们一个建议：“获得真实反馈的最好办法，是让用户为产品付钱。”这也是 Tableau 的核心方法。企业 market research 是一个有预算、有即时需求的 wedge，但长期看，我希望整个社会都能使用它，因为最终目标是帮助人们作出更好的决定。

**Harry Stebbings：** 你什么时候确认已经找到 product-market fit？

**Joon Sung Park：** 很多 Fortune 500 董事和高管会到 Stanford 看实验室 demo。他们看到 Smallville 后都说：“如果我们能这样模拟市场，公司的经营方式会彻底改变。”需求信号从一开始就很明显。

但我们仍花了约一年证明这不只是有趣的 demo，而是能准确预测行为的模型。我们在问卷、行为实验和真实环境中验证，结果显示：模型预测人的行为与态度，其准确度能达到“同一个人再次回答自己问题”的 85%。我们在 2024 年底发布这项研究，它推动了 synthetic panels 和 simulation 这一市场的形成。

**Harry Stebbings：** 三年后，synthetic panels 会比 human panels 更大吗？

**Joon Sung Park：** 会，而且它不只是替代现有人类样本市场，还会大幅抬高能够回答的问题上限。

今天的市场其实很低效。公司、政府和科学家有很多问题：推出某项产品会怎样，采用某种战略或政策会怎样，某个大规模实验会发生什么。但真正被研究的可能只有 5%。其余 95% 因为技术上无法运行、特别是无法做 emergent-scale experiments，或者成本和时间不允许，最后根本不会测试。

社会因而大量依靠直觉决策。直觉有时有效，但也会被个人狭窄经历严重扭曲。simulation 能解除这个限制，让我们在真正把行动投向现实世界以前，测试关于世界的每一条 hypothesis。

**Harry Stebbings：** 你怎样平衡下一美元收入与研究优先级？大客户愿意支付很多钱，但公司也要在 customer success、FDE 和产品能力上投入。如何兼顾利润最大化与研究纯度？

**Joon Sung Park：** Simile 同时是一家产品与工程公司，也是一家研究公司。联合创始团队包括我、Michael Bernstein、Percy Liang 和 Liane。我们三位来自 Stanford 研究体系：我研究 agents 与 simulations；Michael 长期领导 human-centered AI 研究，并参与推动早期 AI 领域的重要工作；Percy 是提出 foundation model 这一术语的人。Liane 则负责 go-to-market。

我们相信 simulation 可能成为 AI 的下一次 paradigm shift。之所以能够同时运营研究实验室和产品公司，是因为技术进步与市场需求高度一致。模型越能准确表示人，就越能创造扎实、可信的模拟，用户体验也立刻变好。只有这种对齐存在时，研究机构与产品公司并存才可能产生很强的效果。

### Fortune 500 销售、ROI 与预测市场

**Harry Stebbings：** 向世界最大的企业销售，通常被认为需要多年。你们与 CVS 等公司合作时也是这样吗？

**Joon Sung Park：** 完全不是。我在 2025 年 6 月离开 Stanford，刚好一年。创业时，我以为市场需要一两年才能接受 simulation，所以计划先打基础，到 2026 年底再加速商业化。

实际情况是，客户行动得极快，甚至改变了我对 corporate America 的看法。以 CVS 为例，我们合作的一位 insights VP 非常前瞻、勤奋而有雄心。更重要的是，这些管理者日常面对的痛点比我预想得严重得多：传统实验太慢、预算太高、很多问题根本没有证据。只要看到 simulation 可能解决这些痛点，他们愿意放下其他事情，立刻试用。

一些全球最大的企业在三个月内就完成交易。对 enterprise sales 来说，这接近闪电速度。

这种速度不是因为大企业突然不需要采购、法务或安全流程，而是因为业务痛点足够尖锐。许多团队要等三到六个月才能拿到一次传统研究结果，等报告完成时，市场环境可能已经变化。只要 Simile 能在第一次会议中，用几分钟复现一项客户已经知道答案的历史研究，就能先用客户自己的 ground truth 建立信任。之后再把系统用于尚未发生的新决策，销售讨论就不再只是概念演示。

**Harry Stebbings：** 对客户来说，速度和准确度哪个更重要？

**Joon Sung Park：** 两者都重要。很多问题今天完全靠直觉。如果系统能先提供方向性证据，客户就愿意试。之后他们会发现，这是一种与海量数据交互的高效方式，而且结果相当准确。

我们获得第一批客户的一种方式，是在第一次电话中让对方拿出大型咨询公司做过的研究，再直接问系统：“如果重新运行，这个结果会是什么？”过去需要三到六个月完成的研究，Simile 两分钟就预测出结果。这种对比非常有说服力。

**Harry Stebbings：** 你甚至可以对客户说：“你过去做了这个 campaign；如果换成另一个版本，效果可能高 12%。现在要不要买产品？”这几乎是销售人员最想要的证据。

如果 Simile 能为 CVS 这类公司创造数亿美元、甚至数十亿美元收入，只收 100 万美元，value generated 与 value captured 之间差距很大。你们怎样更合理地提取价值？

**Joon Sung Park：** 市场正在向更贴近价值的定价方式移动。客户从 Simile 获得的一项核心价值，是避免可能造成数亿美元损失的错误决策。

**Harry Stebbings：** 所以主要是 prevention，而不是 optimization？

**Joon Sung Park：** 两者都有，但 prevention 是最直观的价值案例。如果一个方案失败会损失 5 亿美元，而 simulation 帮助企业在执行前避免它，这就是没有争议的 painkiller。客户很容易计算 ROI。

**Harry Stebbings：** 如果你们足够准确，Kalshi、Polymarket 这类预测市场还能继续存在吗？

**Joon Sung Park：** 两类产品的确重叠，都在帮助人们窥见未来。但 Simile 不只问“会发生什么”，更关心“为什么发生、怎样发生”。我们希望展示生态系统为了到达某个结果会经过哪些步骤，以及客户可以在何处阻止或促进这个结果。单一概率预测无法提供完整因果路径，这正是 simulation 的力量。

### 组建团队与争夺研究人才

**Harry Stebbings：** 从研究者转为 CEO 后，你对建设一支顶级团队最大的认识是什么？

**Joon Sung Park：** 第一，团队必须平衡。我能带来研究能力，但我不是 enterprise seller，因此必须由 Liane 这样的联合创始人领导商业化。公司扩张时会不断出现新缺口，领导者要提前看见，并及时补齐。

第二，团队的价值观和严谨程度必须一致。我曾经画人物肖像。人物画家之间有个不成文的观察：不管画的是谁，画中人多少都会带有画家本人的气质。建设真正重视的团队也是这样，你应当能在团队里看到自己最看重的特质。

我首先寻找“成功的共同分母”。一个人的人生会经历不同阶段、公司和岗位。每一次事情成功时，他是否都是推动成功的关键变量？如果答案是肯定的，通常说明他有极强 ownership，会说“无论其他条件怎样，我会亲自确保这件事成功”，同时也能不断重塑自己。

Michael Bernstein 就是例子。博士期间他研究 crowdsourcing 与 collective intelligence，成为 Stanford 教授后转向其他 AI 方向，后来又进入 generative AI agents 和 simulations。每个阶段的作品都能看出鲜明的 Michael 特征，也能看出他是推动结果的人。

我还寻找一个人身上是否同时存在两种按常理不该共存的 superpowers。会编程又擅长数学并不罕见，因为两者高度相关。真正稀缺的是互相矛盾的能力。

这项标准并不是要求每个人都“全能”，而是寻找能跨越组织边界的人。研究人员如果既能追求严谨真相，又能理解产品为何必须在有限时间内交付，就能缩短 lab 与 customer 之间的距离；商业负责人如果既能制造销售紧迫感，又能尊重实验结果的不确定性，就不会为了季度数字破坏长期技术信誉。Simile 同时经营研究与产品，这种不相干能力的组合尤其重要。

**Harry Stebbings：** 最好的 CMO 就是这样。他们一方面极端重视数据、方法严谨，另一方面又有艺术家的创造力与想象力。这两种思维很不同，同时具备才是 world-class CMO。

**Joon Sung Park：** 对。我也这样描述过一位董事：他分析能力极强，却又非常依赖直觉，这可能正是他能持续作出成功投资的原因。

团队里的另一个重要组合是“短期 paranoid，长期 religious”。Liane 每天都会假设，如果今天不把所有努力都摆上桌，公司就会落后、失败；但长期看，她又有近乎信仰般的确信，相信无论出现什么问题，我们最终都会让公司成功。

通常，短期偏执会让人长期悲观，适合做空股票，却未必适合建设公司；长期确信又可能带来松懈，认为今天少做一点也没关系。要同时保持两者，需要一种不常见的心理结构：充分感受眼前所有风险，却不让风险摧毁对长期结果的信念。

**Harry Stebbings：** 这也很像我。成功创始人常说：“如果早知道最后会成功，我就不会那么焦虑。”我认为这是很糟糕的复盘。正因为当时焦虑，他们才准备充分、熬夜完善演示、给销售团队制造紧迫感、提前招聘。paranoia 本身就是成功原因之一。

顶级研究人员的 total compensation 已达到数千万美元。你也感受到湾区这场人才战争吗？

**Joon Sung Park：** 完全如此。我最亲近的一些研究者朋友，total comp 的确在数千万美元区间。邀请他们加入 Simile 时，我会坦白：无论公司融资几亿美元，都很难在基础薪酬上与大实验室完全匹配。

但研究者真正关心几件事。首先是 vision。他们亲眼看过 OpenAI 从硅谷的笑柄成长为接近万亿美元的企业，也看过 Anthropic 在五年内经历类似跃迁，因此知道宏大愿景有可能成为现实。其次是 impact：这项技术会怎样影响社会？最后是研究问题本身是否足够有趣。

**Harry Stebbings：** 研究者频繁跳槽，你担心 retention 吗？

**Joon Sung Park：** 一直担心。领导者不只是招聘优秀的人，还要提供一个平台，让每个人最大程度表达自己的 superpower。留人确实难，但可以做到。

我对此有一点自豪。博士生通常每做一个新项目就更换合作者，除了导师，co-authorship 经常全部变化。但过去六年，我的核心团队从未离开，大家一起从一个项目走向下一个项目。后来我说要创建 Simile，还说服了曾经的博士导师 Michael 和 Percy 加入。

长期协作建立了真正的信任。我也把自己的职责理解为：向团队传递足够的信心与信任，让他们相信这件事会成功，同时为他们创造充分发挥能力的环境。

仅靠 equity 或现金无法解决 retention。顶尖研究者要看到自己的工作确实改变了模型方向，也要确信公司不会把他们降格为短期 feature factory。领导层必须持续解释技术路线、社会影响和商业反馈怎样连在一起，让个人研究成果能够进入真实世界。这种“能够最大化表达自己的 superpower”的平台，是 Simile 在无法匹配巨型实验室现金薪酬时最重要的竞争条件。

**Harry Stebbings：** 很多优秀学者正在考虑创业。我担心投资到的只是 science project：它也许 intellectually satisfying，却不一定能成为好公司。判断一个学术团队能否跨越到创业，你会看什么？

**Joon Sung Park：** 看他们究竟“忠于一个问题”，还是“忠于产生影响”。有些研究者迷恋某个问题本身，但它可能不适合形成公司，也没有商业 thesis。另一些研究者由现实影响驱动，他们会主动寻找能够触达用户、创造收入的问题。投资人应该寻找后一类。

### 六个月融资 3 亿美元

**Harry Stebbings：** 你们最近完成了新一轮融资。它是怎样发生的？

**Joon Sung Park：** 大约五个月前，我们刚完成 1 亿美元融资。不久后，现有投资人主动提出 pre-empt 新一轮。上一轮由 Index Ventures 的 Shardul Shah 领投。他看过许多高速增长市场，却认为自己很少见到这样的 traction 和客户拉力。再结合技术进展，以及更多 compute 可能进一步加速研发，内部投资人开始问：为什么不现在投入更多？

我们原本没有融资计划，但湾区有几支我非常尊重的团队。如果真的要融资，我希望和它们谈。名单最上方是 Greenoaks。对方已经深入研究 simulation 市场、竞争者与行业进展，只是在等待合适时机。

我联系他们说：“这一轮不会跑正式 process。如果你们想加入，只有几天时间。”他们很快作出决定。最终我们融资 2 亿美元，过去约六个月累计融资达到 3 亿美元。这给了公司足够资本，去解决雄心很大的建模挑战、投入数据和算力，并建设团队。Index、Greenoaks 等投资人也为公司带来很强的合作网络。

这轮融资的逻辑不是用资本掩盖尚未出现的需求，而是把已经看到的客户拉力与研究投入提前匹配。数据覆盖、随机实验、训练探索和大规模 inference 都需要在结果出现前投入。如果确定更多输入能够提高找到正确模型路线的概率，延后融资反而可能牺牲技术窗口。公司无法承诺每一项研究都成功，但可以增加高质量实验的数量与速度。

**Harry Stebbings：** 六个月前刚融资 1 亿美元，你们并不缺钱。为什么还接受 2 亿美元？

**Joon Sung Park：** 我们确实认真讨论过。最后的判断是，资金可以直接转化为 compute、data 和人才投入。研究结果不能被完全控制，但可以控制投入和研究过程。当我们确认额外资源能显著提高输入规模、加快技术进展时，融资就有意义。

**Harry Stebbings：** 从学术界出来，连续完成三轮融资后，你对 fundraising 有什么新认识？

**Joon Sung Park：** 创业前，我很怀疑 VC 到底有什么作用。现在我仍很难用一句话定义，但如果找对人，他们可以成为很好的伙伴与导师。我第一次真正经营公司，研究经验很丰富，日常管理却几乎处处是新问题。可信任、见过类似发展阶段的投资人会提供很大帮助。

早期投资团队成为我的重要导师，Mike Volpi 还把我介绍给 Liane，后者最终成为关键的联合创始人、商业伙伴和朋友。这些帮助很难量化，却真实改变了公司。

第二个认识是，一切往往比计划来得更早。我原以为 seed 后一年融 Series A，再过一年融 Series B；结果这些轮次都在一年内发生。资本市场的兴趣经常比公司自己的时间表快一步，创始人必须随时准备好。

**Harry Stebbings：** 市场这么火热，会不会跑到基本面前面？融资公告带来媒体关注，又会引来下一轮，hubris 可能越来越高。

**Joon Sung Park：** 市场的一些部分确实很 frothy，资本和兴奋度都很高。所以我格外看重基本面：客户是谁，真实 market pull 有多强，技术怎样进步。OpenAI 和 Anthropic 的发展虽然惊人，但背后有可描绘的基础路径：模型按某个速度变好，需求也清楚存在。Simile 也能看到其中一些基础变量，而不能只依赖市场情绪。

### 单次 1 亿美元的模拟与十年后的世界

**Harry Stebbings：** 不同 simulation 的 unit economics 是否差异很大？就像模型路由一样，复杂任务需要昂贵 frontier models，简单任务可以交给便宜模型。

**Joon Sung Park：** 会。需要理解一个决策全部下游影响，或者要对全美国做 market segmentation，计算成本明显更高。但这类 simulation 往往也给客户带来更高 ROI，因为对应的是一旦判断失误就非常昂贵的决策。

行业已经看到 inference cost 持续上升。thinking models 可能推理半小时甚至一天，消耗海量 token。我认为 simulation 会成为下一条成本和价值同时上升的 frontier。

我的设想是，两三年后，一次 simulation session 可能需要 1,000 万至 2,000 万美元计算成本，但它创造的决策价值足够大，政府或全球最大企业愿意为这一次结果支付 1 亿美元。

**Harry Stebbings：** 今天还不能模拟、三年后能够实现的是什么？

**Joon Sung Park：** 与其说今天“不能”做什么，不如说很多事情已经能做 proof of concept，却无法成为可依赖、可规模化的 production system。这是 AI 最核心的鸿沟之一。

未来会出现复杂的 multi-agent simulation，以及由许多步骤组成的长期研究。其实我们从一开始就在 Smallville 做 multi-agent simulation，因为我、Michael 和 Percy 常玩一个“time machine game”：假设坐时间机器去十年后，最疯狂的新事物是什么？今天能否先做出来？Smallville 正是这个问题的产物。

现在真正要补的是评估有效性、建立可扩展系统、让客户能依据结果作决策。模型能力、模拟质量和系统规模每天都在改善，这条鸿沟也在逐步缩小。

评价机制尤其关键。一个看起来栩栩如生的 multi-agent world，并不自动等于能支持数十亿美元决策的工具。系统必须说明结果对哪些假设敏感、在什么人群和时间尺度上有效，并用后续真实结果持续校准。只有当客户能够复现、审计并理解误差边界时，Smallville 式研究原型才真正跨入 production。

**Harry Stebbings：** 那我们一起玩 time machine game。十年后最疯狂的变化是什么？

**Joon Sung Park：** 我喜欢从技术史寻找类比。今天 AI 的主流形态像“智能的 CPU”：一个很大、很聪明的模型，擅长复杂推理。

simulation 有机会提供“智能的 GPU”。Simile 不追求制造单个超级智能体，而是制造许多和普通人一样聪明、却拥有不同价值观、品味和经验的模型。人的魅力来自个体差异；当大量个体共同作用时，又会出现社会、制度与集体成就等 emergent phenomena。如果 simulation 能复制这种集体过程，会产生非常重要的新能力。

**Harry Stebbings：** 是否意味着每个人都会拥有一个在模拟世界中像自己一样行动的 digital twin？

**Joon Sung Park：** 终局仍是 representation at scale。社会历来用不同机制代表成员，有时是政府，有时是公司。公司本质上也是社会配置资本、满足需求的一种结构。如果我们能用更细粒度、可扩展的 artifact 表示每一个人，就可能由此创造新的政策和新公司。

**Harry Stebbings：** 对 hedge fund 来说，这几乎是最明显的购买理由。花 100 万美元签约，就可能获得日常经济活动的巨大 alpha 和 edge。

**Joon Sung Park：** 也许 Simile 以后会拥有一支小型 hedge fund。公司已经有 quant 背景的成员。他们不是为了立刻在 Simile 内创建 quant fund，而是因为“建模世界”与他们的兴趣高度一致。但长期看，这个方向确实有意思。

**Harry Stebbings：** 再把 time machine 推到极端。如果 Simile 或类似提供商极其准确，股票市场会不会变得不可投资，因为拥有完美模拟能力的基金占据压倒性优势，市场不再公平？

**Joon Sung Park：** 如果未来存在某种 AGI 和近乎完美的 simulator，今天关于世界的很多基础假设都会改变，股票市场可能就是其中之一。

**Harry Stebbings：** 还有哪些今天被视为理所当然的事情，五年后可能不再成立？

**Joon Sung Park：** 我们现在默认，不可能真正获得所有人的观点，所以必须由 representatives 粗略代替。这种机制有时有效，有时失败。我不认为未来还必须接受这个限制。我们可能构建一个真正表示社会成员和 collective intelligence 的新层。

### 爱情、快速问答与第一位相信你的人

**Harry Stebbings：** 爱情的未来会不会也是 Simile？如果每个人都能模拟自己，约会时可以先让数字分身同时完成 100 场“第一次约会”，再把最匹配的人带入下一阶段。当然，只能是第一次约会，否则你会惹大麻烦。

**Joon Sung Park：** 我明白这个想法。不过我有点浪漫主义。爱会以不同形式出现，人也高度多样。我仍相信，至少对我而言，爱会以更自然的方式到来。我在意怎样遇见一个人，也在意两个人共同经历的旅程。

一起经历事情、形成 shared memory，是建立信任的根本。产品使用 simulation 时，也要让用户参与整个过程，而不是只拿到一个神谕式答案。寻找伴侣有点像和另一个人共同创办自己的人生。真正重要的是，两个人是否能一起进入并完成生活的过程。

**Harry Stebbings：** 你太浪漫了。我想到一档节目 Married at First Sight。如果 Simile 先运行足够多模拟，促成一对真正完美的“一见面就结婚”，那会是极好的品牌广告。

进入快速问答。今天最被低估的 AI researcher 是谁？

**Joon Sung Park：** 很多大型实验室里都有非常出色的人，只是因为不再公开发表论文，名字不为外界所知。很难只选一个。

**Harry Stebbings：** 哪个 AI 领域最过热？

**Joon Sung Park：** 没有清晰现实影响路径的新实验室。我担心其中一部分最终只是有趣的 research project，而不是可持续公司。

**Harry Stebbings：** 如果你坐在我的投资席位上，AI 产业中哪个方向投入不足、最令人兴奋？不能回答 simulation。

**Joon Sung Park：** 未来的 AI 公司必须有独特 data strategy：是否拥有别人无法取得的数据？是否知道怎样收集极难获得的数据？遇到这种机会，我会投资。

robotics 是明显例子，虽然已经获得很多资金，不能说投入不足，但数据与现实反馈让它仍很有吸引力。此外，inference layer、chip layer 和其他 hardware 也很有意思。进入门槛很高，但最近几年有少数团队做得非常好。例如刚从 stealth 走出来的 Etched，我很看好这支团队。

**Harry Stebbings：** 最后一个问题。别人为你做过最善意的事情是什么？

**Joon Sung Park：** 我的职业生涯一直需要很多帮助。大学毕业后，我搬到 Palo Alto，住在别人的车库里，没有工作，尝试的 startup 也没有进展。那是我非常迷茫的时期。

我能感觉到 AI 浪潮正在形成。我想，如果要成为 surfer，就必须找到可以冲浪的 wave；当 AI wave 到来时，我不只想站在现场，还希望参与创造浪潮，从而确保自己在其中有一席之地。

但我本科没有任何研究经历。申请 PhD 时缺少本科研究，通常几乎不可能被接受。我给很多人发消息，其中一位回复了我：Stanford 理论计算机科学教授 Mary Wootters。她与我毕业于同一所大学。直到今天我也不知道她为什么愿意帮助，可能只是因为同校，也因为她看到一个学生在真诚求教。

她原本只需花半小时，却把整整一个上午给了我，解释应该怎样理解 AI、怎样进入研究，还把我介绍给最初的一批研究伙伴。那些人在没有明显理由相信我的时候，给了我建议和进入研究领域的第一只脚。我当时并不觉得自己配得上这种帮助，所以始终非常感激他们纯粹出于善意作出的下注。
